# 拆解并分阶段处理坏习惯

## R — 原文 (Reading)

> “你无法一次解开所有结……你必须逐一解开这些结，而且不需要一开始就专攻最难的部分。”
>
> — B.J. 福格，第7章「让你想终止的习惯更具体」

> “阶段1，致力于创建新习惯。阶段2，致力于终止旧习惯。如果做不到，那就进入阶段3，致力于用新习惯来替代旧习惯。”
>
> — B.J. 福格，第7章「行为改变系统方案的3个阶段」

> “有时候，只需要解决提示问题就能终止习惯，具体的方法有3种：移除提示、规避提示或忽略提示。”
>
> — B.J. 福格，第7章「聚焦于提示以终止习惯」

> “找到一个相比于旧习惯更容易执行、动机更强的新习惯。”
>
> — B.J. 福格，第7章「替换具体的习惯」

---

## I — 方法论骨架 (Interpretation)

“坏习惯”通常只是一个概括标签，下面缠着多个动作、时点、提示和即时收益，不能一次性处理。
先把标签拆成陌生观察者能判断是否发生的具体绳结，并选最容易、最有把握、情绪负担最低的一结。
改变不是从猛然戒断开始：第一阶段先建立一个安全、容易成功的积极习惯，练习改变技能并积累成功证据。
第二阶段才终止选中的旧行为；默认顺序是先移除或规避提示，再打弱时间、资金、体力、脑力或日程能力链，最后才调整动机。
若完全停止过难，可先缩短周期、时长、次数或强度，但不能把风险行为的缩量自行当作安全治疗。
只有创建积极习惯与直接终止都不足，才进入第三阶段做替换。
替代行为必须在同一提示出现时，比旧行为更想做、也更容易做；“更正确”或“更健康”本身不够。
若旧行为在调节悲伤、焦虑、孤独、疲惫或创伤反应，必须把这个功能纳入设计；只拿走行为可能导致复发或功能迁移。
全流程把方案当作可迭代假设：先记基线，每轮只改一个变量并记录结果，不能把相关性写成确定因果。

## A1 — 书中的应用 (Past Application)

### 案例 1：把“到处乱扔”拆成 15 个具体绳结
- **问题**：福格想改变“到处乱扔东西”，但这个标签覆盖许多不同动作，无法直接设计。
- **方法论的使用**：他列出 15 个以上的具体行为，例如把毛衣放在梳妆台、把书堆在厨房柜台，再从最容易、最没压力的一结开始。
- **结论**：概括标签需要拆开；先攻最难问题会增加无力感，易结更适合学习改变技能。
- **结果**：书中报告他开始掌控具体杂乱行为并变得更乐观，但没有量化长期整洁结果。

### 案例 2：处理甜食背后的悲伤功能
- **问题**：朱妮在悲伤和疲惫时反复吃甜食，戒断和意志力方案持续失败。
- **方法论的使用**：她把“戒糖”拆成晚餐吃冰激凌等具体行为，逐一调整提示和环境；同时建立写日记、与朋友交谈等积极习惯，让对母亲的怀念得到表达。
- **结论**：若旧行为提供即时安慰，终止路径必须正视其情绪调节功能，不能只把它当成自控失败。
- **结果**：训练营结束 3 个月后，她自述已改掉爱吃甜食的习惯；这是个人自述，不等同于临床证据。

### 案例 3：用更有吸引力、更容易的行为替换政治新闻
- **问题**：福格想停止阅读令自己血压升高的政治新闻。
- **方法论的使用**：在直接终止不足后，他没有选文书工作这类低吸引力任务，而是把同类屏幕提示重新映射到自己喜欢、也容易打开的冲浪视频。
- **结论**：替代行为要在动机和能力上胜过旧行为，才能在同一提示下赢得竞争。
- **结果**：福格报告自己成功以冲浪视频替代了政治新闻阅读。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户想戒掉“刷手机、拖延、乱吃、乱放东西”等习惯，但目标仍是覆盖多个时点和动作的概括标签。
2. 用户曾靠决心、戒断、羞耻或忽略诱惑，短期有效后反复复发。
3. 用户不确定该移除提示、增加摩擦、降低动机，还是寻找替代行为。
4. 旧行为总在焦虑、悲伤、孤独、疲惫或压力出现时发生，做完先感到宽慰、随后后悔。
5. 用户已尝试建立积极习惯并直接终止一个具体旧行为，但仍需评估是否进入替换阶段。

### 语言信号 (用户的话里出现这些就应激活)

- “这个坏习惯怎么都戒不掉，总是复发。”
- “我想停止刷手机/吃零食/看新闻，但不知道先改什么。”
- “帮我把这个坏习惯拆开，一个个处理。”
- “是不是应该找个好习惯替代它？”
- “How do I break this bad habit?” / “I keep relapsing.”
- “Should I remove the cue, add friction, or replace the habit?”

### 与相邻 skill 的区分

- 与 `fogg-diagnose-map` 的区别：后者诊断一个具体行为事件的 MAP 瓶颈；本 skill 先拆开概括标签，并管理“建新习惯→终止→必要时替换”的完整次序。
- 与 `fogg-select-golden-behavior` 的区别：后者从愿望中发散并筛选值得建立的行为；本 skill 的主对象是需要减少的一组旧行为，只在第一、三阶段借用行为匹配。
- 与 `fogg-simplify-action` 的区别：后者让想做的行为更容易；本 skill 反向打弱旧行为能力链，或让替代行为比旧行为更容易。
- 与 `fogg-grow-habits-adaptively` 的区别：后者处理已建立积极习惯的生长与成果剂量；本 skill 处理旧行为的拆结、终止和替换。
- 疏忽型问题如“总没按时服药”“总不提交报告”本质是缺少想要的行为，应设计新行为，不要把“没做”当作需要终止的动作。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先做安全与问题类型分流**
   - 检查是否涉及严重成瘾、生理依赖或戒断风险、进食障碍、自伤、创伤反应、躁郁症、重度抑郁、精神病性症状、危机状态或其他重度精神健康问题；同时检查是否有医疗、安全、法律或用药风险。
   - 区分“要停止一个已经发生的动作”与“应做动作总没发生”的疏忽型问题。
   - **完成标准**：明确标记为“可做低风险自助试验 / 需要专业支持 / 应转为建立新行为”之一，并说明依据。
   - **判停条件**：命中上述临床、危机、戒断或高风险边界时，立即停止自助戒除设计，转向有资质的医疗、心理、成瘾或危机支持；有迫近危险时优先当地急救或危机服务。

2. **把概括标签拆成具体绳结，并检查功能**
   - 围绕最近实例列出：`在[地点/时点/情绪或事件]，我会[一个可观察动作]，随后得到[即时结果或宽慰]`。同一标签下的不同动作、时点或提示分别列项。
   - 对每一结记录：提示、执行便利性、当时动机、即时收益，以及是否承担悲伤、焦虑、孤独、无聊、疲惫、疼痛或创伤相关的情绪调节功能；不确定就标“未知”，不可猜测。
   - **完成标准**：至少得到 3 个具体绳结，或确认现实中确实只有 1–2 个；每结都能判断发生/未发生，并有“情绪调节：是/否/未知”。
   - **判停条件**：仍只有“拖延、上瘾、不自律”等人格或概括词时不进入干预；情绪功能强、移除后可能恶化或转移时，先安排合适的专业评估或安全支持。

3. **选择易结，并先建立一个积极习惯（阶段 1）**
   - 按“最容易改变、最有把握、情绪负担最低”选择一结，不按危害或羞耻最大者优先。
   - 先设计一个安全、微小、本人愿意做的积极习惯，用来练习明确行为、可靠提示、容易执行和成功反馈。它可以支持易结背后的正当功能，但此时不要求直接替换旧行为。
   - 若旧行为用于情绪调节，优先建立不伤害自己的支持行为，如联系可信赖的人、写下感受或使用专业人员建议的应对方案；不得把通用建议冒充创伤或精神健康治疗。
   - **完成标准**：选定唯一易结；写出一个积极习惯的具体动作、触发时点和最低版本，并在至少一个真实机会中完成或获得可观察数据。
   - **判停条件**：若用户并不想做、现实中做不到或会引发风险，重新匹配；若积极习惯需要临床判断，停下并转专业支持。

4. **建立基线与 fm-01 单变量试验记录**
   - 在改变前记录选中绳结最近可得的发生次数、典型提示、场景和即时后果；定义一个短而足以观察的窗口。
   - 每轮只改变一个变量，使用记录：`基线 → 唯一改动 → 观察机会/时窗 → 结果 → 副作用 → 下一决定`。不得同轮既删提示、又加摩擦、又设置惩罚。
   - **完成标准**：有可比较的基线、唯一自变量、观察指标和失败条件；记录只描述行为与情境，不评价人格。
   - **判停条件**：没有基线或同时改变多个变量时，不得归因；该轮作废或只作探索记录，恢复单变量试验。

5. **先处理提示以终止易结（阶段 2A）**
   - 依次考虑：①移除提示；②无法移除时规避提示；③前两者均不可行时才尝试忽略。优先一次性环境改造，不要求反复克制。
   - 一轮只测试一个提示变化，并记录旧行为频率、冲动强度和是否出现功能迁移。
   - **完成标准**：写明一个具体提示、一个提示改动和结果；若行为降至预设目标且无明显副作用，保留改动并结束该结。
   - **判停条件**：提示改动有效即不继续叠加摩擦或动机措施；移除触发显著痛苦、危险、替代性伤害或临床症状时立即停止并升级支持。

6. **提示无效或不可控时，增加一种能力摩擦（阶段 2B）**
   - 从时间、资金、体力、脑力、日程中只选一环打弱，例如把物品移远、退出账号、取消家庭库存或让旧行为与重要日程冲突。
   - 摩擦应主要作用于旧行为，不能妨碍急救、求助、必要沟通、工作权利或其他安全关键行为。
   - **完成标准**：写出“旧行为 → 所加单一摩擦 → 预计阻断点”，并完成一个观察窗口；达到目标则保留并结束该结。
   - **判停条件**：若成本外溢到安全、健康、财务稳定或他人权益，撤销改动；若无改善，记录结果后才进入下一阶段。

7. **前两类杠杆无效后，最后处理动机并允许有限缩量（阶段 2C）**
   - 只在提示和能力试验均有记录且不足时，测试一个非羞辱性动机变量，如降低旧行为吸引力；不得用惩罚、威胁、公开羞耻或自我厌恶。
   - 若完全停止引发强烈抗拒，可先只改变周期、时长、次数或强度中的一个，作为有限试验；这不是严重成瘾、戒断、进食障碍或自伤的自行减量方案。
   - **完成标准**：有“提示试验结果 + 摩擦试验结果 + 一个动机或缩量变量”的连续记录，并明确保留、撤销或继续观察。
   - **判停条件**：达到该结目标即结束，不为追求完美继续加码；羞耻、反弹、症状加重或风险上升时立即停止并转介。

8. **只有前两阶段无效才替换（阶段 3）**
   - 进入条件必须同时满足：阶段 1 的积极习惯已真实试验；阶段 2 已按提示→能力→动机进行有记录的终止尝试，仍未达到目标。
   - 为同一旧提示生成多个候选新行为，逐个比较：本人是否**比旧行为更想做**、当下是否**比旧行为更容易做**、是否安全地满足旧行为承担的正当功能。
   - 只选同时满足两项比较的替代行为，把旧提示重新映射到它；首轮只改变“提示后的反应”这一个变量。若需要，先在安全情境演练。
   - **完成标准**：有进入阶段 3 的证据；替代行为在“更想做、更容易”两项均有具体依据；至少记录一个真实提示下的选择结果。
   - **判停条件**：候选仅仅“更健康/更正确”但更难或更无趣时不得实施；替换失败则重选、做有限试验，或退回阶段 1，不用意志力硬塞。

9. **一次只推进一个绳结**
   - 每个观察窗口结束后，做出“保留设计 / 撤销 / 换下一个单变量 / 转专业支持 / 该结完成”之一，再决定是否处理下一个易结。
   - 保留已有效的环境设计，但新增试验仍一次只改一个变量；定期检查旧行为是否换了地点、形式或功能。
   - **完成标准**：每一结都有完整记录与明确决定；只有当前结达到目标或被正式转介后，才开启下一结。
   - **判停条件**：目标已达到、收益不再值得成本、证据无法区分变量、出现功能迁移或风险上升时停止扩展；重新评估，而不是同时围攻整条“坏习惯”绳索。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **严重成瘾或戒断风险**：药物、酒精及其他可能存在生理依赖或医学戒断风险的行为，必须由专业人员评估；本 skill 不可作为独立戒瘾或减量治疗。
- **进食障碍、自伤、创伤及重度精神健康问题**：包括躁郁症、重度抑郁、精神病性症状或危机状态，不得用提示、摩擦、缩量或替换充当自助治疗。
- **疏忽型问题**：迟到、漏服必要药物、没提交报告等若核心是“该做的动作没发生”，应设计想要的新行为；不得把必要行为本身当成坏习惯停止。
- **安全、医疗和法律标准**：不能用“先少做一点”降低必需剂量、操作标准、保护措施或法定义务。
- **结构性或社会性原因占主导**：贫困、轮班、照护负担、歧视、平台成瘾式设计或他人持续制造提示时，应同步处理资源、制度与社会环境，不能只要求个人自控。
- **替他人秘密设计**：未经同意，不得用隐藏提示、摩擦、奖惩或羞耻操控他人，尤其在亲子、雇佣和医疗等权力不对等关系中。

### 作者在书中警告的失败模式

- **猛然打破**：把改变写成“从今天起永远不再”，没有拆出具体绳结，也没有重构旧条件。
- **直接处理概括标签**：给“拖延、吃垃圾食品、刷手机”画一张统一诊断图，混合了不同提示与功能。
- **最难结优先**：一开始就攻最痛、最深或最强迫的一结，失败后强化羞耻和无力感。
- **靠忽略提示**：保留高频诱因，要求自己每次都拒绝，实质上仍依赖波动的意志力。
- **先调动机**：用危害材料、恐惧、惩罚或羞耻压低欲望，却不先处理提示和便利路径。
- **过早替换**：尚未建立积极习惯、也未尝试直接终止，就给每个旧行为硬配一个“好行为”。
- **替代品更难、更无趣**：只因“有益”就选替代行为；旧提示出现时，它无法与旧行为竞争。
- **忽略情绪功能**：拿走带来宽慰的行为，却不处理悲伤、焦虑、孤独或疲惫，导致复发或功能迁移。

### 作者的盲点 / 证据局限

- 本书关于坏习惯的效果证据主要来自作者、学员与训练营参与者自述，缺少充分对照、效应量与长期随访；此流程应作为低风险假设生成器，不是通用治疗定律。
- “提示→能力→动机”是实用的默认顺序，不是所有问题的绝对规律；临床症状、疼痛、创伤、强迫、生理依赖或结构性约束可能改变优先级，并要求专业处置。
- 现代平台可通过推荐系统、无限滚动、跨设备通知和社交关系持续恢复提示。个人增加一点摩擦可能不足，平台治理、家庭/组织边界或外部支持可能更关键。
- 书中成功案例较少呈现长期复发者和失败者；单次成功不能证明绳结永久消失，应保留复发与功能迁移监测。

### 容易混淆的邻近方法论

- **拆结不等于 MAP 诊断**：拆结先确定分析单位；每个具体结之后才可单独诊断提示、能力和动机。
- **积极习惯不等于替代习惯**：阶段 1 的积极习惯用于练技能、建信心或安全支持功能；只有前两阶段不足后，才把同一旧提示映射到替代行为。
- **缩量不等于治疗性减害**：普通低风险行为可试验减少周期、时长、次数或强度；临床、成瘾和戒断问题必须由专业人员决定。
- **一次只改一个变量不等于永远只用一个杠杆**：可按证据逐轮更换或累积已验证设计，但每一轮必须能判断新增变量的作用。
