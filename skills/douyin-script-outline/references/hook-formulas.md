# 开头钩子公式与示例

开头第一句是唯一要逐字写定的部分，决定 2 秒跳出率。目标：**12 字左右、具体、与“我”有关**。
下面给可直接套用的公式和好坏对比，按主题类型选用。

## 公式

1. **痛点反问式**：一个具体难受的场景 + 反问
   - 结构：「[具体场景] + ？」
   - 例：学新东西一卡壳就烦？ / 看书 5 分钟就走神？
2. **反常识结论式**：先抛一个和直觉相反的结论
   - 结构：「你以为 X，其实 Y」
   - 例：练得越久，反而进步越慢？
3. **普通人 vs 高手对比式**（常用在第二句承接）
   - 结构：「普通人还在……，高手早就……」
   - 例：普通人还在等大块时间，高手早就粗糙地开始偷跑了。
4. **具体数字 / 悬念式**（适合活动、挑战类）
   - 例：我用 28 天，帮 30 个人养成读书习惯。

## 好 vs 坏对比

| 类型 | 坏（宽泛/铺垫/安抚） | 好（具体/与我有关） |
|---|---|---|
| 学习方法 | 学习是有方法的，今天聊聊怎么学 | 天天练习，进步还是不快？ |
| 习惯养成 | 习惯很重要，大家要重视 | 计划很好，就是动不起来？ |
| 行动拖延 | 先别灰心，这不是你的问题 | 知道却做不到？高手早就偷跑了 |
| 转型类 | 普通人转型做自媒体最先抓什么 | （此类受众窄，慎选） |

## 要避免的开头

- **寒暄/自我介绍**：「大家好，我是 XXX，今天……」
- **安抚废话**：「先别灰心」「这不是你的问题」「也不是你不够自律」——这些可以放在中段，
  不能占用前 2 秒。
- **铺垫背景**：先讲“想法来源”“为什么要做”，再进入正题。
- **大而虚**：只说“学习/成长/努力很重要”，没有具体场景。

## 自检三条

- 观众刷到第一句，能不能立刻对号入座“说的就是我”？
- 12 字内能不能读完？拖了两三句就是铺垫。
- 第二句有没有立刻给“新东西”（高手做法 / 反常识 / 超预期）？
