# 前5秒钩子库（知识/读书/成长干货）

前5秒逐字，决定 2s 跳出和 5s 完播。固定两段：**第1句痛点（12字）→ 第2句结论+预告**，
核心结论最迟第5秒出现。第1句从下面 A/B/C/D 里挑，第2句用“第2句公式”配。

## 怎么选第1句（按内容对号入座）

| 本条讲的是 | 优先用哪类 |
|---|---|
| 解决一个具体困扰/坏习惯 | A 痛点反问 |
| 纠正一个常见误区、认知升级 | B 反常识结论（干货最常用） |
| 讲高手和普通人的做法差异 | C 高手对比（也可作第2句） |
| 有真实使用场景（通勤、早起、深夜） | D 场景代入 |

## A. 痛点反问（具体困扰）

- 结构：「[具体难受场景] + ？」
- 学新东西一卡壳就烦？ / 看书 5 分钟就走神？
- 计划很好，就是动不起来？ / 想读书，却三天打鱼两天晒网？

## B. 反常识结论（干货最常用，重点）

- 你以为 X，其实 Y：你以为读书要整块时间？其实一句就能开始。
- 我花了 X 才明白，其实根本不用……：我读了十几本才明白，读书根本不用追求记住。
- 99% 的人都搞错了（略标题党，用了第2句必须立刻上干货）：99% 的人读书都做错了——光读，不用。
- 做了 X，我发现一件反常识的事：我坚持读书大半年发现，读得越少反而记得越牢。

## C. 高手对比（讲方法差异，常作第2句）

- 结构：普通人还在……，高手早就……
- 普通人还在等大块时间，高手早就粗糙地开始偷跑了。

## D. 场景代入（有真实场景时）

- 早上六点，我已经在地铁上听完半本书了。
- 注意：场景后立刻接“我在做什么/学到什么”，不要停在写景。

## 第2句公式：结论 + 预告（不许只给悬念）

- 结构：反常识结论/高手做法 + 这条讲几点
- 例：其实不用逼自己。我一年读17本，靠的不是意志力，是2个习惯设计。
- 区分：成绩（“读17本”）要紧跟结论当佐证，不能抛在结论前面吊胃口。

## 好 vs 坏

| 类型 | 坏（铺垫/背书/悬念） | 好（具体/结论前置） |
|---|---|---|
| 学习方法 | 学习是有方法的，今天聊聊 | 天天练习，进步还是不快？ |
| 习惯养成 | 习惯很重要，大家要重视 | 计划很好，就是动不起来？ |
| 行动拖延 | 先别灰心，这不是你的问题 | 知道却做不到？高手早就偷跑 |
| **背书/悬念** | 我读了17本，收获最大的不是知识……（答案拖到第8秒） | 不用逼自己。我读17本，靠的是2个习惯设计 |

## 前5秒不要用

- **自我背书/晒成绩开场**：我读了X本、我做了X年——结论之后（第5秒起）再用它做信任背书。
- **只吊胃口不给答案**：我最大的收获不是……（停顿）；核心结论必须第5秒前给出。
- **卖关子/爆秘密**（“有件事我一直没敢拍”）、**自我情绪开场**（“今天我最崩溃”）。
- 寒暄、自我介绍、安抚铺垫（“先别灰心”）、大而虚的话。

## 自检

- 第1句刷到，能不能立刻对号入座“说的就是我”？
- 第5秒前，观众拿到明确结论了吗？核心结论在第几秒？
- 第2句是“给答案+预告”，还是“继续吊胃口”？
