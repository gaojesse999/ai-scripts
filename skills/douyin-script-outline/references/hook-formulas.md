# 开头钩子库（知识/读书/成长干货）

开头第一句是唯一要逐字写定的部分，决定 2 秒跳出率。目标：**12 字左右、具体、与“我”有关**。
下面是按“内容类型”整理的钩子库。生成框架时，**根据本条主题从库里挑最合适的 2-3 个，
都改写成能直接念的句子，供用户选其一，并标注最推荐**。

## 怎么选（按内容对号入座）

| 本条讲的是 | 优先用哪类钩子 |
|---|---|
| 解决一个具体困扰/坏习惯 | A 痛点反问 |
| 纠正一个常见误区、认知升级 | B 反常识结论（干货最常用） |
| 讲高手和普通人的做法差异 | C 高手对比 |
| 有真实使用场景（通勤、早起、深夜） | D 场景代入 |

## A. 痛点反问（具体困扰）

- 结构：「[具体难受场景] + ？」
- 学新东西一卡壳就烦？
- 看书 5 分钟就走神？
- 计划很好，就是动不起来？
- 想读书，却三天打鱼两天晒网？

## B. 反常识结论（干货最常用，重点）

- 你以为 X，其实 Y
  - 你以为读书靠硬记？其实读完“用”一下才记得住。
  - 你以为读书要整块时间？我通勤路上就听完了一本。
- 我花了 X 才明白，其实根本不用……
  - 我读了十几本书才明白，读书根本不用追求记住。
- 99% 的人都搞错了一件事（略标题党，用了第二句必须立刻上干货）
  - 99% 的人读书都做错了——光读，不用。
- 做了 X，我发现一件反常识的事
  - 我坚持读书大半年发现：读得越少，反而记得越牢（说精读）。

## C. 高手对比（讲方法差异，常作第二句）

- 普通人还在……，高手早就……
- 普通人还在等大块时间，高手早就粗糙地开始偷跑了。

## D. 场景代入（有真实场景时）

- 早上六点，我已经在地铁上听完半本书了。
- 现在是深夜，我还在复盘今天读的内容。
- 注意：场景后要立刻接“我在做什么/学到什么”，不要停在写景。

## 好 vs 坏

| 坏（宽泛/铺垫/安抚） | 好（具体/与我有关） |
|---|---|
| 学习是有方法的，今天聊聊怎么学 | 天天练习，进步还是不快？ |
| 习惯很重要，大家要重视 | 计划很好，就是动不起来？ |
| 先别灰心，这不是你的问题 | 知道却做不到？高手早就偷跑了 |

## 不要用于干货的钩子

- **卖关子/爆秘密**（“有件事我一直没敢拍”）：干货没有秘密，会显得标题党。
- **自我情绪开场**（“今天我最崩溃的一天/我到现在没缓过来”）：观众不认识你，与我无关。
- 寒暄、自我介绍、安抚铺垫（“先别灰心”）、大而虚的话。

## 自检

- 第一句能不能让观众立刻对号入座“说的就是我”？
- 12 字左右、不拖两三句？
- 第二句有没有立刻给“新东西”（反常识 / 高手做法 / 具体动作）？
