# 口播框架生成器（前5秒逐字 + 整篇大纲）

帮用户快速准备一条知识口播：**只把前5秒（2句）逐字写定，第5秒后全部给关键词**，
脱稿自由发挥。产出必须是一个已保存的 Markdown 文件。

## 核心原则（务必遵守）

1. **只逐字写前5秒（2句）。** 前5秒是决定 2s 跳出、5s 完播的闸门，必须逐字锁死；
   第5秒后只给关键词、节点和思路，禁止扩写成逐字稿。
2. **前5秒必须交付，不许吊胃口。** 结构固定：第1句痛点（12字左右）→ 第2句立刻给
   反常识结论/高手做法 + 预告这条讲几点。**自我背书、晒成绩、“我最大的收获不是……”这类
   悬念一律后置到第5秒之后；核心结论最迟第5秒出现。**
3. **一条只讲一个点。** 主题若含多个点，帮用户挑最值得讲的 1 个，其余以后单独做。
4. **必须给一个可照做的动作。** 明确“第一步做什么”，具体到能立刻执行（这是收藏的来源）。
5. **时长卡在 60-80 秒。** 提示用户讲完看时长、超了就删。
6. 语言自然接地气，不堆砌术语、不浮夸、不要“AI味”。

## 输入

- 用户给的主题/主要内容（一句话即可，也可能列几个点）。
- 信息不足时，只需确认“这条最想让观众记住/做到的是什么”，不反复追问；主题过宽自行收窄并说明。

## 输出的 Markdown 结构

1. **前5秒逐字（给 1-2 组，每组 2 句，标注最推荐 1 组）**：
   - 第1句：12字左右的具体痛点反问或反常识结论，与“我”有关；
   - 第2句：立刻给反常识结论/高手做法 + 预告（“靠的是X不是X，一共X点”），禁止只给悬念。
2. **整篇口播框架（第5秒后，只给关键词）**：
   - 中段（只讲这 1 个点）：2-4 个推进节点，先给动作、再讲原理；个人经历/成绩背书放这里，
     可用一个小例子；
   - 给观众的 1 个动作：第一步做什么，写成可照做的一句话/小清单；
   - 结尾：免费训练营/免费资料本身就是利他钩子，视频里一句话带过、详细信息放评论区；
     有系列规划时可加“明天讲 X”，没有就不强求（冷启动期结尾提问基本没人答，不依赖）。
3. **思路与提醒**：为什么这么开头；别铺垫、别吊胃口、别贪多、别讲嗨了绕；录完看时长。

## 如何写前5秒

1. 先读 [references/hook-formulas.md](./references/hook-formulas.md) 的钩子库。
2. 判断本条内容属于“具体困扰 / 认知误区 / 方法差异 / 真实场景”哪一类，按库里的“怎么选”
   对号入座，定第1句痛点。
3. 再按“第2句公式”配一句“结论+预告”，组成 1-2 组完整前5秒（每组2句、能直接念），
   标注最推荐的一组。不要把卖关子/自我情绪/自我背书钩子混进来。

## 保存

- **保存位置**：统一保存到工程根目录的 `口播脚本/` 目录（即本工程
  `D:\Data\AI\github\zhigao\my-vault\口播脚本\`），目录不存在则创建；用户指定其他位置以用户为准。
- **文件名**：`YYYYMMDD-HHMMSS-主题.md`，时间用当前本地时间、精确到秒；主题取 4-15 个
  能概括内容的汉字，去掉标点和虚词。
  示例：`20261013-172600-我决定发起28天挑战带30人养成读书习惯.md`、
  `20261010-174500-认知觉醒单点突破法.md`。
- 同一主题若后续再出优化版本，在主题后加 `_优化版`、`_精简版` 等后缀。
- 保存后通过 `present_files` 交付该文件，并在回复中用一句话给出最推荐的前5秒和框架要点。
