# 口播框架与逐字稿生成器（速查提纲 + 前5秒逐字 + 完整逐字稿）

帮用户快速准备一条高完播率的抖音知识口播：**以「一屏速查提纲」为主体便于脱稿发挥，以「完整参考逐字稿」为底稿便于对标录制**。产出必须是一个已保存的 Markdown 文件。

---

## 核心原则（务必遵守）

1. **【最高优先级】前 5 秒黄金钩子必须是「反直觉 / 反常识」（打破认知惯性）**：
   - **第一性原理**：单有痛点只是及格线，**“反直觉、反常识”才是让用户大拇指瞬间急刹车的核武器**！短视频信息流中，大众只会被“颠覆既有认知、打破生活常识、行为与预期产生强烈冲突”的内容瞬间抓住（脑科学上的“认知失调停顿”）。
   - **4 种高杀伤力「反直觉 / 反常识」范式（核心武器库）**：
     1. **反直觉现象（行为与结果强烈背离）**：
        - “躺平歇了一整天，为什么比上班还累？”（常识以为躺着回血，事实却反向漏电）
        - “为什么天天拼命读书，反而越读越焦虑、越读越记不住？”（越努力越没结果的反直觉）
     2. **反常识归因（彻底推翻大众本能归因，摘掉自责标签）**：
        - “买回来的书全在落灰？根本不是你意志力差，而是你把书放错了位置！”（常识怪意志力不行，真相是环境开关）
        - “学东西一卡壳就烦躁？别瞎怪自己记性差，是你少了‘他人视角’！”（推翻智力/自律自责）
     3. **反常识禁令 / 解法（禁止做大众以为该做的事）**：
        - “想养成读书习惯？第一步千万别急着逼自己读完整本！”（常识以为要硬啃读完，真相是先只翻开一页）
        - “读完整本书转头就忘？别再逼自己做工整的思维导图了，那叫假勤奋！”（常识以为做笔记有用，真相是伪努力）
     4. **反直觉反讽 / 扎心（撕开假象）**：
        - “天天准时打卡，其实是在自欺欺人做无效假打卡！”
   - **前 2 秒必须是受众正在真切难受的“具体病症/场景画面”（患者视角）**：
     - **生动范例（仅供参考启发，绝非唯一限制）**：
       - 记忆/吸收痛：“读完整本书，转头全忘光？”、“学了总记不住？”
       - 情绪/卡壳痛：“学东西一卡壳，心里就烦躁内耗？”
       - 习惯/行动痛：“买回来的书，全在角落吃灰？”、“翻开两页就开始犯困？”
       - 精力/状态痛：“在家瘫了一整天，为什么比上班还累？”、“计划列得满满当当，一天下来一件没动？”
     - **严禁使用“高深术语、学术理论、正确大道理”开场（一票否决）**：
       - ❌ 严禁用说教建议开场（如“一定要在舒适区边缘读书”——这是学术建议不是患者病症，观众第一反应是“你在教我做事”）；
       - ❌ 严禁用教科书式平淡设问（如“为什么刷手机很累”——像科普答疑，缺乏反常识反差）；
       - ❌ 严禁直接抛出学术概念（如“注意力分为行动与感受”——认知负荷过重直接赶人）。
   - **严禁剧透抽象概念/专有名词**：第 2 句给出结论时，**严禁直接抛出“靠的是情绪专注/心流”这类生硬学术名词**；必须转化为**痛点利益点 + 极简动作预告**（如“一招三分钟帮你找回精力”），专业概念一律后置到中段揭秘。
   - **严禁前 5 秒塞入书名/机构名**：严禁前 5 秒出现《XXX》书名；书名统一在 15-20 秒作为权威解法背书引出！
   - **5秒内必须给答案与预告**：第 1 句反常识病症痛点（12-20字）→ 第 2 句立刻给反常识结论/神比喻 + 预告讲几步。禁止只吊胃口不给答案。
2. **时长严格卡死 60-75 秒，一条绝对只打透一个单点（防时长拖垮完播率）**：
   - **纯汉字数严格锁定在 300-350 字**（按口播语速 4.2~4.5 字/秒计算，总时长牢牢控制在 60-75 秒最佳完播区间，严禁超过 80 秒）。
   - **一条只讲一个单点，严禁一篇塞两个对等大概念**（吸取“讲了降维又塞升维”导致时长膨胀到 137 秒、把 8 秒高留存好内容彻底拖垮的惨痛教训）：
     - 若主题包含“降维”和“升维”，只选最痛的“降维”配一个具体案例讲透；
     - 另一个概念宁可拆成下集，也绝不贪多塞在同一条视频里，确保全片时长紧凑、完播率最大化。
3. **双重交付，分层展示（框架优先，内容集中）**：
   - **交付条件包含两部分**：【一屏速查提纲】与【完整参考逐字稿】。
   - **优先集中展示框架与前 5 秒**：呈现时务必**紧凑精炼、集中在一页内展示完毕**，防止篇幅过散、翻屏繁琐，让创作者一眼看清逻辑骨架、脱稿即录；
   - **随后进一步展示完整逐字稿**：严禁添加机械的【停顿】字样（严重干扰提词器与朗读视线，自然停顿通过标点与分行体现），保持纯净流畅，供用户对标语速或直接录入提词器。
4. **必须给一个可照做的微动作**：明确“今晚/明天第一步做什么”，门槛低到 3-5 分钟能做完（这是完播后促成点赞、收藏的核心动力）。微动作优先设计为**物理动作**（撕便签写3件事、把书摊在沙发扶手翻开一页），具象可感，杜绝虚无缥缈的心性体悟。
5. **语言自然接地气**：大白话、口语化，善用生活化神比喻（如“手机开满后台”），坚决去“AI味”和书面腔。
6. **前后逻辑主体必须严密一致（严禁前宽后窄、偷换概念）**：前 5 秒预告的解法主体，必须与中段交付的具体动作完全一致。若中段交付的是“读书中的 2 个动作”，前 5 秒就必须明确亮出“真正回血的不是躺平，而是去读 5 分钟书”这一反直觉解法，确保通篇逻辑严丝合缝、一气呵成。

- 信息不足时，只需确认“这条最想让观众记住/做到的是什么”，不反复追问；主题过宽自行收窄并说明。

## 交付前自检清单（门禁规则）

在向用户输出回复与保存文件前，**必须在模型思考阶段（Thinking）完成以下 3 项核验**：

- [ ] **【最高优先级】反直觉/反常识核验（一票否决项）**：第 1 句是否具备颠覆常识的认知冲突（行为与结果强烈背离、推翻大众自责归因、或反常识禁令）？如果只是一句顺理成章的大道理或平淡提问，**一律直接打回重写**，直至改出强反差！
- [ ] **病症与患者视角核验**：第 1 句是否说中了观众正在真切难受的具体病症画面？是否彻底剔除了学术名词与说教语气？
- [ ] **结论交付核验**：核心答案（如“大脑后台疯狂漏电”）最迟在第 5 秒说出来了吗？第 2 句是否给出了清晰步骤预告？
- [ ] **版面与时长核验**：纯汉字数是否严格控制在 300-350 字（60-75 秒）？是否做到了“一条只打透一个单点案例”（严禁塞两个概念导致时长超标）？速查提纲是否做到高度精炼、一屏尽览？

## 输出的 Markdown 文件结构规范

生成的文件按以下 4 部分组织，并统一保存到工程根目录的 `口播脚本/` 目录：

### 1. 【速查卡片】开头前 5 秒与提纲抽取（置顶 · 集中紧凑 · 一屏看全）
- **开头前 5 秒逐字**（0-2s 痛点反差 + 2-5s 结论与预告，标注语气与表情动作）；
- **整篇 4 步推进提纲**（ASCII 流程图或紧凑清单：痛点破题 → 漏电/痛点归因 → 核心方法与动作 → 极小微动作与收尾）。

### 2. 【完整口播逐字稿】（纯净提词版）
- 按时间轴分段（`[00:00 - 00:05]`、`[00:05 - 00:20]`、`[00:20 - 00:50]`、`[00:50 - 00:75]`）；
- 严禁加入机械的 `[停顿]` 标签，停顿完全依靠逗号、句号及短句分行自然实现；
- 统计纯汉字数（严格保持在 300-350 字之间，对应 60-75 秒黄金时长）。

### 3. 【画面与机位包装指南】
- 机位与头顶留白规范（中景，头顶留白 15%-20% 防止大头怼脸）；
- 前 3 秒顶部固定大标题卡建议；
- 关键时刻动态花字提示。

### 4. 【配套发布建议】
- 爆款发布标题建议；
- 热门话题标签（Tag）；
- 封面主副标题；
- 评论区置顶破冰/引流话术（作者抢沙发引导互动）。
