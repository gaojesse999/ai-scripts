# 口播框架与逐字稿生成器（速查提纲 + 前5秒逐字 + 完整逐字稿）

帮用户快速准备一条高完播率的抖音知识口播：**以「一屏速查提纲」为主体便于脱稿发挥，以「完整参考逐字稿」为底稿便于对标录制**。产出必须是一个已保存的 Markdown 文件。

---

## 核心原则（务必遵守）

1. **初稿完成后，交付前必须严格确认前 5 秒是否足够吸引人**：
   - **拒绝温吞说教**：严禁使用“身体在做事脑子在想别的”“学习是有方法的”这类平铺直叙、大家习以为常的温和废话。
   - **引爆好奇心三要素**：必须具备**强反差（反直觉现象）**、**扎心刺痛（隐形代价具象化，如“后台疯狂漏电”）**或**现场抓包（抓现行动作）**。
   - **严禁剧透抽象概念/专有名词**：第 2 句给出结论时，**严禁直接抛出“靠的是情绪专注/心流”这类生硬学术名词**（观众听到术语会误以为“又是大道理”而失去好奇滑走）；必须转化为**痛点利益点 + 极简动作预告**（如“真正给大脑快速回血，就靠这 2 个动作”），专业概念一律后置到中段揭秘。
   - **严禁前 5 秒塞入书名/机构名**：严禁前 5 秒出现《XXX》书名（如“读完《认知觉醒》我才明白”自带极强的推销感与信息摩擦，极易触发用户划走防备）；书名统一在 15-20 秒作为权威解法背书引出！
   - **5秒内必须给答案与预告**：第 1 句痛点反差（12-20字）→ 第 2 句立刻给反常识结论/神比喻 + 预告讲几步。禁止只吊胃口不给答案。
2. **双重交付，分层展示（框架优先，内容集中）**：
   - **交付条件包含两部分**：【一屏速查提纲】与【完整参考逐字稿】。
   - **优先集中展示框架与前 5 秒**：呈现时务必**紧凑精炼、集中在一页内展示完毕**，防止篇幅过散、翻屏繁琐，让创作者一眼看清逻辑骨架、脱稿即录；
   - **随后进一步展示完整逐字稿**：严禁添加机械的【停顿】字样（严重干扰提词器与朗读视线，自然停顿通过标点与分行体现），保持纯净流畅，供用户对标语速或直接录入提词器。
3. **一条只讲一个点**：主题若含多个点，帮用户挑最痛、最反常识的 1 个点打透，其余以后单独做。
4. **必须给一个可照做的微动作**：明确“今晚/明天第一步做什么”，门槛低到 3-5 分钟能做完（这是完播后促成点赞、收藏的核心动力）。
5. **时长严格卡在 60-80 秒**：纯汉字控制在 300-380 字（按 4.2~4.5 字/秒计算）。超时优先压缩原理解释，保留核心比喻与动作。
6. **语言自然接地气**：大白话、口语化，善用生活化神比喻（如“手机开满后台”），坚决去“AI味”和书面腔。
7. **前后逻辑主体必须严密一致（严禁前宽后窄、偷换概念）**：前 5 秒预告的解法主体，必须与中段交付的具体动作完全一致。若中段交付的是“读书中的 2 个动作”，前 5 秒就必须明确亮出“真正回血的不是躺平，而是去读 5 分钟书”这一反直觉解法，让观众的好奇心精准聚焦在“为什么读书能回血、怎么读”上，绝不能前头说一套通用解法、后面突然拐弯变成另一个具体场景，确保通篇逻辑严丝合缝、一气呵成。

## 输入

- 用户给的主题/主要内容（一句话即可，也可能列几个点）。
- 信息不足时，只需确认“这条最想让观众记住/做到的是什么”，不反复追问；主题过宽自行收窄并说明。

## 交付前自检清单（门禁规则）

在向用户输出回复与保存文件前，**必须在模型思考阶段（Thinking）完成以下 3 项核验**：

- [ ] **好奇心与吸引力核验**：第 1 句能不能让刷到的人瞬间停下大拇指？有没有反常识反差（如“躺平为什么比上班还累”）？是不是一针见血？如果偏平淡，必须立即升级为高反差扎心款或颠覆认知款。
- [ ] **结论交付核验**：核心答案（如“大脑后台疯狂漏电”）最迟在第 5 秒说出来了吗？第 2 句是否给出了清晰步骤预告？
- [ ] **版面集中度核验**：速查提纲是否做到高度精炼、一屏尽览？逐字稿是否字数适中、纯净流畅（无冗余的机械停顿标注）？

## 输出的 Markdown 文件结构规范

生成的文件按以下 4 部分组织，并统一保存到工程根目录的 `口播脚本/` 目录：

### 1. 【速查卡片】开头前 5 秒与提纲抽取（置顶 · 集中紧凑 · 一屏看全）
- **开头前 5 秒逐字**（0-2s 痛点反差 + 2-5s 结论与预告，标注语气与表情动作）；
- **整篇 4 步推进提纲**（ASCII 流程图或紧凑清单：痛点破题 → 漏电/痛点归因 → 核心方法与动作 → 极小微动作与收尾）。

### 2. 【完整口播逐字稿】（纯净提词版）
- 按时间轴分段（`[00:00 - 00:05]`、`[00:05 - 00:20]`、`[00:20 - 00:50]`、`[00:50 - 00:75]`）；
- 严禁加入机械的 `[停顿]` 标签，停顿完全依靠逗号、句号及短句分行自然实现；
- 统计纯汉字数（严格保持在 300-380 字之间）。

### 3. 【画面与机位包装指南】
- 机位与头顶留白规范（中景，头顶留白 15%-20% 防止大头怼脸）；
- 前 3 秒顶部固定大标题卡建议；
- 关键时刻动态花字提示。

### 4. 【配套发布建议】
- 爆款发布标题建议；
- 热门话题标签（Tag）；
- 封面主副标题；
- 评论区置顶破冰/引流话术（作者抢沙发引导互动）。
