# Knowledge Video Builder v2

This package updates the original `knowledge-video-builder` Skill with the state-driven Knowledge Motion Engine validated through the grill-me demo iterations.

## Main changes

- audio-first semantic timing
- Scene → State → Attention → Motion architecture
- progressive accumulation and persistent context
- premium editorial controls instead of dashboard-heavy UI
- typography/antialiasing rules
- direct end-to-end mode
- universal 1080p delivery settings

Install or replace the existing Skill with `SKILL.md`; keep the `reference/`, `templates/`, and `examples/` folders beside it.
