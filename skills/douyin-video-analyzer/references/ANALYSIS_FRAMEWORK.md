# 三层归因分析框架

报告的分析部分必须回答用户最关心的问题：**每条视频为什么表现好 / 为什么不好？
下一周期怎么改？** 用“数据层 → 脚本层 → 视觉层”的顺序做归因，先定位现象、再解释根因、
最后给可执行动作。

## 基本原则

1. **先证据后结论**：每个判断都要能落到具体作品 + 具体数字 + 具体脚本句子/具体帧。
   不写“开头不够吸引人”这类空话，要写“第 1 条前 2 秒在做自我介绍（脚本第 1-2 句），
   2s 跳出 48.6%，而第 3 条直接抛痛点反问，2s 跳出 41.4%”。
2. **横向对照**：单条数字放在同周期多条里看，找赢家与输家的**结构差异**，而非孤立评价。
3. **区分事实与推断**：播放/完播/互动是事实；“可能因为钩子太绕”是推断，要用脚本/帧佐证。
4. **冷启动校准**：小样本、熟人流量的干扰先剥离（见 METRICS_BENCHMARK.md）。
5. **行动导向**：每条根因都要能转成“改哪里、怎么改、预期影响哪个指标”。
6. 语言自然接地气，不堆砌术语、不夸张、不写“AI 味”套话。

---

## 数据层：漏斗定位（先判断问题出在哪一环）

按用户观看路径逐环看，找到**第一个明显恶化的环节**：

```
曝光/封面点击 → 2s 留存（1-2s跳出）→ 5s 留存（5s完播）→ 完播/平均播放时长
   → 点赞/收藏/转发/评论 → 主页访问 → 涨粉
```

- **封面点击率低/无**：冷启动阶段很多流量来自关注页/推荐，封面权重小，先不主攻。
- **2s 跳出高**：开头钩子问题（脚本层 0-2s + 视觉层前 3 秒花字）。
- **5s 完播低但 2s 跳出正常**：钩子没接住（2-5s 承接无信息增量）。
- **5s 尚可但完播/平均播放时长低**：中段拖沓、单点没讲透、时长过长。
- **完播尚可但互动低**：讲清了但没给“认同点/可收藏动作/转发理由”。
- **有点赞无收藏**：有共鸣但“没用”，缺可照做的交付。
- **有主页访问无涨粉**：结尾关注钩子不够利他。
- **一条数据独高**：检查是否熟人转发、话题蹭量、是否有可复用的结构，别轻易归因于运气。

读 `_数据底稿.md` 的三张表：先看每日趋势与发布节奏，再看作品明细横向排序。

## 脚本层：对照脚本逐句找症结

对每条作品，打开骨架里自动填入的**口播脚本原文**，按四段检查：

1. **0-2 秒钩子**：是不是 12 字内的痛点反问/反常识结论？还是寒暄、自我介绍、铺垫？
   - 对应 2s 跳出率。
2. **2-5 秒承接**：有没有立刻给“反常识 / 高手怎么做 / 超预期收益”？信息密度够不够？
   - 注意识别一种隐蔽死因：**自我背书/晒成绩 + 悬念**（“我读了17本，最大的收获不是……”），
     它没解释背景、却没给答案，观众照样划走。
   - 对应 5s 完播率。
3. **中段结构**：是否一条只讲透一个点？有没有案例、动作、步骤？哪里开始重复/绕？
   - 对应完播率、平均播放时长、收藏。
4. **结尾 CTA**：是“求关注”还是“给明天继续看的理由”（利他钩子）？
   - 对应主页访问、涨粉。

同时做“**跨作品脚本对比**”：
- 赢家的开头句式、选题角度、交付动作是什么？
- 输家的开头在干什么？是否选题过宽/过虚/与我无关？
- 提炼出可复用的“本账号赢家公式”和要避免的“输家套路”。

## 视觉层：逐张看关键帧

用 `frames/<作品>/` 下 9 张帧（0.5/1.5/2.5/3.5/5 秒 + 25%/50%/75%/90%）：

- **前 5 秒帧**：头顶是否有固定大标题花字？第一帧表情/口型是否有张力？画面是否“一眼知道在讲什么”？
- **中段帧**：是否出现示范动作、手势、道具、图文辅助？信息是否可被截图？
- **结尾帧**：是否有引导关注的画面或字幕？
- **一致性**：着装、背景、帽子/道具是否形成稳定识别；同一套视觉是否在各条统一。

把视觉结论与数据对应：例如“前 3 秒无花字的条 2s 跳出普遍更高”。

---

## 逐条作品诊断模板（骨架已留好占位，按此填写）

```
- 数据层：漏斗第一个恶化环 = __，证据（与赢家/基准对比）= __
- 脚本层：
  - 0-2s：__（引用脚本原句）
  - 2-5s：__
  - 中段：__（单点是否讲透 / 动作是否可照做）
  - 结尾：__
- 视觉层：花字/表情/动作/着装 = __
- 一句话结论：在【选题/钩子/结构/动作/视觉/时长】里锁定主因。
```

一句话结论要**单点击穿**：一条视频通常只有一个最主要的问题，不要面面俱到。

## 跨作品归纳与迭代方案

1. 逐条诊断后，归纳**本周期 3 条以内的共性规律**（例如“赢家都在 2 秒内抛出与我相关的
   痛点，输家都在铺垫”）。
2. 迭代方案表（P0/P1/P2）每条写清：
   - **改哪里**（开头/中段/结尾/视觉/时长/选题）
   - **怎么改**（具体到句式、花字、动作、时长，最好给可直接套用的示例）
   - **预期影响哪个指标**（2s 跳出 / 5s 完播 / 收藏 / 涨粉）
3. 给出下一周期 **3-5 个选题方向**，每个配一句 12 字黄金开头（延续赢家公式）。
4. 节奏建议：基于断更日/一天多条的表现，给明确的发布节奏（如保持日更、固定时段）。

## 常见“现象 → 根因 → 动作”速查

| 现象 | 高频根因 | 优先动作 |
|---|---|---|
| 2s 跳出普遍偏高 | 开头寒暄/铺垫、无花字、痛点不具体 | 改成 12 字痛点反问 + 前 3 秒大标题 |
| 5s 完播上不去 | 没信息增量、还在解释背景，或自我背书/晒成绩吊胃口 | 2-5s 直接给反常识/高手做法，结论前置 |
| 完播塌、平均播放短 | 时长过长、一个视频讲多个点、中段绕 | 砍到 60-80s、单点讲透 |
| 有赞无藏 | 有共鸣但没有可执行步骤 | 设计一个可照做的小动作/清单 |
| 有播放无涨粉 | 结尾“求关注”、没给持续价值 | 改利他型 CTA（预告明天解决什么） |
| 一条独高 | 熟人转发/话题蹭量/真有好结构 | 核实来源；若是好结构，抽象成公式复用 |
