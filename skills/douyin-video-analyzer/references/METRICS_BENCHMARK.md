# 指标基准与冷启动校准

基准来自本账号口播脚本方法论（douyin-script-writer，已被数据验证）与历史复盘经验。
它们是**判断方向的参考线，不是及格线**：冷启动期、不同题材会有系统性偏移，要结合
同周期作品做横向对照，避免单条孤立下结论。

## 核心漏斗指标目标

| 指标 | 目标/参考 | 作用 | 异常指向 |
|---|---|---|---|
| 2 秒跳出率 | **< 40%** | 开头钩子是否抓人 | 高 → 0-2s 痛点不清、开头铺垫、花字/标题卡缺失 |
| 5 秒完播率 | **> 25%-30%（破局核心）** | 钩子承接是否成立 | 低 → 2-5s 没有反常识/高手偷跑/超预期收益 |
| 整体完播率 | **> 1%** | 全片结构与节奏 | 低 → 中段拖沓、单点没讲透、时长过长 |
| 平均播放时长 | 越长越好，但要看**占比** | 内容留存 | 占比低 → 观众在钩子后快速流失 |
| 时长 | **60-90 秒，60-80 秒最佳** | 信息密度 | 过长完播塌、过短交付不足 |
| 互动率 | 越高越好，结合结构看 | 共鸣/争议 | 低赞高评常是争议型；高赞低收常是共鸣型 |

> 账号当前实测：5s 完播多在 12%-28%、2s 跳出多在 42%-53%，说明多数视频**能留住一部分
> 但钩子还没稳定打到 25%+**，这是最值得优先攻的环节。

## 互动结构的读法（不同反馈代表不同含义）

- **点赞**：认同、情绪共鸣、“被说中”（战友视角、认知顿悟）。
- **收藏**：内容**可照做、可复用**（方法、清单、步骤）。知识口播要主动设计“可收藏的小动作”。
- **转发**：替我表达、对某人有用、社交货币（“我也是这样”“发给 XX 看”）。
- **评论**：强共鸣或争议；冷启动期熟人评论会虚高，需剥离。
- **主页访问 / 粉丝增量**：结尾 CTA 与持续关注价值的转化。

## 冷启动期口径校准（粉丝少阶段必须做）

1. **熟人流量剥离**：发布初期的播放、完播、评论可能来自熟人转发。判断公域表现时，
   多看 5s 完播与互动结构本身，少被绝对播放量/熟人评论带偏。
2. **小样本波动**：播放量基数小（几十~几百）时，比率指标波动大，单条 1-2 个赞藏就会
   让互动率跳动，要结合多条作品的趋势而非单条数字。
3. **横向对照为主**：同周期、同题材、相近发布时间的作品互相对比，比对照“行业大盘”更可靠。
4. **优先攻漏斗上游**：2s 跳出、5s 完播是“能不能获得更多分发”的闸门；下游的收藏/涨粉
   在流量基数小的时候先不作为主攻指标。

## 口播脚本的四条结构性标准（脚本层对照）

- **0-2s 钩子**：12 字黄金痛点反问，配前 3 秒头顶固定大标题卡，抓静音刷屏人群。
- **2-5s 承接**：反常识结论 / 高手偷跑 / 超预期收益，前 5 秒高密度给信息，禁止铺垫废话。
- **中段**：单条只讲透一个点，四段式紧凑推进，交付一个可照做的小动作（支撑收藏）。
- **结尾 CTA**：利他型关注钩子，给观众一个“明天还想继续看”的明确理由。

## 视觉层参考（关键帧对照）

- 前 3 秒固定花字大标题：让静音/划屏的人瞬间知道“这视频与我有关”。
- 表情：眉头/眼神/口型是否有“着急告诉你”的情绪张力，而非平静叙述。
- 动作：是否有可被截图的示范动作、道具或手势（提升可看性与收藏）。
- 着装与道具：稳定的视觉识别（同一顶帽子/同一着装）强化记忆与主页一致性。

## 优先级建议

复盘时按“漏斗上游 → 交付价值 → 关注转化”排序：先修钩子（2s/5s），再修中段与时长，
然后是收藏/转发设计，最后才是 CTA 与涨粉。数据越冷启动，越聚焦前两环。
