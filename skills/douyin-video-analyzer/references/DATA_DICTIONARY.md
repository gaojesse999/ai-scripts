# 数据字典与口径

三张表来自抖音创作者中心官方导出。**注意同名字段在不同表的格式不一致**（脚本已统一归一）：
作品表的比率是小数（如 `0.010989`），日数据表是百分号字符串（如 `11.81%`）；
时长在作品表是纯数字秒、日表是 `4.13s`；缺失值统一为 `-`。

---

## 表一：作品列表导出.xlsx（作品粒度，全量，本地按区间筛）

发布时间精确到秒，16 列。**该表没有视频 ID/链接**，作品与本地视频的对齐依据是
「发布时间 + 标题」（一天多条再按发布时间排序加序号）。

| 列名 | 类型 | 说明 |
|---|---|---|
| 作品名称 | 文本 | 含 emoji 与 #话题，做文件名时需清洗 |
| 发布时间 | 日期时间 | `YYYY-MM-DD HH:MM:SS`，区间筛选与排序主键 |
| 体裁 | 文本 | 如 `1-3min视频` |
| 审核状态 | 文本 | 如 `公开` |
| 播放量 | 整数 | 播放次数 |
| 完播率 | 比率 | 小数，如 0.010989 = 1.10%；看完整条的比例 |
| 5s完播率 | 比率 | 小数，播到 5 秒的比例（**钩子健康度核心指标**） |
| 封面点击率 | 比率 | 小数；详情页/封面场景的点击，可能为 `-` |
| 2s跳出率 | 比率 | 小数，2 秒内划走的比例（**开头钩子反向指标**） |
| 平均播放时长 | 秒 | 纯数字，如 4.773050；需结合视频总时长看占比 |
| 点赞量 | 整数 |  |
| 分享量 | 整数 |  |
| 评论量 | 整数 |  |
| 收藏量 | 整数 | “可照做”价值的强信号 |
| 主页访问量 | 整数 | 结尾钩子触发的关注前置动作 |
| 粉丝增量 | 整数 | 该条带来的净涨粉 |

## 衍生指标（脚本现算，不在原表）

| 指标 | 公式 | 含义 |
|---|---|---|
| 互动率（作品） | (赞+藏+评+转)/播放 | 内容引发反馈的总强度 |
| 互动率（日） | (赞+评+转)/播放 | 日维度反馈强度 |
| 播赞比 | 播放/点赞 | 每多少播放产生 1 个赞 |
| 平均播放时长占比 | 平均播放时长 / 视频总时长 | 视频总时长来自本地 mp4 的 ffprobe，需视频已下载 |
| 视频总时长 | ffprobe 本地 mp4 | 官方三表不含视频时长，必须取本地文件 |

## 数据更新与口径提醒

- 平台每天约 12:00 更新前一天数据；分析当天数据可能未出齐。
- 冷启动期（粉丝少）播放量受熟人/转发影响明显，完播率与评论可能被熟人拉高，
  见 [METRICS_BENCHMARK.md](./METRICS_BENCHMARK.md) 的校准说明。
- 三表为官方导出事实；脚本衍生项口径如上；分析推断需与事实分开陈述。
