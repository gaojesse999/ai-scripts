# 让微习惯按状态生长、繁殖或守住基线

## R — 原文 (Reading)

> “习惯发展的过程一般分为两类：生长类和繁殖类。”
>
> — B.J. 福格，第 6 章「习惯的生长与繁殖」

> “不要过早地提高标准。不要急着做出更大的行为。”
>
> — B.J. 福格，第 3 章「入门步骤」；第 6 章「循序渐进」

> “如果你想多做一些，不要限制自己。让动机来告诉你该做多少和该怎么做。”
>
> — B.J. 福格，第 6 章「习惯的生长」

> “沮丧、痛苦以及逃避等情绪标志着你的习惯出了问题，可能是难度提升太多、太快。”
>
> — B.J. 福格，第 6 章「循序渐进」

---

## I — 方法论骨架 (Interpretation)

本方法只接手已经稳定的微习惯：提示能可靠带出行为，最低版本在普通低状态下仍容易完成。

稳定之后先分三路，而不是默认升级：同一行为增加数量、时长或强度叫生长；从原习惯衍生一个相邻行为叫繁殖；当前负荷高、已有剂量足够或扩展体验变差时守住基线。

最低基线是永久退路。状态好时多做属于自愿加分，不能因为连续几次多做就自动抬高次日标准。

痛苦、沮丧、逃避常提示加量过快；稳定但厌倦可能提示可小幅加难。它们是调节线索，不是疾病、损伤或心理状况的诊断。

自然生长没有统一进度，也不保证抵达目标成果。每个习惯可能有自己的自然上限，有些更适合繁殖而不是继续加量。

因此要把“习惯持续”与“成果有效”分开验收：写明目标成果、该成果需要的行为剂量、当前剂量和复查日期。

若成果长期不变，不能只庆祝最低动作并假定迟早会变；必须加量、繁殖、换行为，或引入专业、社会、工具与环境支持。

身份只能作为累积行为证据的副产品，不能用“我已经是某种人”的口号替代有效剂量和成果复查。

整套方法是可逆的小实验：观察状态，提出一个假设，每轮只改一个变量，到期比较，再决定下一轮。

## A1 — 书中的应用 (Past Application)

### 案例 1：埃米的一张便利贴繁殖为工作系统
- **问题**：埃米忙于育儿和创业，却常用杂事回避当天最重要的工作。
- **方法论的使用**：她先稳定“女儿关车门后，在便利贴写一件最重要的事”，没有一开始就要求完整规划。
- **结论**：原动作足够稳定且有意义后，更适合繁殖出待办与深度工作行为，而非把便利贴动作本身无限加长。
- **结果**：书中报告，这个起点逐渐扩展为工作习惯系统，并伴随项目、收入和生活状况改善。

### 案例 2：苏库马尔在两个俯卧撑与一小时训练间保留退路
- **问题**：他 17 年间反复用激进节食和一小时锻炼开局，最终都中断。
- **方法论的使用**：先稳定刷牙后两个俯卧撑和 5 秒平板；状态好时多做，状态差时仍只做最低版本。
- **结论**：额外完成量是加分，不是自动升级的新基线；同一行为可生长，也可向饮食等相邻行为繁殖。
- **结果**：书中报告，他后来减重 9 千克、腰围减少 12.7 厘米，并逐步形成每天一小时的训练过程。

### 案例 3：咖啡滤网从第一步生长为完整家务
- **问题**：迈克要求成年儿子一次完成咖啡机清洁，多步任务引发羞愧、愤怒与冲突。
- **方法论的使用**：先只要求取出滤网并给予具体感谢；这个动作稳定后，才扩展到清洗、放回及其他家务。
- **结论**：先守住可成功的行为，再根据稳定状态生长或繁殖，比一次抬到完整任务更可靠。
- **结果**：书中报告，家务行为和父子关系均改善；这是家庭个案，不能据此保证同样因果结果。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一个微习惯已经能自动或稳定发生，用户问是否该增加数量、时长或难度。
2. 原习惯保持良好，但继续加量开始痛苦、逃避，或稳定到厌倦，不知道应退回还是扩展。
3. 最低动作维持数周或数月，目标成果却没有可见变化，出现“稳定但无效”的剂量断层。
4. 一个习惯已经达到自然上限，用户想围绕同一愿望增加互补行为。
5. 状态波动明显，用户想在好状态多做、差状态不断线，又不想把基线越抬越高。

### 语言信号

- 「这个习惯已经稳定了，接下来要不要加量？」
- 「我应该把它做大，还是再长出一个新习惯？」
- 「每天都做最低动作，但目标怎么一直没变化？」
- 「多做几次以后，是不是以后都必须做到这么多？」
- "Should I scale this habit or keep the baseline?"
- "My tiny habit is stable but the outcome is not changing."
- "Is this habit growing, multiplying, or plateauing?"

### 与相邻 skill 的区分

- 与 `fogg-simplify-action` 的对比：该方法处理行为尚未稳定、启动太难时怎样降低能力门槛；本 skill 只在最低行为已经稳定后，决定生长、繁殖或守基线。
- 与 `fogg-reinforce-with-shine` 的组合：完成后持续无感时可先检验即时成功感；行为已稳定后，本 skill 再独立核对增长路线和成果剂量，不把短期再次执行信号当成最终效果。
- 与提示类方法的区别：漏做或提示错位时先修原配方；本 skill 不把未稳定误判成需要升级。
- 与目标行为选择：若现行为即使增加到现实上限也不能影响成果，应换行为，而不是继续优化其成长路线。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 必须按顺序执行；第一步只判断状态，不先鼓励加量。

1. **确认稳定，并先判定生长 / 繁殖 / 守基线**
   - 先确认：明确提示已能反复带出最低动作；最低动作在普通的忙、累或低动机状态下仍容易完成；偶尔多做后仍允许退回最低版本。
   - 同时记录：目标成果、可观察成果指标、成果所需行为剂量、当前实际剂量、复查日期。剂量没有可靠依据时标为“未知”，不得编造。
   - **生长**：同一行为多做一点可能补足剂量差，且额外量当前感觉自然、可承受。
   - **繁殖**：原行为接近自然上限，或目标成果还需要另一种互补行为。
   - **守基线**：当前负荷高、加量引发明显负面体验，或现有剂量已足够且无需新分支。
   - 完成标准：输出“稳定证据 + 唯一主路线 + 选择理由 + 成果指标 / 所需剂量 / 当前剂量 / 复查日期”。
   - 判停：若最低动作仍常漏做、提示不可靠或启动困难，停止本流程，转去简化动作或排查提示；若涉及疼痛、疾病、用药、成瘾或必要安全标准，先转专业评估。

2. **设计一个可逆的下一周期**
   - 生长：保留原最低基线，只增加一个很小的可选扩展量。
   - 繁殖：保留原习惯，只新增一个与同一成果相关、可单独验收的微行为。
   - 守基线：不加量，明确哪些低状态直接退回最低版本；需要时先减负或恢复。
   - 所有额外完成量都记为“加分”，不会因连续完成而自动升级为最低标准。
   - 完成标准：下一周期只有一个改动变量，且原最低基线原样写出。
   - 判停：若新方案同时改提示、行为、剂量和环境，缩回单变量；若加量后出现持续痛苦、明显逃避或功能受损，立即撤回扩展量并评估是否需要医疗支持。

3. **执行 fm-01 迭代协议**
   - 观察：记录提示、最低量、额外量、当时状态、完成体验和成果指标。
   - 假设：把问题写成可检验句，如“当前运动剂量不足以改变耐力”，不归因于懒惰或人格。
   - 单变量调整：只测试步骤 2 的一个改动，其他条件尽量保持不变。
   - 再测试：到复查日期比较行为剂量、体验与成果；失败只作为下一轮设计数据。
   - 完成标准：至少有一条调整前基线、一条单变量假设和一组复查记录。
   - 判停：没有可观察数据时不宣布有效或无效；先补测量。出现明显不良后果时提前停止，不等复查日。

4. **根据调节信号校准**
   - 痛苦、沮丧、逃避：优先撤回最近增量、退回最低基线，检查是否加得太多或太快。
   - 厌倦：仅在行为稳定、无过载且目标仍需更多剂量时，小幅加难或转为繁殖；厌倦不自动等于必须升级。
   - 感觉良好且成果改善：维持当前周期，不因一次顺利继续连跳多级。
   - 完成标准：每个信号都对应一个明确动作，不能只写“继续观察”。
   - 判停：这些信号不能诊断损伤、抑郁、焦虑、躁狂或其他病症；症状持续、严重或影响功能时停止自助推断并建议专业判断。

5. **在复查日决定下一轮**
   - 成果改善且体验可承受：维持、再做一次小幅生长，或在确有互补需要时繁殖。
   - 成果达到所需剂量或阶段目标：守住最低有效基线，不为“进阶”而进阶。
   - 习惯稳定但成果长期不变：必须选择一项——增加有效剂量、繁殖互补行为、更换行为，或引入专业指导、同伴、工具、环境等外部支持；不得只延长最低动作并假定它会自然长成最终剂量。
   - 完成标准：写出“保留什么 / 只改什么 / 为什么 / 下次复查日期”。
   - 判停：若现行为与成果关系缺乏证据，先换行为假设或寻求可靠指导，不继续机械加量。

### 最小输出格式

```text
稳定证据：
目标成果与指标：
所需剂量 / 当前剂量：
本轮路线：生长 / 繁殖 / 守基线
永久最低基线：
本轮唯一改动：
调节信号与退回条件：
复查日期：
若成果不变，下一步四选一：加量 / 繁殖 / 换行为 / 外部支持
```

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 行为尚未稳定、仍经常忘记或启动困难：先做能力简化、锚点或强化排障；稳定前没有“成长路线”可判断。
- 一次性任务或短期冲刺：本方法针对可重复习惯，不替代项目排期。
- 医疗、康复、营养、用药或安全行为的必要剂量：不得自行把专业标准缩为微小基线，也不得凭情绪信号调整处方。
- 严重成瘾、自伤、进食障碍、重度抑郁、躁郁症、创伤或疑似损伤：微习惯不能替代诊断、治疗或危机支持。
- 工时、照护、贫困、无障碍与组织制度造成的结构性限制：不能把系统问题改写成个人“再长一点”的责任。

### 作者在书中警告的失败模式

- **过早抬高最低标准（ce19）**：几次多做后取消退路，低状态时反而整项中断。
- **忽略痛苦的反强化（ce31）**：只看完成数字，任由疼痛、羞耻和逃避累积。
- **强迫越过自然边界（ce32）**：假定所有微习惯都必须线性变大，忽略繁殖或保持微小。
- **固定天数迷信（ce03）**：用 21、60 或 66 天替代状态、剂量和成果检查。
- **把身份当证据（ce35）**：先宣布新身份，再忽略真实行为与结果。

### 作者的盲点 / 证据边界

- 书中增长案例多为作者、学员或家庭个案，选择偏差、自述偏差和长期随访不足；本框架应作为 N-of-1 试验启发式，不是普适定律。
- “微小成功自然长成大改变”缺少普遍保证；稳定性与成果有效性必须分开验收。
- 痛苦、逃避、厌倦可帮助调节难度，但原因可能来自损伤、疾病、药物、情绪障碍或结构压力，不能据此做医疗判断。

### 容易混淆的邻近方法论

- `fogg-simplify-action` 解决“还做不起来”；本方法解决“已经稳定，下一步怎么走”。
- 渐进超负荷、治疗剂量或专业训练计划可提供目标剂量；本方法只负责如何在保留退路的前提下迭代，不替代领域专业方案。
- “保持连续”只保护行为联结，不证明成果正在发生；达到成果仍需有效剂量。
