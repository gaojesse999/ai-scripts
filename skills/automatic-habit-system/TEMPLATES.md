```text

## 5. 启动检查

- [ ] 所有闹钟只需设置一次
- [ ] 所有模板已经提前建好
- [ ] 所有必要 APP/文件已放到可见位置
- [ ] 每个最低版本都能在状态差时完成
- [ ] 不需要当天临时决定做什么
```

## 六、版本质量检查

每次更新后检查：

- 每个时间段都出现于标题或总表。
- “显而易见”描述真实触发，不重复写属于其他原则的动作。
- “有吸引力”描述渴求或期待，不是缩短时长。
- “简便易行”有最低完成标准，且用户认为可执行。
- “令人愉悦”是完成后的即时奖励。
- 不强迫四原则齐全。
- “反转/倒置”只在明确竞争行为存在时出现。
- 断点前有存档，断点后有读取动作。
- 最新表格、说明、速查卡不冲突。
- 历史版本保留，用户原话不被篡改。
