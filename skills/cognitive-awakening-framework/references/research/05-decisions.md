## 0. 决策风格总览（从行为反推，不是从口号）

周岭真正做过的选择，比他反复讲的「元认知 / 舒适区边缘」更窄、更可复述：

1. **先被触动，再当「有理有据的傻瓜」做半年以上**（敲《财富自由之路》、每日反思 160 天、早起四年）。  
2. **不辞职、不组团、不靠打卡展示**；成长发生在本职工作之外的早晨与业余咨询。  
3. **重大人生题用感性筛选，小事用理性拆解**（PAGE 32：「小事听从你的脑，大事听从你的心」）。  
4. **用作品换反馈，而不是用课程/社群换粘性**——至少到 2020 截稿时，产品是公众号问答 + 一本书，不是训练营。  
5. **家庭账是沉默的**：常年两地、女儿陪伴缺位，用写书当补偿（PAGE 144）。这是他唯一明确承认的「没选完美项」。

## 一、他自己的重大决策（按时间）

每一条结构：背景 → 声称的逻辑 → 事后反思 → 与书中原则是否一致。

### D1. 大学 1500 米：把考核改写成「追逐游戏」（早年原型）

| 项 | 内容 |
|---|---|
| 时间 | 大学期间（具体年份未给） |
| 来源 | 一手 PAGE 109–111 |
| 背景 | 毕业必须跑进 5 分 10 秒；他入学约 8 分钟；全队近百人，课前测试优秀可免后面 2 小时体能课。 |
| 声称的逻辑 | 不要让事情本身束缚情绪和注意力。把 1500 米拆成一段段 10 米：「先别减速，等跑到前面 10 米再减速」。一开始冲到最前面，是为了边上没人干扰、好沉浸。 |
| 事后反思 | 写成「大学时代为数不多能一直记到现在的人生经验」；后来用德西/瑞恩自我决定理论回贴：自主需求把「必须做」改写成「另外一件自己能掌控的事」。 |
| 一致性 | **高度一致**于后文「游戏心态」（第七章）和「拆目标进拉伸区」。这是他决策操作系统的最早可核样本：不换任务，换框架。 |

### D2. 2010 元旦：开始记日程（觉知的第一笔）

| 项 | 内容 |
|---|---|
| 时间 | 2010-01-01；2014 元旦改用手机日历；截稿时已约 10 年 |
| 来源 | 一手 PAGE 133–134 |
| 背景 | 与好友聊天，发现很多共同经历自己毫无印象；一问「这些年我都做了什么」，眼前像真空，背上汗毛直竖。这是书中第一次把「焦虑」具象化。 |

### D6. 朋友意外 → 2017 年 36 岁「觉醒元年」（总开关）

| 项 | 内容 |
|---|---|
| 时间 | 「直到有一天」朋友命运巨变（未给精确日期）→ 2017 年，自称 36 岁 |
| 来源 | 一手 PAGE 9–10、PAGE 17 |
| 背景 | 本职工作投入，业余被聚会烂醉、熬夜、搞笑视频、八卦、手游、蒙头大睡占据；下意识觉得无忧生活会继续。两位极好的朋友因意外轨迹巨变。自问：若现有一切被剥夺，我还有什么、会什么、留下了什么？答案是「几乎什么都不会」。 |
| 声称的逻辑 | 真正的觉醒不是每天有事做、也不是每天努力，而是发自内心渴望、立足长远、用认知与时间做朋友。人与人的根本差异是认知差异；认知影响选择，选择改变命运。 |
| 事后反思 | 觉醒后立刻焦虑：报很多课、买很多书、求多求快、只盯阅读量；一度觉得「来不及了，太晚了」。用笔把烦恼列尽，拆出五种焦虑（完成/定位/选择/环境/难度），归结为欲望>能力 + 缺耐心。对策是「反着来」+ 不跟成功人士比现状、跟自己的过去比。 |
| 一致性 | **叙事与原则同构**：触发是死亡/丧失的元时间，方法是消除模糊、降低对标。未辞职、未抛弃本职——成长加在业余层，符合「接受环境，在局限中做力所能及的事」（PAGE 19）。 |

**职业决策（重要空缺）**：书中反复说「对本职工作非常投入」「成长咨询是业余的」「常年两地」。**没有「辞职做自媒体」这一决策的一手记录。** 网络检索（B 站、出版社、豆瓣作者介绍）也没有可核对的辞职/转职声明。作者介绍统一为「一位心智探索者」，不写公司。**推断（低置信）**：至少写到 2020 截稿，他选择的是「双轨」：本职养活家庭 + 早晨/业余写作成长；是否在畅销后辞职，公开信息不足，不得编造。

### D7. 2017-02：每日反思；约第 160 天决定开公众号

| 项 | 内容 |
|---|---|
| 时间 | 2017 年 2 月开始；写到第 160 天萌生开号；2017 年 7 月开通「清脑」；截稿前反思文超 1000 篇 |
| 来源 | 一手 PAGE 86、PAGE 134–135、PAGE 54（深度学习章亦述） |
| 背景 | 读成甲《好好学习》被「每日反思」触动。此前 10 年日程让他愧疚于浪费、困惑于被动忙碌，但找不到出口。 |
| 声称的逻辑 | 反思 = 深度日志：只取当天最触动的点，经过—原因—改进。避开「把日记当反思」。暗含触动学习法、元认知、刻意练习。载体用电子文档（石墨/印象笔记），不推荐纸质（不便搜索）。 |
| 事后反思 | 「谁能想到这个毫不起眼的每日反思却帮我打开了一个全新的世界」；「我有幸从混沌走向觉醒，正是依靠每日反思……是它帮我开启了元认知。」开公众号的动机是把好处带给更多人，不是先想变现。 |
| 一致性 | **这是全书最强的「言行一致」证据**：方法他自己先用到阈值，再对外教。形式纪律也一致：不要求一天不落、不写正式文章、目的是改变不是完美（PAGE 140–141）。 |

### D8. 早起四年：无闹钟、不参团、不打卡（习惯决策）

| 项 | 内容 |
|---|---|
| 时间 | 截稿时「已经过了 4 年」→ 约 2016 前后启动（与觉醒期重叠） |
| 来源 | 一手 PAGE 116–119 |
| 背景 | 以前 12 点后睡、睡前刷手机；身体精神差。知道名人早起但觉得是另一个世界。若有人用多闹钟/打卡/监督来劝，他「一定无动于衷」——那是消耗意志力。 |
| 声称的逻辑 | 被中岛孝志《4 点起床》四点打动：多一个工作日的算法（他承认「经不起推敲」但心动）、睡眠节点、弃闹钟、抓住晨间激素高峰。认知想通就不靠大把意志力。起床内容：规划 10 分钟 → 跑步 → 反思 → 读写 → 困难工作。 |
| 事后反思 | 并非完全无痛：两周兴奋期后约两个月适应期（不愿起、打哈欠、黑眼圈）。继续的动力是「无闹钟醒来的神奇体验」和晨间静谧，不是打卡纪录。明确列出可以不起的场景（生理低谷、聚会睡太晚、次日长途/高耗能、环境突变）。原则：**状态优于时间**；难度匹配（先散步后跑步、冬天先室内热身 20 分钟）。 |
| 一致性 | **与「反打卡、反监督群、驱动而非对抗、匹配」完全同向。** 这是检验后来有没有把反打卡做成打卡产品的对照基线。 |

### D9. 放弃闹钟；后来买入专业番茄钟（工具决策，方向相反但逻辑同构）

| 项 | 内容 |

## 二、他建议别人怎么选（咨询决策样本）

这些不是他的人生选择，而是「周岭式决策启发式」的外推。价值：Skill 遇到用户提问时，应模仿**他建议别人的选法**，而不是只复述他的自传。

### C1. Amy 曹 —— 降难度，不要加鸡血

- **来源**：一手 PAGE 49–50、PAGE 84（2019-05-06 反馈）  
- **她的问题**：跑步 1 小时靠意志力最终中断；英语 1 小时烦躁。  
- **他看到的**：她主动降到 30 分钟、一周不少于 4 次；「找能坚持的方式比标准化时长更重要」。他判断：她一开始在困难区，急于求成。  
- **建议内核**：舒适区边缘；复利比速成重要。后来她认真「写下来」日程，焦虑下降。  
- **启发式**：如果 X 靠意志力很拼但反复放弃，则先减量到「有点挑战但不痛苦」，而不是加激励。

### C2. 阿健 —— 五个打卡计划，中断就想扔掉

- **来源**：一手 PAGE 65–68  
- **问题**：为学习建了 5 个打卡；一旦中断就不愿继续。  
- **他的诊断**：不是贪心或完美情结，是动机从「学习本身」转移到「纪录完整」；叠加认知闭合（打卡=任务结束）和身心分裂。极端例子：早起群打卡继续睡、拍书封发朋友圈。  
- **建议**：①不反对打卡作助推，但不可依赖；②**用记录代替打卡展示**；③**设下限不设上限**（来自《微习惯》，他「亲测有效」）。「偶尔中断对学习有什么关系？」  
- **启发式**：如果坚持的是 streak 而不是技能，则拆掉展示和上限。

### C3. 考研党 —— 太刻苦所以崩

- **来源**：一手 PAGE 73–79  
- **问题**：五六点起、吃饭听音频、累了瞄小说就失控三四天；同学打两局游戏能回来，自己一放松像跌入地狱。  
- **建议**：有效学习靠极度专注而非比拼毅力；精力 <70% 还硬撑是进入困难区；模式 = 极度专注 + 主动休息（番茄循环）；「分心了就放下笔，没有睡意了就离开床」。  
- **启发式**：如果崩溃形态是「硬撑→报复性放纵」，则处方是主动休息，不是更刻苦。

### C4. A丽 —— 「道理都懂就是不做」

- **来源**：一手 PAGE 90–92  
- **当时回答**：「真想破解，方法也有，就一条：直接去做！」事后觉得太简单，补课：认知也是技能；「知道」的快感会关闭练习回路；必须大量重复形成神经元强关联。  
- **启发式**：如果用户在收集更好方法，则打断寻优，指定一个够用的动作做 180 天。他自己承认曾是知而不行的人。

### C5. 「无悔」与傅琴 —— 只输入不产出

- **来源**：一手 PAGE 69–70  
- **无悔**：大二，每天从早学到晚，6 学 1 休，收获无力疲累。  
- **傅琴**：为应对生活危机同时学瑜伽、写作、肚皮舞、英语口语、绘画、茶道，内心仍无价值感。  
- **建议**：凡咨询类似问题，都建议去产出：说、写、或分享视频；不能一味学学学。创造动机要放弃「打卡式输入」，直接用（英语：翻译、设系统语言、读原版）。  
- **启发式**：技能数量过多 = 困难区 + 无反馈；先做成一个能换夸奖/解决问题的作品。

### C6. 如如大王 / 一位妈妈 —— 执行匹配与番茄钟

- **来源**：一手 PAGE 89  
- **如如大王**：按舒适区边缘练钢琴，两周把考试节拍 160 提到 192，考前焦虑消失。  
- **一位妈妈**：国庆让孩子用番茄工作法，有时 2 小时完成全部作业，「父子大战」消失。  
- **他的评论**：同样的道理，有人当鸡汤，有人当干货——差别是有没有行动。

### C7. 年轻老师与大学生 —— 自由太多是匹配失败

- **来源**：一手 PAGE 50–51（2019 暑假提问）  
- **老师**：有寒暑假但不喜欢，计划全空、作息乱。  
- **学生**：上大学后失去高三约束，寝室游戏抖音。  
- **建议**：自由/财富必须与当前掌控力匹配；突然巨额财富（彩票案例）会毁人。理想态是**持续获取与能力匹配的财富或自由**；父母不要过早给孩子过大决策权。  
- **启发式**：如果用户想辞职/gap/暴富「先自由再成长」，周岭会泼冷水：先证明你能掌控现有空闲。这与他自己「不辞职、在本职约束里早起」同构。

### C8. 人生目标 / 职业 / 伴侣 —— 大事听心

- **来源**：一手 PAGE 31–32  
- **他反对的选法**：理性权衡后得出「变得很有钱」「被别人崇拜」——动机是自我索取和外在评价，不耐久。  
- **他建议的选法**：用感知力代替思考力。转述一稼六问（最想帮谁、废寝忘食的事、最感动自己/别人的时刻、若无经济压力如何度过余生、闲暇关注什么）和米勒三问（临终后悔、最喜欢的人物、年轻时的闲暇）。「正确的答案往往都是利他的」。洪兰：小事听脑，大事听心。捕捉工具：最、总、第一反应、梦、身体、直觉。  
- **启发式**：职业咨询若用户在做利弊表，先停，改问触动与利他对象。

### C9. 一念 —— 每日反思的读者回传

- **来源**：一手 PAGE 137  
- **反馈**：每天写好多篇反思，观察行为/情绪/决定，从小事改；内心变稳，知道价值、想要什么、该怎么做。  
- **他的元建议**：任何人遇到问题都可以把反思当药引；形式服从改变。

### C10. 读者「晴天」—— 概念要用类比砸开

- **来源**：一手 PAGE 127  
- **问**：前额皮质、元认知、理智脑什么关系？  
- **他答**：前额皮质是理智脑和元认知的「肉身」。决策风格：宁可找一个准类比，也不堆术语。

## 四、言行一致 / 不一致（本 Agent 的核心交付）

发现矛盾时保留矛盾，不和稀泥。

### 一致（高置信，有一手行为）

1. **反打卡：自己早起四年不参团、不打卡、不用闹钟**；教阿健用记录替换展示。  
2. **反意志力硬刚：承认自制力不强、试过失败**；改用清晰力、匹配、认知驱动。  
3. **作品意识：先写 160 天反思 → 公众号 → 书 → 读者反馈闭环**；咨询一律推向产出。  
4. **阈值：习惯以 180 天而非 21 天**；敲专栏约一年、反思过千篇。  
5. **业余咨询 + 保留本职（至少到 2020）**：不把「觉醒」兑现成立即辞职追求完全自由——与「自由要匹配掌控力」同向。  
6. **触动学习：自己读书也是只取最触动的一句并实践**（李笑来那句、成甲反思、刘未鹏 11 层楼）。  
7. **费曼：读者先指认，他再补课并公开承认孤陋**——没有装成一直师从费曼。

### 软张力（有价值，未构成打脸）

**T1. 批评浅层知识付费，入门却在得到专栏。**  
他踩过「报很多课、买很多书、求多求快」的坑（PAGE 17），又批评打卡课、多闹钟早起课；但跃迁动作是订阅并手敲《财富自由之路》。**不是伪善**：他反对的是「只输入、打卡、求快」，不是反对一切专栏。仍需记住：方法论的「出生医院」是 2016 年知识付费高潮，书却把自己写成底层、可穿透 50 年。

**T2. 反意志力的修辞 vs 极强的持续量。**  
四年早起、一年敲书、1000+ 反思、两个月早起适应期的痛苦，外行人会看成毅力奇迹。他的解释是「认知想通后不需要大把意志力」。两种描述可以同时真：启动需要认知，维持仍有痛苦。Skill 不要把「认知驱动」说成零痛苦。

**T3. 「不涉商业 / 穿透 50 年」vs 同一 IP 的青少版、精装、漫画、姊妹篇。**  
后记那句话指**书的题材**（不写职场权谋、不写赚钱技巧），不是「永不做出版生意」。后续产品线是标准的畅销书工业化，也符合他自己的「作品换反馈」「匹配不同拉伸区」。真正的张力是：**反复利焦虑的人，把同一套概念卖了四次形态**。可以记为「传播策略上的重复」，不必升格为道德指控。

**T4. 「一流生活不是富有而是觉知」vs 百万册作者。**  
不矛盾：觉知是主观标准，销量是作品反馈。更值得标的是：他几乎不公开消费自己的成功（无履历、无照片、无「我辞职了」故事），这与「不迎合」的作者文案一致，也让决策档案永远缺职业一页。

**T5. 要事第一 vs 两地缺位女儿。**  
他公开承认缺位，用书当礼物。原则没破，优先级暴露了：成长系统 / 本职 / 著作 > 物理陪伴。咨询别人「要事第一」时，要事可能被用户理解成家人；他本人的要事是觉知与写作。**这是价值观排序，不是口是心非。**

**T6. 卡面抄、每日反思、下限打钩，看起来很像打卡。**  
他坚持区分：有无**对外展示**、有无**固定上限**、动机是否在活动本身。逻辑自洽。若未来有人用「清脑打卡营」卖课，那是渠道行为，需另证是否他授权。

## 五、可写入 Skill 的决策启发式（全部有案例）

可表述为「如果 X，则 Y」。供 Phase 2 使用，不是最终心智模型。

1. **如果选项会让你立刻更自由（辞职、长假、暴富、全自主），先问掌控力是否匹配**（C7 + 他自己不辞职）。  
2. **如果靠意志力很拼但循环中断，减量到拉伸区，而不是加打卡、加鸡血**（Amy 曹）。  
3. **如果坚持的是纪录完整，拆掉展示和上限，改成私人记录 + 下限**（阿健 vs 他自己早起）。  
4. **如果道理越懂越不动，停止寻优，选一个有依据的动作做满约 180 天**（A丽 + 敲专栏 + 反思）。  
5. **如果学习只输入，立刻规定一个可被看见的产出**（傅琴/无悔；他自己的公众号）。  
6. **如果是伴侣/职业/人生目标，先问触动和利他对象，再做利弊表**（PAGE 32）。  
7. **如果工具是外力摧残（多闹钟、监督群），拒绝；如果工具是自己理解后的边界（番茄钟、卡面抄），可以使用。**  
8. **如果家庭与成长系统冲突，他倾向于用作品补偿缺席，而不是立刻改工作结构**（D15）—— Skill 应标成「他会这样选」，不要标成「人人应该这样选」。  
9. **如果被死亡/丧失/真空记忆击中，把那天当元时间：只做一件事——想清楚，然后写下来**（朋友意外、2010 日志）。  
10. **如果别人的理论有理有据且自己暂时无法反驳，又真想做，就当傻瓜先做，用行动验证**（PAGE 89）。
