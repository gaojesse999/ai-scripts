# Audience Building Content Creator

把一个早期想法、主题、观点、经历或内容方向，写成能吸引**特定受众**、建立信任、并复利成长期个人品牌的内容。

这不是「多发、坚持、提供价值」这类正确但没用的建议。它解决的瓶颈是：**冷启动增长卡在「被看见」，而不是内容产量。**

方法论来源：`content-generation-rules/如何在没有任何粉丝的情况下建立自己的受众群.md`。完整框架、模板、失败模式和成稿样例见 [REFERENCE.md](REFERENCE.md)。Agent 执行细则见 [SKILL.md](SKILL.md)。

## 这个 Skill 做什么

当你说「帮我写一篇关于 X」「写个短视频口播」「列一批选题」「把这篇改好」，Agent 会按同一套标准产出可直接发布或录制的内容，而不是通用鸡汤。

它会帮你：

- 把模糊主题收窄到**一个具体人群 + 一个具体问题**
- 用你自己的经历、观点或能力当骨架（不是谁都能写的百科解释）
- 用六要素把内容写成「该停、该在意、该信任、该记住、该转发」
- 按平台和体裁改长度、语气和结构
- 优化已有文案时：先诊断缺了哪一环，再给改写，而不是只给建议

优先长期受众积累，不追短期流量技巧。

### 适合做什么

| 你想要的 | Skill 会产出 |
|---|---|
| 文章大纲 | 定位 + 标题候选 + 带受众逻辑的大纲 |
| 完整文章 | 可直接发布的成稿（微信 / Substack / Medium 等） |
| 短视频脚本 | 15–60 秒口播 + 屏幕字 + 备选钩子（Reels / Shorts / TikTok 等） |
| 长视频口播 / 出镜稿 | 按分钟估算字数、分节、可念的讲稿 |
| 社媒图文 | 小红书、微信短帖、LinkedIn、X 串帖、Threads 等 |
| 选题列表 | 默认 8 条（5–15），每条都带受众、问题、角度、收益、推荐体裁 |
| 内容优化 | 对照六要素诊断 + 具体改写 + 可复用的 1–3 条动作 |

### 明确不做什么

- 不把受众写成「所有人」
- 不写谁都能写的通用解释文
- 不做无观点的骑墙（「看情况」「每个人都不一样」）
- 不空追热点、不自嗨发泄、不模板式社交腔
- **视频需求只做内容侧**：选题、结构、脚本、口播、屏幕字、画面内容建议。除非你明确要求，否则不谈拍摄、剪辑、设备、灯光、软件或后期

## 使用前准备什么

不必填问卷。信息够用就会直接写；缺关键项最多问 2–3 个短问题。

六项输入里，**受众、平台、你自己的真实角度**最容易卡住质量：

1. **主题** — 这篇到底讲什么
2. **目标受众** — 谁会觉得「说的就是我」（角色、阶段、痛点、身份）
3. **内容方向** — 观点、经历、框架、案例、教程、故事等
4. **素材** — 你的真实经历、观点、数据、例子（这是骨架）
5. **平台** — 决定长度、语气、结构
6. **产出类型** — 大纲、成稿、脚本、口播、社媒帖、选题、优化

最高杠杆的三个问题：

- 什么样的人读/看完会认出自己？
- 发哪个平台，大概多长？
- 你在这个题目上真正吃过的亏、坚持的观点、或练出来的方法是什么？

## 使用步骤

对人来说，按下面走一遍即可。Agent 内部有 8 步检查清单，默认不展示给你。

### 第 1 步：用一句话说清内容

把原始主题压成这一句。填不满，就先补受众、问题或你的真实经历，不要直接开写泛文。

```text
面向【具体受众】，
他们正在纠结 / 在意【具体问题或欲望】，
这篇内容帮他们【具体收益】，
方法是展示【经历、洞察、方法、故事或立场】，
所以他们有理由【读、收藏、转发、评论、关注或信任】。
```

主题太宽时先收窄，例如：

| 太宽 | 收窄到能赢的粒度 |
|---|---|
| 个人成长 | 刚开始接私单、没有作品集的人，如何攒出前 30 天的信任资产 |
| AI 工具 | 内容创作者如何用 AI 把零散经历变成稳定的文章/脚本流水线 |
| 职场效率 | 3–5 年经验的职场人，如何把忙碌变成看得见的专业影响力 |

### 第 2 步：锁定两件事

- **受众**：一个能叫得出来的群体，不是「对成长感兴趣的人」
- **骨架**：必须是你的经历、观点或能力。没有你，这篇就不该存在

### 第 3 步：用六要素搭结构

六条都要有，按体裁缩放，缺一条就是失败：

| 要素 | 作用 | 常见翻车 |
|---|---|---|
| **钩子 Hook** | 第一句 / 前 1–3 秒拦住对的人 | 「今天想分享一些想法」 |
| **大问题 Big Problem** | 用对方的话说出他们立刻认出的痛 | 「内容创作很难」「人人都想涨粉」 |
| **清晰方案 Clear Solution** | 可执行路径，且带着你的指纹 | 「多发、坚持、提供价值」 |
| **大收益 Big Benefit** | 说清能得到什么（实用 / 情绪 / 社交 / 身份） | 让读者自己猜收益 |
| **立场 / 极化 Confidence** | 敢站边。极化 ≠ 引战 | 「两边都有道理」「看情况」 |
| **新视角 Novel Perspective** | 让人觉得「我没这么看过」 | 正确但可互换的常识 |

立场句式可以是：「真正的问题不是 X，是 Y」「多数人先做 A，你其实该先做 B」「这不适合所有人，只适合某某」。

### 第 4 步：按平台和体裁成形

默认长度，可按你的平台、语气、限制改：

- **短视频 15–60 秒**：钩子 0–3s → 问题 3–8s → 方案 8–45s → 收益+带走 45–60s
- **长口播 / 出镜**：英文约 150 词/分钟；中文约 250–300 字/分钟
- **完整文章**（微信 / Substack / Medium）：一个想法 1200–2500 词
- **LinkedIn 长帖**：600–1200 词
- **选题列表**：默认 8 条，范围 5–15

新内容默认带三块：

1. **定位摘要**：目标受众 · 内容承诺 · 角度
2. **主成品**：大纲 / 成稿 / 脚本 / 帖子 / 选题
3. **可选变体**：2–3 个钩子、标题或 CTA

优化已有内容时默认带：

1. 对照六要素诊断（有 / 弱 / 缺）
2. 改写，不是空建议
3. 以后也能用的 1–3 条动作

### 第 5 步：发布前过三道关

**压缩测试**：这篇有没有给出停下来、在意、信任、记住、转发的理由？缺一条就改。

**转发检查**：

1. 别人为什么要转？
2. 目标受众能认出自己吗？
3. 立场够不够锋利，能引发讨论、收藏或引用？

**质量清单**（必须全过）：

- 对着具体受众说话，不是「所有人」
- 骨架是你的真实经历 / 观点 / 能力
- 六要素都在，且能指认出来
- 有清晰立场，不骑墙
- 至少有一个转发触发：身份、实用、判断、新奇、讨论、信任
- 不空追热点、不自嗨、不人人都同意的正确废话
- 视频只出内容侧
- 成品能直接发或录，不过度方法论化

## 怎么跟 Agent 说

信息够用就直接生成。缺关键项时，Agent 最多一次问 2–3 个短问题，不会甩长问卷拦住你。

**最小可用：**

```text
帮我写一条小红书，主题是「工程师转独立开发前半年最容易走错的路」。
受众是 3–5 年后端、想做独立产品的人。
我自己做过 4 年后端，转独立后前 6 个月一直补技术，后来才发现卡点是选题和分发。
```

**只给主题也可以**，但质量取决于 Agent 能否补全受众和骨架。更稳的说法：

```text
/audience-building-content-creator
平台：微信公众号，大约 2000 字
产出：完整文章
受众：有专业经验但更新不稳定的知识博主
主题：用 AI 把零散经历变成稳定产出
我的观点：AI 的杠杆不在代写，而在把你已经懂的东西结构化
```

**优化已有内容：**

```text
帮我按 audience-building 的六要素改这篇。
先指出钩子、问题、方案、收益、立场、新视角哪条弱，再直接改写，不要只给建议。
```

**视频：**

```text
写一条 60 秒口播：为什么大多数企业号涨不起来。
我做了 5 年内容策略咨询。立场是：企业号失败不是因为更新少，而是从来没选定对谁说话。
只要脚本、屏幕字和画面内容建议，不要拍摄和剪辑。
```

## 长短内容怎么搭配

规划一整套内容、而不是单篇时，记住结构分工：

- **短内容**（帖子、推文、短视频）是入口漏斗，赚到前 10 秒注意力
- **长内容**（文章、newsletter、播客、长视频）占用 15–60 分钟，建立深度信任和议题所有权
- 健康做法：表现好的短内容再长写。每条跑出来的短帖，都是长文的候选种子

单篇交付里不必每次都讲这套。

## 常见失败（写的时候主动避开）

- 自嗨艺术品：创作者自己爽，市场不在乎
- 无骨架追热点：蹭了话题，没有你的角度
- 人人都同意：没有立场，没有记忆，没有转发
- 通用解释文：换个人也能写，里面没有你
- 受众 = 所有人：等于对谁都没说话
- 钩子吸引错人：播放高，粉不转化
- 方案正确但没用：「坚持更新」「提供价值」
- 视频需求滑到拍摄 / 剪辑 / 设备建议
