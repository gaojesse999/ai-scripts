# 用能力链把行为简化成可靠起点

## R — 原文 (Reading)

> “你是否有足够的时间？你是否有足够的资金？你是否有足够的体力？这个行为是否需要许多创意或脑力？这个行为符合你现在的日程吗？”
>
> — B.J. 福格，第3章「容易做分析」

> “提升技能、获取工具和资源，以及让行为变得微小，都能让事情变得更简单。”
>
> — B.J. 福格，第3章「实现容易做的3种方式」

> “让行为变微小的案例，它们大致可以分为两类：入门步骤、缩小规模。”
>
> — B.J. 福格，第3章「入门步骤与缩小规模」

---

## I — 方法论骨架 (Interpretation)

行为难，不是一个足够精确的诊断；先把困难拆成时间、资金、体力、脑力和日程五个环节。
能力链不是取平均值：任一环弱到无法支持行动，整个行为就难以可靠启动。
因此先找当前情境下的最弱环，再处理它，不用“更自律”掩盖具体摩擦。
可用杠杆只有三类：提升技能；获取工具、协作或其他资源；把行为缩小。
缩小时要区分两种设计：**入门步骤**只完成理想行为的第一个动作；**缩小规模**仍做同类行为，但减少数量、时长或强度。
设计出的**最低启动剂量**只回答“怎样可靠开始”，不等于目标、医疗、安全或合规所要求的**目标验收剂量**。
最低动作可以降低启动门槛，却不能把“已经启动”冒充“已经达标”。
每个方案都只是待检验假设：一次只改一个变量，观察后再保留、替换或转介。

## A1 — 书中的应用 (Past Application)

### 案例 1：演示把“清理浴室”变成可执行动作
- **问题**：丹尼多次要求福格清理浴室，福格却不知道这个抽象任务具体包含什么。
- **方法论的使用**：丹尼现场演示关闭淋浴、用浴巾拖几下地面、把浴巾扔进衣篮，补上“脑力/技能”这一弱环，也把流程压到约 10 秒。
- **结论**：阻力不是态度，而是不清楚怎样做；具体示范比继续催促更有效。
- **结果**：福格此后开始每天清理浴室，并学会在不懂任务时主动请求演示。

### 案例 2：工具与缩小规模共同解决牙线障碍
- **问题**：福格多年无法持续使用牙线，紧密牙缝和不合适牙线让动作费力、挫败。
- **方法论的使用**：他测试多种牙线，找到细滑工具；同时把最低行为缩为只清洁一颗牙。
- **结论**：工具加固了体力/资源环，缩小规模降低了每日启动门槛。
- **结果**：两周多后他经常清洁全部牙齿，并长期保持该习惯。

### 案例 3：先取出滤网，而非一次清完整台咖啡机
- **问题**：迈克要求成年儿子一次完成咖啡机清理的全部步骤，长期引发羞愧、愤怒与冲突。
- **方法论的使用**：他把任务拆开，只要求先取出滤网；这是完整任务的入门步骤，不是假装清洁已经完成。
- **结论**：先建立可成功的入口，再让后续步骤在稳定之后生长。
- **结果**：取滤网逐步扩展为清洗、放回及其他家务，父子关系也得到改善。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 行为已经选定，也知道它有价值，但每次想到完整任务就拖延或放弃。
2. 行为看似只需几分钟，仍反复启动失败，需要定位隐藏的能力瓶颈。
3. 用户要为一次性任务、新习惯或新手流程设计一个安全、可履约的第一步。
4. 任务有不可降低的最终标准，需要把“容易开始”和“最终达标”分开设计。
5. 用户怀疑缺的是技能、工具、协作、预算或日程空间，不想再笼统归因于意志力。

### 语言信号 (用户的话里出现这些就应激活)

- “这件事对我来说太难了，怎么拆小一点？”
- “我知道要做，但就是开始不了。”
- “第一步应该小到什么程度？”
- “帮我找出是时间、钱、体力、脑力还是日程卡住了。”
- “I can't get started.” / “Make this easier.” / “What's the tiny first step?”

### 与相邻 skill 的区分

- 与 `fogg-diagnose-map` 的区别：后者先判断失败来自提示、能力还是动机；本 skill 在能力或感知难度已成为候选瓶颈后，专门设计可靠起点。
- 与 `fogg-select-golden-behavior` 的区别：后者决定“选哪个行为”；本 skill 处理“已选行为怎样更容易开始”。若任何简化方案都不可行，应返回行为选择。
- 与 `fogg-design-anchor` 的区别：本 skill 定义“做多小、怎样变容易”；后者定义“在什么可靠信号之后做”。
- 与 `fogg-grow-habits-adaptively` 的区别：本 skill 只负责**启动**；后者只在行为稳定后处理增量、生长、繁殖与成果复核。不要在本 skill 中把偶尔多做升级为新基线。
- 与 `fogg-untangle-bad-habit` 的组合：本 skill 可让阶段 1 的积极习惯或阶段 3 的替代行为更容易；对旧行为本身，则由后者反向增加能力摩擦。
- 与 `fogg-support-consensual-change` 的组合：帮助他人时，后者先处理同意、权限与结构责任，本 skill 只在共同选定的行为上降低能力门槛。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **把行为和两种剂量写清**
   - 写成可观察动作，并分别记录：`最低启动剂量`（只保证可靠开始）与 `目标验收剂量`（真正满足成果、安全、医疗或合规要求的剂量）。
   - 完成标准：两者各有动作、数量/时长和完成条件，且文案明确“完成最低启动剂量 ≠ 达到目标验收剂量”。
   - 判停条件：若行为仍是“变健康”“认真工作”等抽象愿望，停止本流程，先转入行为选择；若最终标准未知，先向合格负责人确认，不得自行下调。

2. **逐环扫描能力链**
   - 对同一具体时点逐项询问并记录证据：
     - **时间**：最忙时是否仍有连续可用时间？
     - **资金**：费用、现金流或采购权限是否可承受？
     - **体力**：疲劳、疼痛、动作负荷或无障碍条件是否允许？
     - **脑力**：是否知道步骤，需不需要记忆、判断、创意或新技能？
     - **日程**：真实作息中是否有可执行窗口，是否与照护、轮班或其他责任冲突？
   - 完成标准：五环都有“足够/不足/未知”的判定及一条事实依据，并选出一个证据最强的最弱环；并列时写明并列。
   - 判停条件：任何关键环为“未知”时，先收集事实而不猜；若主要障碍是结构性资源、组织制度或他人控制，停止个人归因，转为资源支持、合理便利或制度处理。

3. **为最弱环选择一个杠杆**
   - 只从三类中选择首轮方案：
     1. **提升技能**：示范、练习、模板或即时指导能直接补上不会做；
     2. **获取工具和资源**：设备、材料、自动化、协作者、预算、无障碍支持或受保护时段能直接减摩擦；
     3. **缩小行为**：前两类成本过高、不能立刻获得，或行为在低动机时仍太难。
   - 完成标准：写出“最弱环 → 所选杠杆 → 预计降低的具体摩擦”，并确定本轮只改变一个变量。
   - 判停条件：若所选办法不作用于最弱环，退回本步重选；若只有牺牲安全、治疗效果、劳动权益或合规才能变容易，停止，不实施该方案。

4. **需要缩小时，选择正确类型**
   - **入门步骤**：只做通向理想行为的第一个可见动作，例如打开恢复演练文档并填写第一个依赖项；它适合复杂、多步骤或感知沉重的任务。
   - **缩小规模**：保留行为本质，仅缩短时长、减少数量或降低强度，例如从整理整个桌面缩为收好一件物品；它适合同类动作可以安全缩量的任务。
   - 完成标准：方案被明确标为二者之一，并能在低动机、忙碌状态下完成；继续做是可选项，不是隐含义务。
   - 判停条件：若第一步本身制造危险、不可逆后果或误导性“已完成”状态，停止并重设；若缩量会低于必要剂量，只能使用安全的入门步骤，不能降低验收标准。

5. **做安全、临床、合规与资源闸门**
   - 检查动作本身及其后续默认路径：是否涉及火、电、驾驶、药物、医疗操作、数据/财务权限、法定义务或其他高风险；是否把疾病、疼痛、残障、照护负担、贫困、排班或组织缺陷个人化。
   - 完成标准：标记“可自行低风险试验”或“需专业/组织支持”，并保留所有不可协商标准、授权和复核点。
   - 判停条件：有未控制的风险、需要临床判断、缺少法定授权或资源缺口无法由个人解决时，停止自助试验并转介相应专业人员、负责人或支持渠道。

6. **运行 fm-01 单变量试验**
   - 先记录当前启动基线；在 1–3 个真实机会中只应用步骤 3 选定的一个变化，记录：提示出现时是否能开始、最弱环是否减轻、最低剂量是否完成、是否误以为已经达到验收剂量。
   - 完成标准：至少获得一次真实观察，且能把结果归到这一个被改变变量；记录不评价人格，只描述行为与情境。
   - 判停条件：出现风险、疼痛、明显恶化或标准混淆时立即停止；若多个变量同时改变导致无法归因，本轮作废，恢复为单变量重试。

7. **按证据迭代或转出**
   - 若启动变可靠，保留该设计；若未改善，恢复原设置并对同一最弱环换一个杠杆，或用新证据重排五环。每轮仍只改一个变量。
   - 完成标准：明确作出“保留 / 换杠杆 / 重查能力链 / 返回行为选择 / 转专业或组织支持”之一，并写出依据。
   - 判停条件：连续两轮无改善、无法形成安全起点或关键资源不可得时，停止继续缩小并升级处理；行为稳定后，本 skill 到此结束，增量、繁殖和目标复核转交 `fogg-grow-habits-adaptively`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 还没确定要做哪个行为：先生成并筛选黄金行为；简化一个不匹配的行为只会让错误选择更容易发生。
- 真正问题是提示缺失或动机冲突：先用 B=MAP 验证，不要预设一切失败都是能力不足。
- 行为已经稳定，当前问题是何时加量、是否繁殖新行为或最低动作长期达不到成果：使用 `fogg-grow-habits-adaptively`。
- 严重成瘾、进食障碍、自伤、创伤、躁郁症、重度抑郁、ADHD、显著疼痛或其他临床问题：本流程不能替代诊断、治疗、无障碍支持或专业照护。
- 法律、医疗依从、安全关键操作、灾难恢复等有必要标准的行为：可以简化启动，不能缩减最终标准、检查项、授权或验收。

### 作者在书中警告的失败模式

- **高基线起步**：把理想规模直接设为每日最低标准，忙、累或生病时就跌到行动线下。
- **漏查薄弱环**：因“才几分钟”就断定容易，忽略资金、脑力、体力或日程中的单点瓶颈。
- **基线爬升**：几次自愿多做后立刻抬高最低标准，堵死状态差时仍可进入的起点。
- **复杂首版**：新手一开始就要记住多步、使用多功能或完成全流程，学习成本和出错点同时上升。
- **忽视感知难度**：用“这其实很简单”与用户争辩，而不设计可见的第一步。

### 作者的盲点 / 时代局限

- 书中大量成功材料来自作者本人、学员和训练营自述，缺少充分的对照、效应量和长期随访；能力链应作为产生假设的工具，而非已证明的通用定律。
- 时间、资金、日程和体力不足常来自轮班、照护、贫困、残障、老旧系统或组织制度。此时责任在资源和制度设计，不应把“无法简化”归咎于个人。
- “微小成功会自然长大”没有保证。最低启动剂量若长期未贡献目标所需剂量，必须复核成果和支持条件，不能用持续启动掩盖未达标。

### 容易混淆的邻近方法论

- **入门步骤不等于缩小规模**：前者只做开头，后者仍完成同类行为的较小版本。
- **启动成功不等于目标达成**：最低启动剂量是入口指标，目标验收剂量才是成果、安全或合规指标。
- **个人技巧不等于结构修复**：工具和资源包括组织支持；若资源分配权不在个人，输出应是升级请求，不是自律建议。
- **启动简化不等于习惯增长**：本 skill 不规定升级节奏，也不把额外完成量固化为新底线。
