# 在自主与成功感约束下帮助他人改变

## R — 原文 (Reading)

> “帮助人们做他们已经想做的事。”
>
> — B.J. 福格，第8章「改变他人必须坚持两项原则」

> “帮助人们感受成功。”
>
> — B.J. 福格，第8章「改变他人必须坚持两项原则」

> “创新者往往会试图同时掌控所有4个分区……这两种方式都是错误的。”
>
> — B.J. 福格，第8章「共同排除障碍和重复」

> “如果当别人达成了某个重大里程碑时才给予反馈，那就错过太多可以帮助人们感受‘发光’的机会了。”
>
> — B.J. 福格，第8章「庆祝成功以巩固习惯」

---

## I — 方法论骨架 (Interpretation)

本方法只处理“帮助别人或群体改变”，不接管个人为自己设计习惯的任务。
第一道门不是选技巧，而是区分可协商行为与合法必要行为；两者不能借“自愿”或“合规”互相伪装。
可协商行为以当事人的已有愿望为起点：先取得可理解、可撤回的知情同意，并保留拒绝、暂停和退出权。
必要行为不能假装成自由选择；必须说明法律、医疗、安全或职责依据，公开不可协商的最小边界，并接受比例、权限与程序审查。
即使结果必要，执行路径仍应尽量提供替代方案、无障碍支持、申诉渠道和对等尊重，不能用羞耻或秘密设计换服从。
有限支持资源优先给“已经想做但能力不足”的人，而不是先围攻既无动机又无能力的最抵触者。
行为、提示和反馈由双方共同选择；帮助者提供选项与排障，不替对方定义愿望或抢走控制权。
反馈只针对刚发生的具体动作，必须即时、具体、真实；不夸大、不比较人格，也不等重大里程碑才肯定。
行为设计只能解决行为层瓶颈；排班、人手、收入、权限、歧视、照护负担等结构问题必须由相应责任主体处理。
所有方案都按共享 fm-01 协议运行：小范围试点、每轮只改一个变量、预设可回退点并记录结果，不把个案相关性说成普遍因果。

## A1 — 书中的应用 (Past Application)

### 案例 1：把咖啡机清理缩成可成功的第一步

- **问题**：迈克长期用唠叨和威胁要求成年儿子克里斯完成整套咖啡机清理，任务与关系都持续恶化。
- **方法论的使用**：他停止加压，把任务共同聚焦到“取出滤网”这一个可完成动作；克里斯做到后，他立即说出该动作对自己的具体意义并真诚感谢。
- **结论**：对一个愿意改善生活却被多步任务压垮的人，降低能力门槛和提供真实成功反馈，比继续提升压力更合适。
- **结果**：书中报告，行为后来扩展到清洗、放回及其他家务，克里斯找到兼职并存钱搬家，父子关系改善；这是家庭个案，不证明单一技巧必然导致全部结果。

### 案例 2：母女共同设计作业习惯

- **问题**：有多动症的瑞秋难以专注完成作业，母女冲突增加；单由母亲要求成绩并不能形成可靠行为。
- **方法论的使用**：埃米先找到女儿自己的愿望——与同学同步升学；两人共同试验10分钟任务、5分钟蹦床、不同工具与时机，并由瑞秋参与选择锚点和庆祝方式。
- **结论**：帮助者应支持当事人已有愿望、共同排除能力障碍，并逐步把调整权交还给当事人。
- **结果**：书中报告，瑞秋后来脱离特殊教育班、进入进阶课程并顺利毕业，时间管理和母女关系改善；ADHD 属临床范畴，此案例不能把微习惯当作诊断或治疗替代品。

### 案例 3：护士共同设计减压微习惯

- **问题**：医院护士在12小时轮班中面临少喝水、少休息与倦怠，通用健康建议难以嵌入真实工作。
- **方法论的使用**：护士共同列出工作中的真实锚点和减压行为，自由组合配方，并用掌声、击掌和简短肯定回应彼此的微小完成；项目进行了培训前后测。
- **结论**：群体方案应让参与者共同选择行为和提示，并把成功反馈贴近实际动作。
- **结果**：书中报告多项自评指标统计显著改善；不能据此声称护士微习惯解决了人员配置、排班、软件、饮水条件或组织文化造成的结构性倦怠。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 家长、伴侣、教练或照护者想帮助某人改变，但不想把自己的愿望强加给对方。
2. 管理者、教师或产品团队要推动一组可协商行为，需要设计透明参与、选择与退出机制。
3. 对方已经表达改变愿望，却被时间、工具、技能、认知负荷、环境或日程卡住。
4. 组织必须落实合法的安全、医疗、照护或合规行为，需要划清不可协商边界，同时保留替代路径与申诉程序。
5. 团队想共同选择具体行为、提示和反馈方式，并用小范围试点检验设计。

### 语言信号

- “我怎么帮助他改变，又不变成控制他？”
- “对方想做但总做不到，我能怎么支持？”
- “如何推动团队采用这个流程，同时保留选择和退出权？”
- “这是强制合规要求，怎样透明、合比例地实施？”
- “How can I help someone change without coercing them?”
- “Design consensual behavior change for a team.”
- “How should we implement a mandatory behavior fairly?”

### 与相邻 skill 的区分

- 与 `fogg-select-golden-behavior` 的区别：后者选择“做什么”；只要执行者是他人或群体，本 skill 的同意、权力与必要行为分流先行，并约束共同选择。
- 与 `fogg-diagnose-map` 的区别：后者诊断具体行为为何发生或没发生；本 skill 先判断帮助者是否有正当权限、当事人是否同意，以及该不该使用行为设计。
- 与 `fogg-simplify-action`、`fogg-design-anchor`、`fogg-reinforce-with-shine` 的区别：这些方法分别处理能力、提示与成功感；本 skill 决定它们能否被伦理地用于他人，并要求共同选择和真实反馈。
- 与个人改变 skills 的区别：若用户是在设计自己的习惯，即使方法相同，也不触发本 skill；只有帮助他人或群体时才触发。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 必须按顺序执行：

1. **先分流：可协商行为还是合法必要行为**
   - 写明行为、执行者、受益者、决定者、帮助者的权限来源，以及不执行的实际后果。
   - 只有法律、合格专业标准、真实安全风险或明确职责能支持“必要”标签；组织偏好、管理便利、增长指标和家长焦虑不能自行冒充必要性。
   - **完成标准**：输出“可协商 / 合法必要 / 依据不足待核实”之一，并列出依据、权力关系与可争议点。
   - **判停条件**：依据不明、权限越界、必要性存在重大争议或可能违法时，不进入行为设计；先由合格法务、医疗、安全、伦理或治理主体核实。

2. **检查硬边界与结构性责任**
   - 检查亲子、雇佣、医疗、教育、照护等权力不对等；隐私与数据最小化；秘密提示、默认勾选、诱导退出等暗黑模式；临床问题；以及人手、排班、收入、权限、无障碍、歧视等结构性问题。
   - 把个人可做动作与组织、制度或资源责任分开列出，明确谁有能力改变条件。
   - **完成标准**：形成“可继续的行为层问题 / 必须同步处理的结构问题 / 不得使用行为设计的问题”三栏清单，并为每项标责任主体。
   - **判停条件**：若方案依赖秘密收集敏感数据、剥夺实质退出、利用脆弱性或掩盖违法和结构性伤害，立即停止；护士倦怠等问题不得被归结为个人微习惯不足。

3. **为可协商行为取得知情同意并确认已有愿望**
   - 用对方能理解的语言说明目的、方法、收集的数据、可能影响、替代选项、暂停和退出方式；确认拒绝不会带来隐性惩罚。
   - 询问对方本来想改变什么、为什么，以及愿意接受何种帮助；帮助者的目标只能作为候选，不能替代当事人的回答。
   - **完成标准**：有当事人的明确同意、用其原话记录的已有愿望、可执行退出方式和拒绝后果说明。
   - **判停条件**：没有同意、同意受威胁或信息不充分、对方没有该愿望或已撤回时，停止设计；不得转用社交压力、奖金威胁或默认同意。

4. **为合法必要行为建立透明且合比例的程序**
   - 明说哪些结果不可协商、依据是什么、最低必要范围是什么；不把强制包装成“你自愿选择”。
   - 检查干预是否与风险相称、是否存在侵害更小的替代路径，并提供无障碍支持、合理便利、申诉、复核和例外申请渠道。
   - 可共同选择执行时间、工具、提示或支持方式，但不得降低专业、安全或法定验收标准。
   - **完成标准**：产出“不可协商边界 + 依据 + 比例说明 + 至少一个替代执行路径 + 申诉/复核入口 + 数据规则”。
   - **判停条件**：没有真实依据、没有申诉或合理替代、手段明显过度、歧视性影响未评估时，不实施；转交有权限的治理主体修正。

5. **按动机与能力分区，优先支持想做但做不到者**
   - 分别确认执行者是否已有动机、当下是否有能力；不根据沉默、职位或点击行为猜测动机。
   - 首轮支持优先给“有动机、能力不足”的人，排查时间、资金、体力、脑力、工具、技能和日程；已能做到者无需过度干预。
   - 对可协商行为中既无动机又无能力者，不以有限资源反复说服；对必要行为则回到步骤4补透明说明与能力支持，而不是放弃标准。
   - **完成标准**：每个目标群体有“动机证据 / 能力证据 / 支持优先级 / 不确定项”，并选定一个首轮小群体。
   - **判停条件**：只能靠刻板印象分区或计划同时覆盖所有人时，先补访谈与观察；不得把抵触自动诊断为懒惰。

6. **共同选择一个行为、一个提示和一种反馈**
   - 与执行者共同生成候选，选择其已有愿望支持、当下可做且安全的一个具体行为；必要行为只微小化启动步骤或降低摩擦，不降低最终标准。
   - 共同选取真实日程中可感知、出现时有能力行动的提示；允许个体选择不同提示，不用通知轰炸。
   - 询问何种反馈让对方自然感到成功；反馈句式为“刚才你完成了[具体动作]，[真实影响]”，不用夸张表扬、人格评价、公开排名或比较。
   - **完成标准**：由执行者确认一张配方卡：`行为 / 最低安全版本 / 提示 / 反馈方式 / 谁反馈 / 可拒绝项`。
   - **判停条件**：行为并非本人愿意、提示侵犯隐私、反馈显得虚假尴尬，或必要标准被削弱时，不启动；返回共同选择。

7. **按 fm-01 做小范围、单变量、可回退试点**
   - 先记录基线，再明确本轮唯一改动是行为、提示、能力支持或反馈中的哪一个；设定短观察窗口、成功指标、副作用指标和回退触发条件。
   - 只收集完成试点所需的最少数据，优先聚合或匿名记录；说明谁可见、保存多久、如何删除。
   - 记录格式：`基线 → 唯一改动 → 观察机会/时窗 → 结果 → 副作用/差异影响 → 保留或回退`。
   - **完成标准**：有小范围参与者、单一自变量、可观察指标、隐私规则、回退方案和复盘日期。
   - **判停条件**：同时修改多个变量、没有基线、无法退出或无法回退时，不得声称因果；试点作废、恢复原状并重新设计。出现伤害、羞耻、报复风险或不平等影响时提前停止。

8. **只给即时、具体、真实反馈并复盘**
   - 在动作完成后尽快反馈，只描述真实完成及可核实影响；对未完成先排查设计，不批评人格。
   - 到复盘日分别检查：行为是否发生、执行者是否仍同意、是否感到受控、是否出现隐私或差异影响、结构性问题是否被推进。
   - 每轮只做“保留 / 回退 / 换一个变量 / 扩大一点 / 转专业或治理支持”之一；扩大试点前重新确认同意与程序保障。
   - **完成标准**：至少一条真实即时反馈记录和一份含行为、体验、伦理、结构责任四类结果的复盘决定。
   - **判停条件**：目标达到即停止加码；反馈不真实、对方撤回、收益不抵成本、结果无法归因或结构伤害持续时，不扩大并执行回退或转介。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **个人自我改变**：用户只是在设计自己的习惯，应调用个人行为选择、简化、提示、强化或坏习惯 skills；本 skill 只在帮助他人或群体时触发。
- **权力不对等且无实质同意**：亲子、雇佣、医疗、教育、照护与平台关系中，形式上的“同意”若伴随惩罚、利益损失或无法退出，不可视为自愿。
- **隐私与监控越界**：不得秘密采集健康、位置、情绪、绩效或行为数据；不得以帮助为名扩大监控、二次使用或无限期保存。
- **暗黑模式与成瘾设计**：不得利用红点、无限内容、默认勾选、隐藏退出、社交压力或即时愉悦让人做事后后悔且难以停止的行为。
- **临床问题**：ADHD、成瘾、进食障碍、自伤、创伤、躁郁症、重度抑郁、精神病性症状、戒断风险及其他诊疗问题，不能用本 skill 替代合格专业评估、治疗或危机支持。
- **结构性问题占主导**：倦怠、人手不足、危险排班、贫困、照护负担、歧视、无障碍与权限问题必须由制度和资源责任者处理；个人微习惯最多是自愿辅助，不能充当完整解法。
- **违法或不合比例的强制**：缺少法律/专业依据、没有正当权限、手段过度或没有申诉与替代路径时，不能借“必要行为”实施。

### 作者在书中警告的失败模式

- **强迫他人改变（ce47）**：由帮助者替当事人定义愿望，再靠压力维持行为；失败会损伤信心与关系。
- **在脆弱的强力区给负面反馈（ce50）**：当对方高度在意但缺乏把握时，权威的批评、比较和抢夺控制权会被放大。
- **资源先投向无动机人群（ce51）**：同时覆盖所有分区或先围攻最抵触者，会忽略真正想做但被能力卡住的人。
- **把设计用于操控和成瘾（ce53）**：简单、提示和情绪强化若只服务点击、停留和服从，就可能变成暗黑模式。
- **用社交压力压过真实恐惧（ce58）**：起哄、公开参与、命令或奖金威胁只能制造表面配合，不能替代愿望与能力匹配。
- **只在重大里程碑反馈（ce60）**：反馈太晚、太稀疏，错过对正在形成的具体行为提供成功证据。

### 作者的盲点 / 证据边界

- 书中群体与家庭案例多为作者、学员或项目自述，存在选择偏差、回忆偏差、混杂变量和长期随访不足；应当作低风险试点启发式，不是普遍因果定律。
- “帮助人们做其已想做之事”不足以覆盖合法必要行为，后者还需要法律、专业、比例、程序正义、合理便利和申诉框架。
- 书中对权力、隐私、残障、劳动条件、算法操控和结构性不平等讨论不足；同意不能仅靠一次口头确认，组织设计必须接受持续伦理与治理审查。
- 护士项目中的自评改善不能证明微习惯解决结构性倦怠；排班、人手、工作量、软件、饮水条件和组织文化仍需独立评估与整改。
- 即时积极反馈可能与行为同时出现但不必然是长期改变的唯一原因；每轮只改一个变量并记录失败条件，避免过度归因。

### 容易混淆的邻近方法论

- **支持自主不等于放弃必要标准**：可协商行为允许拒绝；合法必要行为保持最低标准，但必须透明、合比例、可申诉，并尽可能提供替代执行路径。
- **共同选择不等于帮助者预选答案**：提供菜单可以，隐藏默认、诱导选项或以权力制造“本人愿意”不可以。
- **即时反馈不等于奖励操控**：反馈描述真实具体动作和影响，不以金钱、积分、排名或虚假赞美换服从。
- **微小化启动不等于微小化验收**：安全、医疗、照护与法律行为可以降低启动摩擦，不能降低最终专业标准。
- **行为层支持不等于结构性治理**：喝水、呼吸或短休息可以作为护士自愿支持，但不能替代人员配置、排班和劳动条件改革。
