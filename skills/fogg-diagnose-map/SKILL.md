# 用 B=MAP 诊断行为并选择干预杠杆

## R — 原文 (Reading)

> “当动机、能力和提示同时出现的时候，行为就会发生。三者缺一不可，否则，行为就不会发生。”
>
> — B.J. 福格，第1章「3要素齐备，行为才能发生」

> “如果其中一方较弱，那另一方就需要很强才能促进行动，让行为落到行动线上方。”
>
> — B.J. 福格，第1章「福格行为模型的4个原则」

> “1．检查有没有行为提示。2．检查有没有行为能力。3．检查有没有行为动机。”
>
> — B.J. 福格，第1章「解决行为问题的3个步骤」

> “如果无法改变某个行为要素（如动机），那你可以改变其他要素（能力或提示）。”
>
> — B.J. 福格，第1章「福格行为模型」

---

## I — 方法论骨架 (Interpretation)

- 分析单位不是人格或抽象目标，而是“某人在某个情境与时刻做出的一个可观察行为”。
- `B=MAP` 表示行为出现时，动机（Motivation）、能力（Ability）与提示（Prompt）在同一时刻形成了足够组合。
- 提示回答“为什么是现在”，能力回答“当时做起来有多容易”，动机回答“当时有多想做或不做”。
- 动机与能力可在一定范围内互补：越容易的行为，越不需要依赖高动机；越困难的行为，越依赖动机峰值。
- 对想要的行为，诊断目标是找到把它推到行动线之上的可调条件；对不想要的行为，则寻找能把它推到线下的条件。
- 默认排障顺序是先提示、再能力、最后动机，因为前两者通常更具体、可观察、可调整。
- 每次只形成一个可被观察推翻的瓶颈假设，并只修改一个 MAP 杠杆，避免无法判断究竟什么起了作用。
- `B=MAP` 是生成与检验干预假设的诊断启发式，不是科学定律；变量宽、测量弱，不能把事后解释当成因果证明。

## A1 — 书中的应用 (Past Application)

### 案例 1：红十字会短信募捐
- **问题**：人们即使关心海地地震，也未必把捐款意愿转成当场行动。
- **方法论的使用**：灾难报道提供较强动机，短信把捐款变成容易完成的动作，并在可操作的时刻给出提示，三个要素同时汇合。
- **结论**：无需继续教育或劝说；关键组合是已有动机、低摩擦动作与适时提示。
- **结果**：书中报告募捐活动在 24 小时内筹得 300 多万美元，一周后超过 2100 万美元。
- **出处**：第1章「3要素齐备，行为才能发生」。

### 案例 2：莫莉重新设计每周备餐
- **问题**：莫莉想带健康午餐，但五小时备餐与决策疲劳让行为反复失败。
- **方法论的使用**：她没有加码意志力，而是把瓶颈定位在能力，借助未婚夫的技能与协作、切片器等工具，降低时间、体力和脑力负担。
- **结论**：当提示和动机已有基础时，补强能力链比继续激励更合适。
- **结果**：备餐时间减半，几个月后每周可稳定准备 10 份餐食。
- **出处**：第3章「获取工具和资源」。

### 案例 3：不在家中储存冰激凌
- **问题**：晚间吃冰激凌的动机难以稳定削弱，家中现货又让行为过于容易。
- **方法论的使用**：福格和丹尼不先处理欲望，而是取消家庭库存，让购买额外消耗时间和体力。
- **结论**：对不想要的行为，增加能力摩擦也能把它推到行动线下。
- **结果**：即时取食变难，许多欲望在真正购买前消退；书中未给出精确频次。
- **出处**：第7章「重新设计能力以终止习惯」。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill？

1. 已明确一个想做的行为，但它在特定时刻反复没有发生。
2. 一个不想要的具体行为总在相似情境中自动发生，用户想定位最小干预点。
3. 团队已做宣传、培训或奖惩，实际行为率仍低，需要判断问题究竟在提示、能力还是动机。
4. 用户在“加提醒、降难度、提高动力”之间犹豫，希望先用观察证据选择杠杆。
5. 一次性高动机窗口已经出现，需要判断能否趁机完成降低未来摩擦的动作。

### 语言信号（用户的话里出现这些就应激活）

- “我明明很想做，为什么到时候还是没做？”
- “为什么我一看到这个就会忍不住？”
- “应该再提醒一次、把步骤变简单，还是想办法提高动力？”
- “大家都知道这很重要，为什么培训后还是没人做？”
- “Why didn't the behavior happen?” / “What is the MAP bottleneck?”
- “Should I change motivation, ability, or the prompt?”

### 与相邻 skill 的区分

- 与 `fogg-select-golden-behavior` 的区别：若只有“变健康、提高效率”等愿望，尚无具体行为，先生成并筛选行为；本 skill 只诊断已经明确的行为。
- 与 `fogg-simplify-action` 的区别：本 skill 判断能力是否为当前优先杠杆；一旦确认要系统分析时间、资金、体力、脑力、日程并设计简化方案，转交该 skill。
- 与 `fogg-design-anchor` 的区别：本 skill 判断提示是否缺失、错时或不可见；一旦确认要设计与日程匹配的锚点及最后动作，转交该 skill。
- 与 `fogg-untangle-bad-habit` 的区别：本 skill 可诊断一个具体的不想要行为；若“坏习惯”其实是一组行为、涉及替代或分阶段终止，应先拆结并使用该 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行。共享执行协议贯穿全程：**可观察假设 → 每轮只改一个 MAP 杠杆 → 观察再迭代**。

1. **把问题锁定为一个具体行为事件**
   - 写成：`在[情境/时刻]，[谁]是否完成[可观察动作]`，并注明这是想增加还是想减少的行为。
   - 记录最近至少一个发生或未发生的实例；区分事实与推测，不使用“懒、自律差、不重视”等人格标签代替行为描述。
   - **完成标准**：陌生观察者能仅凭描述判断行为是否发生，且一次只含一个动作与一个关键时刻。
   - **判停条件**：若仍是愿望、成果或一组概括型行为，停止 MAP 诊断，转交 `fogg-select-golden-behavior` 或 `fogg-untangle-bad-habit`。

2. **先做硬边界分流**
   - 检查是否涉及严重成瘾、进食障碍、自伤、创伤、躁郁症、重度抑郁、ADHD 等临床问题；是否涉及医疗、安全、法律合规等不得降低的标准；是否主要受贫困、排班、歧视、照护负担、设备或组织制度等结构性约束。
   - **完成标准**：明确写出“可继续个人行为试验”或“必须转介/升级”，并给出依据。
   - **判停条件**：命中临床或安全边界时停止把 MAP 当作主要处方，建议专业支持或遵循强制标准；结构性因素占主导时停止个人化归因，升级到资源、流程或制度干预。

3. **按提示 → 能力 → 动机生成单一瓶颈假设**
   - **提示**：当时是否出现了可察觉、含义明确且到达时可行动的信号？若没有、错时或被忽略，先假设提示是瓶颈。
   - **能力**：若提示有效，检查当时是否有足够时间、资金、体力、脑力、技能、工具和日程空间；任一关键阻力都可构成能力瓶颈。
   - **动机**：只有提示与能力已有观察支持时，才检查当下欲望强度、相互冲突的动机、恐惧或回避；不能把口头认同等同于当时动机。
   - 把假设写成：`若只改变[一个 MAP 杠杆]，则在[观察窗口]内，[具体行为指标]会[预期变化]；若无该变化，假设暂不支持。`
   - **完成标准**：得到一个含干预、时间窗、可观察指标和失败条件的假设，并列出支持它的实例证据。
   - **判停条件**：若证据已经显示提示缺失，不继续推测能力或动机；若没有任何可观察实例，先收集基线，不进入干预。

4. **只调整当前优先级最高的一个杠杆**
   - 想增加行为：先补齐或校准提示；提示无碍再降低行为难度；二者无碍才尝试处理动机。
   - 想减少行为：先移除、规避或改变提示；提示不可控再增加时间、体力、脑力等摩擦；前两者不可行或无效才处理动机。
   - 本轮不得同时新增提醒、简化步骤并追加奖惩；若需要专门设计，转交对应相邻 skill，但该轮仍只实施一个杠杆变化。
   - **完成标准**：记录唯一改动、保持不变的条件、开始时间、观察次数或截止日期，以及成功指标。
   - **判停条件**：若改动会降低安全/合规标准、操控未同意的他人，或代价明显超过预期收益，取消本轮并返回步骤 2。

5. **观察结果并用共享协议迭代**
   - 到达预定观察窗口后，对比基线与本轮结果，同时记录副作用和情境变化；只报告“假设得到支持、暂不支持或证据不足”，不宣称证明了因果定律。
   - 若行为向目标方向稳定变化，保留该改动并结束诊断，或转交对应 skill 做精细化设计。
   - 若无变化，保留观测记录，一次只换下一个 MAP 假设，继续遵循提示 → 能力 → 动机的顺序。
   - **完成标准**：形成一条审计记录：`行为定义 → 基线 → 单一假设 → 唯一改动 → 结果 → 下一决定`。
   - **判停条件**：达到用户预设目标即停止；命中硬边界立即停止；连续多轮均无清晰信号、观察条件无法稳定或副作用上升时，停止 MAP 微调并重新定义行为、检查结构因素或寻求专业评估。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 只有抽象愿望或结果指标，没有某个时刻可观察的具体行为；MAP 无法直接诊断“变健康”“更自律”。
- 严重成瘾、进食障碍、自伤、创伤、躁郁症、重度抑郁、ADHD 等临床问题；不得用本 skill 替代专业诊断、治疗或危机支持。
- 医疗依从、安全操作、法律合规等高风险任务；可降低启动摩擦，但不能缩减必要标准或绕过安全程序。
- 贫困、轮班、歧视、照护负担、设备缺失、工作制度等结构性因素是主要约束；应优先改变资源与制度，不能把系统问题归咎于个人 MAP。
- 对未同意的他人进行隐性提示、奖惩、恐惧、羞耻或环境操控；尤其在亲子、雇佣、医疗等权力不对等关系中。

### 作者在书中警告的失败模式

- **先操作动机**：一看到迟到、漏做或低参与，就先训话、奖励、罚款或制造恐惧，未先检查提示和能力。
- **把动机当稳定常量**：用今天的热情预测未来持续投入，忽略动机波动、冲突与不透明。
- **用人格解释失败**：把一次未做归因于懒惰、缺乏意志力或“不够重视”，遮蔽可调整的行为条件。
- **同时修改多个变量**：即使结果改善，也无法知道哪个变化有效，下一轮不能可靠复用。

### 作者的盲点 / 证据局限

- B=MAP 的三个变量覆盖面宽、量化弱，容易对任何结果做事后解释；必须提前写出可观察预测和失败条件。
- 书中许多证据来自作者、学员和项目参与者自述，成功案例可能有选择与回忆偏差，不能外推为普适因果结论。
- “提示优先、能力其次、动机最后”是低成本排障默认值，不是所有情境的绝对顺序；疼痛、价值冲突、临床障碍或外部强制可能改变优先级。
- MAP 能提示个体层面的可调条件，但不足以衡量组织权力、社会资源和平台算法等结构性原因。

### 容易混淆的邻近方法论

- MAP 负责**诊断并选择杠杆**，不负责替用户从抽象愿望中选择值得做的行为。
- “能力不足”是诊断结论；能力链分析、工具选择和微小化属于后续简化设计。
- “提示有问题”是诊断结论；地点、频率、主题、锚点与最后动作属于后续提示设计。
- 对概括型坏习惯直接画一张 MAP 会混合多个情境，应先拆成逐一可诊断的具体行为。
