# 维度 3：术语体系与表达 DNA

## 0. 研究边界与标注约定

本文件只研究《福格行为模型》主题 Skill 所需的术语和表达方式，不撰写最终 `SKILL.md`，也不替作者的实证主张做独立科学背书。

- **主语料**：`references/sources/books/fogg-behavior-model.txt`，简体中文版电子书文本。本文引用其行号，称为“中译本原句”，不把译文冒充英文原文。
- **英文核对**：只使用 BJ Fogg 官方网站、Fogg Behavior Model 官方站和 Tiny Habits 官方材料。称为“官方英文表述”。
- **推断**：从跨章节样本归纳出的写作规律，均明确标为“风格推断”或“使用建议”。
- **抽样方式**：目的性抽样，覆盖中文版序、前言、模型、动机、能力、提示、庆祝等主要部分，共 26 组段落。用于识别稳定风格，不做机械词频统计，也不声称统计代表性。

## 1. 核心术语对照：定义、边界与语义漂移

### 1.1 aspiration / outcome / behavior

#### Aspiration

- **中译本译法**：愿望。
- **中译本定义**：“愿望是抽象的欲望”，例如“想让孩子在学校取得成功”（1928–1942）。
- **官方英文补充**：官方材料把 aspiration 与 “enduring” 连用，即较持久、较高层的期望方向，而非一时念头。  
  来源：https://tinyhabits.com/purpose/
- **边界**：它可以启动行为设计，但不是能在某一时刻直接执行的动作，也不等于某个可量化指标。
- **可能漂移**：“愿望”在中文里容易被理解成短暂心愿或愿望清单；Fogg 此处常指较持久、抽象的理想方向。Skill 首次出现时宜写成“愿望（aspiration，持久而抽象的期望方向）”，后文再简称“愿望”。不要擅自统一成“目标”，因为作者明确排除语义含混的 goal（1953–1957）。

#### Outcome

- **中译本译法**：成果。
- **中译本定义**：比愿望更容易衡量，例如“第二学期取得‘优’的成绩”（1938–1942）；“存入 500 美元应急资金”仍是成果，不是行为（1959–1969）。
- **边界**：它是可观察或可衡量的结果状态，仍不能“现在就做”。
- **可能漂移**：“成果”在中文里常带有“已经完成、积极成就”的意味，而 outcome 是中性的预期结果，也可能未达成或不理想。Skill 可在定义处补“预期成果/可衡量结果”，但引用书中术语时保留“成果”。

#### Behavior

- **中译本译法**：行为。
- **中译本定义**：现在或某个特定时刻可以做的事情，如关掉手机、吃一根胡萝卜、打开书读几页（1945–1951）。
- **官方英文表述**：行为发生于 Motivation、Ability、Prompt 在同一时刻汇合；若行为没发生，至少缺少一个要素。  
  来源：https://www.behaviormodel.org/
- **边界**：行为可以是单次行为，也可以被重复并逐渐自动化；behavior 本身不等于 habit。
- **可能漂移**：中文“行为”有时像宏观行为模式或道德评价。Fogg 要求的是可执行、可定位到时刻的具体动作。Skill 应优先使用“具体行为/目标行为”，并用“现在能不能做？”检验其是否真是 behavior。

#### 三者的最小辨别法

1. 抽象、持久、方向性的想要 → **愿望（aspiration）**。
2. 可衡量但不能立即执行的结果 → **成果（outcome）**。
3. 某人能在明确时刻完成的具体动作 → **行为（behavior）**。

**禁止混用**：不要把“减肥”“改善睡眠”“更专注”直接称作行为；也不要把“每天晚饭后步行 5 分钟”称作成果。

### 1.2 motivation / ability / prompt

#### Motivation

- **中译本译法**：动机；部分叙述偶尔写“动力”，宜视为普通语言，不另立术语。
- **中译本定义**：做出某个特定行为或某类行为的欲望（1721–1728）；会冲突、波动，且通常不可可靠维持。
- **官方英文补充**：Motivation 与 Ability 是补偿关系；动机高时能做较难的行为，动机下降后通常只会做容易的行为。  
  来源：https://www.behaviormodel.org/motivation
- **可能漂移**：中文“动机”容易被当成深层人格原因，“动力”容易被当成能量；这里是**特定时刻对特定行为的想做程度**。它不等于意志力、品格或 aspiration。

#### Ability

- **中译本译法**：能力；定义处写“去做某个行为的执行能力”（1090–1092）。
- **中译本展开**：时间、资金、体力、脑力/创意、是否符合日程五个因素构成“能力链”，最薄弱环决定难度（2722–2744）。
- **官方英文补充**：Fogg 有时以 Simplicity 替换 Ability；提高 Ability 的实务含义通常是“让目标行为更容易做”。Simplicity 取决于当时最稀缺的资源。  
  来源：https://www.behaviormodel.org/ability
- **可能漂移**：中文“能力”容易让人想到稳定技能或个人素质，从而重新归责于人。Fogg 的 Ability 更接近**当下可执行性/容易程度**，技能只是其中一条路径。Skill 宜写：“能力（Ability，即此刻做起来有多容易）”。诊断时问“什么让它难做？”，不要问“你有没有能力？”

#### Prompt

- **中译本译法**：提示；旧版 Trigger 译为“触发/触发器”。
- **中译本定义**：提醒你做出行为的信号（1090–1092）；“没有提示，就没有行为”（1307–1320）。
- **官方英文表述**：Prompts tell people to “do it now!”；官方明确说明 2017 年末由 Trigger 改称 Prompt。  
  来源：https://www.behaviormodel.org/prompts
- **可能漂移**：“提示”可能被误解为提供信息或温和建议，缺少“此刻行动”的时间性。Skill 应在定义中补“现在就做的信号”。不要继续把 B=MAP 写成 B=MAT。
- **分类版本风险**：
  - 中译本第 4 章按 PAC 分为**人物提示、情境提示、行动提示**（3396–3403）。
  - 当前官方 Prompt 页面列出 **Facilitator、Signal、Spark** 三类。
  - 这是不同切分维度/版本材料，不能拼成同一张“三类提示”表。围绕《Tiny Habits》个人习惯流程时优先使用书中的人物/情境/行动提示；讨论通用行为设计的 prompt 功能时可注明官方页面的另一分类，但必须标版本与来源。

### 1.3 anchor / celebration / Shine

#### Anchor / Anchor Moment

- **中译本译法**：锚点 / 锚点时刻。
- **中译本定义**：锚点是生活中已经稳固的事情，本质上是作为提示的既有日程或行动（3551–3556）；“锚点时刻”强调一个确切时间点（3690–3693）。
- **官方英文表述**：an existing routine；之所以称 anchor，是因为它是生活中稳定、坚固、可附着新习惯的东西。好锚点与新行为匹配频率、地点和主题。  
  来源：https://tinyhabits.com/good-spot/
- **可能漂移**：“锚点”在中文产品语境里常指静态位置、记忆点或心理暗示。这里首先是**既有例程结束的确切动作时刻**，且它在 B=MAP 中承担 Prompt 的功能。模糊的“晚饭后”不如“把餐具放进洗碗机后”。

#### Celebration

- **中译本译法**：庆祝 / 即时庆祝。
- **中译本定义**：完成微行为后立刻做的、能带来积极情绪的事情（961–976）；可说、可做、也可在心中完成（4597–4601）。
- **官方英文表述**：something you think, say, and/or do to make yourself feel a positive emotion；紧接新微行为之后进行。  
  来源：https://tinyhabits.com/purpose/
- **可能漂移**：中文“庆祝”容易联想到公开、隆重、外在奖励。Fogg 的 celebration 可以只是微笑、点头或心里说“干得不错”，重点是**立即创造真实的积极感受**。它不是两周后按摩或晚上看电影式延迟“奖励”。

#### Shine

- **中译本译法**：发光；上下文也反复释为“成功的感觉/感受成功/发光之感”（4597–4660）。
- **中译本定义**：英语没有完美词描述“体验成功之后的积极感受”，最接近“真心感到自豪”，作者因此命名为 Shine（4597–4612）。
- **概念边界**：
  - Celebration 是为了产生感受而做的**动作/想法/话语**。
  - Shine 是庆祝有效时产生的**内在成功感**。
  - 两者不是同义词，也不是“奖励”。
- **可能漂移**：“发光”在中文更像外表耀眼、被人看见或自我表现，不能自然指向内在成功感。Skill 首次出现宜写“发光感（Shine，即真实的成功感）”，不要只写“发光”；后续用“发光感”比“发光”更稳。

### 1.4 其他高复用术语

- **B=MAP / 福格行为模型**：Behavior happens when Motivation, Ability, and a Prompt come together at the same moment。三要素是同时汇合，不是先后步骤。
- **Action Line / 行动线**：动机—能力平面上的阈值曲线；点在线上方时，提示到来后行为发生。中文“行动线”可能被误解成行动顺序线，定义时应说明“发生阈值”。
- **Tiny Behavior / 微行为**：目标行为缩小后的最小可执行版本。它还不必然是习惯。
- **Tiny Habit / 微习惯**：以锚点提示、微行为和即时庆祝设计出的习惯方法/逐渐自动化的行为。中译本叙述中“微行为”和“微习惯”偶有滑移，Skill 应严格区分“设计单元”和“自动化结果”。
- **ABC 三步骤**：Anchor—Behavior—Celebration。它是微习惯的应用配方，不是 B=MAP 的替代模型（958–976）。
- **Recipe / 配方**：官方完整格式为 “After I …, I will … Then, I celebrate!”；中译本第 4 章为突出提示时常只写前两句。Skill 给完整模板时应保留第三部分。  
  来源：https://tinyhabits.com/wp-content/uploads/2020/10/tinyhabits-recipe-cards.pdf
- **Behavior Swarm / 行为集群（B 群）**：围绕愿望发散尽可能多的具体行为选项（2014–2024）。
- **Behavior Matching / 行为匹配**：以影响、想做、做得到三个标准匹配行为（2159–2169）。
- **Golden Behavior / 黄金行为**：既能推动愿望、又想做、也做得到的具体行为。
- **Focus Mapping / 焦点地图**：按影响度与可行性放置行为选项，以筛出黄金行为。
- **Ability Chain / 能力链**：时间、资金、体力、脑力、日程的最弱环决定行为难度。
- **Motivation Monkey / 动机猴子**：把动机拟人化为善变且诱人设大目标的角色。
- **Motivation Wave / 动机波浪**：动机短期冲高后回落的模式。
- **Last Action / 最后动作**：锚点例程最后一个明确、可感知的动作，用来提高提示精度（3783–3800）。
- **Meanwhile Habit / 顺便习惯**：利用等待等碎片时间，以当下事件作为锚点的小行为（3846–3863）。
- **Pearl Habit / 珍珠习惯**：把不可避免的刺激或烦恼变成积极行为的提示；“珍珠”强调以新行为包裹刺激。
- **Celebration Blitz / 庆祝闪电战**：密集练习“做一点—庆祝一次”，用来找到自然有效的庆祝方式。
- **Fogg Maxims / 福格原则**：原则 1“帮助人们做他们已经想做的事”；原则 2“帮助人们感受成功”（4523–4537）。注意“感受成功”不是“保证获得成果”。
- **Crispification / 行为清晰化**：官方辅助材料强调用尽可能少的字把行为写得明确。中文主语料未将其作为核心显式术语，若 Skill 使用，应标注为官方补充材料，而非假装中译本固定译法。  
  来源：https://tinyhabits.com/wp-content/uploads/2020/10/TinyHabits-Crispification-Guide.pdf

## 2. 表达 DNA

### 2.1 叙述人格：科学家 × 教练 × 同行者

**风格推断**：Fogg 不是用纯学术论文腔讲话，而是在三种角色间切换。

1. **科学家**：命名、定义、画模型、拆变量、强调“特定时刻的特定行为”。
2. **教练**：直接用“你”，给出下一步、模板和微练习。
3. **同行者**：大量暴露自己的尴尬与失败，如忘记赴约、不会坚持牙线、凌晨焦虑，削弱权威压迫感。

典型语用不是“你缺乏自律”，而是“这不是你的错；这是设计问题；让我们检查 Prompt、Ability、Motivation”。诊断对象始终是行为设计，不是人格。

### 2.2 稳定的论证节奏

最常见的章节级节奏可概括为：

> 反直觉短句 → 日常故事 → 模型拆解 → 命名/定义 → 一条可记口号 → 1–3 个步骤 → 微练习

段落节奏常在长故事后突然收束为极短断言：

- “小即是大。”
- “简单改变行为。”
- “没有提示，就没有行为。”
- “情绪创造习惯。”
- “猜一猜，结果如何？她成功了。”

这类短句是“记忆钉”，不宜把它们全部改写成学术长句。

### 2.3 高频句式

#### 纠偏句

- “大多数人认为……但事实并非如此。”
- “这不是……问题，而是……问题。”
- “问题不在于你，而在于你所采用的方法。”
- “不要从动机入手；先检查提示，再检查能力。”

作用：先解除羞耻，再把注意力迁移到可设计变量。

#### 条件—结果句

- “当 M、A、P 同时出现时，B 就会发生。”
- “如果第一步没效果，那就进入下一步。”
- “只要找到……就能……”

作用：把抽象心理学压缩成可操作的因果骨架。写 Skill 时应保留条件，不要只保留鼓舞性的结果。

#### 定义/命名句

- “我称之为……”
- “我将……命名为……”
- “它的定义是……”
- “这个概念非常简单。”

作用：先给熟悉体验，再赋予一个可复用名字；命名服务于行动，不追求术语炫技。

#### 对话式问答

- “是什么让这个行为难以做到？”
- “那么，怎样才能让它更容易？”
- “这时候你会做什么？”
- “就这么简单？事实上……”

作用：模拟现场教学，让读者先作判断，再读答案。

#### 三连与排比

- “无须一味重复，无须讲究频次，无须盼望奇迹，只需积极的情绪。”
- “点击、阅读、观看、评价、分享或评论。”
- “停止自我批评；拆解成微行为；把错误当成新发现。”

作用：先堆叠旧路径，再用一个短转折落到新主张。

### 2.4 类比系统

Fogg 偏好**家常、可触摸、可继续展开**的类比，不偏好抽象哲学隐喻。

- **植物/花园**：微习惯是种子、庆祝是肥料、习惯扎根、生长、繁殖。
- **锚点/附着**：既有日程是稳定物，新行为绑在其上。
- **波浪**：动机涨落；高峰期可借势做一次性困难行为，但不能把长期习惯托付给浪峰。
- **猴子**：动机善变、会诱导人设过大目标。
- **能力链**：最薄弱的一环决定整体可执行性。
- **食谱/配方**：失败意味着调整配比或食材，不意味着厨师人格有缺陷。
- **实验室/培养皿**：带着距离和好奇观察行为，失败是数据。
- **行动线像微笑**：把阈值曲线人格化为“快乐的小曲线”。
- **提示像闪电**：强调瞬时性。
- **自行车机制**：外观不同的行为共享 M、A、P 核心机制。
- **鲸鱼一口一口吃**：大结果来自微小动作。
- **拼图/编码/化学反应**：行为顺序需要正确配对，而非意志硬推。
- **珍珠**：用积极行为包裹不可避免的刺激。

**使用建议**：一个概念选择一个主类比并贯穿到底。不要在同一小节同时混用“锚点、种子、算法、阶梯”四套隐喻。

### 2.5 命名法

1. **普通名词 + 功能名词**：动机猴子、动机波浪、能力链、行动线、焦点地图。
2. **具体物象 + Habit**：毛伊习惯、珍珠习惯、顺便习惯。
3. **三字母缩写**：MAP、ABC、PAC；缩写均能还原成模型中的角色。
4. **结果导向命名**：黄金行为、行为匹配、最后动作。
5. **把技术写成可修改对象**：配方、卡片、地图、工具箱。

**风格推断**：术语名字通常先让人“看见”或“做出”某件事，再承担理论分类功能。中文 Skill 若新增辅助名称，也应满足“具体、短、可直接导向动作”，并明确标为编辑性命名，不能冒充 Fogg 原术语。

### 2.6 行动指令风格

- 用第二人称和动词开头：“写下”“找出”“选择”“问自己”“把它放到”“立刻庆祝”。
- 步数少，通常先给 1–3 步；复杂流程拆成连续小轮。
- 明确最小下限：“一颗牙”“两个俯卧撑”“3 秒”“一条待办事项”。
- 给模板而非空泛倡议：“在我 ___ 之后，我会 ___；然后我庆祝。”
- 允许个体化：“找到对你有效的”“如果不自然就换一个”“可随时修改”。
- 用试验语言消除失败：“试一试”“重新设计”“找薄弱环”“把错误当新发现”。
- 常附“加分项”，把超出微小下限视为 bonus，而不是偷偷提高最低标准。
- 指令的情绪基调是轻松、好奇、可玩，不是纪律、羞耻或强迫。

### 2.7 确定性表达及使用边界

#### 作者高确定性口号

- “福格行为模型适用于所有行为/年龄/文化。”
- “没有提示，就没有行为。”
- “简单改变行为。”
- “情绪创造习惯。”
- “庆祝是培养习惯最重要的技能。”

这些是作者的标志性表达，应保留锋利度，但 Skill 中最好写成“Fogg 的主张是……”或“在该模型内……”，避免把作者主张扩张成已被所有研究一致证实的事实。

#### 作者常用的降确定性装置

- “可能、通常、对大多数人来说、有时候、也许。”
- “如果没效果，就调整。”
- “对我有效不等于对你有效。”
- “没有万能方案。”

**风格推断**：Fogg 对模型核心命题说得很确定，对个体实施方案保持试验性。Skill 也应采用这种不对称：**原则清楚，处方可改**。

#### 中文翻译的放大风险

“必定、唯一、所有、极其有效、立刻、毫不费力”等词在中译本较密集。部分来自作者本身的营销式确定语气，部分可能是汉语修辞强化。没有英文纸书逐句对照时，不应把每个强断言都当成精确英文原句。涉及因果、神经科学或普适性的陈述，要用归因句并保留证据边界。

## 3. 26 组可复核段落样本

以下每组均包含语料位置、可复核文本特征和风格观察。引号内为**中译本原句摘录**；“观察”是本文推断。

1. **567–579，前言开场**  
   摘录：“小即是大。”“这不是你的错。”  
   观察：先用悖论式四字短句定调，再立刻解除读者羞耻；价值主张先于理论说明。

2. **580–620，设计问题而非人格问题**  
   摘录：“这是一个设计问题，而不是个人缺点问题。”  
   观察：稳定的“不是 A，而是 B”纠偏结构；把失败从人格迁移到方法。

3. **630–637，方法可信度**  
   摘录：“用经过实践验证的原则替代错误观念，用具体流程替代笼统建议。”  
   观察：平行对偶；以“原则/流程”对抗“观念/建议”，建立工程化权威。

4. **677–692，信息—行动谬误**  
   摘录：“仅有信息是无法保证有效改变行为的。”  
   观察：先指出常见专家错误，再命名谬误，最后给可行替代项；典型“反驳—命名—转向”。

5. **703–723，碎片时间**  
   摘录：“谁……有……这个……时间！”  
   观察：用戏剧化停顿模拟读者内心独白，随即给 30 秒小动作；正式模型语言与口语喜剧并置。

6. **733–780，毛伊习惯**  
   摘录：“请你每天早晨一起床就立刻说……”“感受成功。”  
   观察：指令极具体，包含时点、话语和感受目标；用个人调整示例避免僵化。

7. **802–842，失败风险与鲸鱼**  
   摘录：“一次咬一小口。”“吃掉了整条鲸鱼。”  
   观察：宏大目标以儿童故事和身体动作落地；同一类比前后闭环。

8. **949–976，ABC 三步骤**  
   摘录：“Anchor 锚点 / Behavior 行为 / Celebration 庆祝。”  
   观察：模型压缩为三项、每项一句定义加一个微型例子；极适合卡片化教学。

9. **1080–1119，B=MAP 与捐款案例**  
   摘录：“动机是……能力是……提示则是……”  
   观察：先定义，再把单个真实事件逐项拆成 B/M/A/P；不是先堆学术背景。

10. **1142–1148，自行车类比**  
    摘录：“行为就像是不同款式的自行车……核心机制却是一样的。”  
    观察：用机械结构说明模型普适性，同时承认表面体验差异，避免类比过度抹平。

11. **1211–1224，快乐小曲线**  
    摘录：“如果我的墓碑上只能刻一个东西，那一定是这条快乐的小曲线。”  
    观察：在图解技术点中插入夸张幽默，让行动线成为可记忆角色。

12. **1279–1286，队友关系**  
    摘录：“动机和能力要像队友一样密切配合。”  
    观察：把补偿关系翻译为团队协作，再用“其中一方弱，另一方要强”复述技术含义。

13. **1307–1320，提示像闪电**  
    摘录：“没有提示，就没有行为。道理就是这样，简单又强大。”  
    观察：绝对化口号后接闪电类比，突出 prompt 的瞬时性和必要性。

14. **1461–1519，行为问题三步诊断**  
    摘录：“1．检查有没有行为提示。2．检查有没有行为能力。3．检查有没有行为动机。”  
    观察：诊断顺序反转大众对动机的偏好；先给算法，再用迟到和买海报纸案例演示。

15. **1588–1601，模型不是人格投票**  
    摘录：“它是一个模型，而不是对性格好坏的投票。”“把习惯当成食谱。”  
    观察：去道德化是核心修辞；模型、食谱、实验室三层类比都服务于“调整而非自责”。

16. **1610–1615，动机猴子出场**  
    摘录：“是什么阻碍了你做出改变呢？是动机猴子。”  
    观察：设问后用两词回答；抽象变量被拟人化为反复出场的叙事反派。

17. **1706–1717，酒肉朋友类比**  
    摘录：“动机就像是一位酒肉朋友……不能指望它会去机场接你。”  
    观察：选择日常且略带幽默的社会关系解释“高吸引、低可靠”。

18. **1794–1821，动机波浪**  
    摘录：“动机冲到顶峰，随后急转直下。”  
    观察：先命名体验，再用斯波克与榨汁机故事扩展；流行文化帮助读者识别自己。

19. **1928–1957，愿望/成果/行为**  
    摘录：“行为是你现在或在某个特定时刻可以去做的事情。”  
    观察：术语辨析最终落到一个可执行测试；明确弃用 goal，体现对词义精度的执着。

20. **2014–2032，行为集群**  
    摘录：“如果你可以挥舞魔法棒……”“很好，还有呢？”  
    观察：发散阶段暂缓评判，用魔法棒降低现实约束；教练式追问短而重复。

21. **2159–2183，黄金行为**  
    摘录：“影响、动机、能力”三标准。  
    观察：新术语都配判据，不只给漂亮名称；“黄金”表达筛选后的高价值。

22. **2674–2718，简单改变行为与一颗牙**  
    摘录：“我决定每天只用牙线清洁一颗牙齿。我是认真的。”  
    观察：预判读者会觉得荒谬，用短句加重承诺；以亲身试验替代说教。

23. **2722–2818，能力链与两类问题**  
    摘录：“是什么让这个行为难以做到？”“怎样才能让这个行为更容易做到？”  
    观察：探索型问题负责诊断，突破型问题负责设计；抽象 Ability 被拆成可检查资源。

24. **3396–3556，三类提示到锚点**  
    摘录：“不要把提示交给运气。”“行动提示……我还给它取了另一个名字：锚点。”  
    观察：先对比人物、情境、行动提示，再为最佳习惯提示命名；分类服务于选择。

25. **3565–3613，‘之后’、编码与化学反应**  
    摘录：“这里的关键是‘之后’。”“为对的行为安排对的顺序。”  
    观察：用时间连接词作为配方核心；编码、拼图、化学反应都强调排序和配对，而非努力程度。

26. **4115–4174、4200–4249、4397–4618，庆祝与 Shine**  
    摘录：“庆祝是习惯养成的‘肥料’。”“情绪创造习惯。”“发光（Shine）。”  
    观察：先用琳达和作者自身低谷建立情绪必要性，再讲神经机制，最后命名 Shine 并列出动作；情感故事—机制—技能三段式完整闭环。

## 4. 可直接迁移到主题 Skill 的表达规范

### 应保留

- 开头先去责备：“这更可能是设计问题，不是人格问题。”
- 一次只诊断一个明确行为。
- 先定义术语，再给一个日常反例和一个正确例。
- 使用短口号作段落收束，但把因果主张归因给 Fogg。
- 给明确模板、最小动作、立即可做的练习。
- 处方允许修改，以“试验—观察—调整”代替“坚持—失败—自责”。
- 原则层表达清楚，个体建议层保留“可能/试试/对你有效”。

### 应避免

- 把 aspiration、outcome、behavior 都翻成“目标”。
- 把 Ability 解释成能力素质或意志力。
- 把 Prompt 解释成一般信息提醒，忽略“现在做”的时点。
- 把 Anchor 当成任意环境线索；它在微习惯配方中优先指既有稳定例程及其确切结束时刻。
- 把 Celebration 当奖品、聚会或延迟奖励。
- 把 Shine 与 Celebration 合并；前者是感受，后者是产生感受的动作。
- 用“微习惯”代替尚未自动化的“微行为”而不加区分。
- 混合书中“人物/情境/行动提示”与官方网页“Facilitator/Signal/Spark”而不标版本。
- 把作者的强主张改写成无归因的科学共识。
- 过度模仿营销确定性，声称任何人都必然迅速成功。

### 推荐的中文微型句模

> 先把人格判断放到一边。请只看一个具体行为：___。  
> 它是愿望、成果，还是现在能做的行为？  
> 如果它没有发生，按这个顺序检查：提示 → 能力 → 动机。  
> 问：“什么让它难做？”把行为缩小到容易开始。  
> 在一个明确锚点之后执行它，然后立刻用自然的方式庆祝。  
> 若配方不工作，调整配方；不要评价自己。

这是依据语料归纳出的**编辑性模板**，不是书中逐字原文。

## 6. 当前薄弱点

1. **作者与译者风格无法完全拆分**：句式、四字格、成语和部分确定性强度可能来自中文编辑加工。
2. **缺少英文纸书逐段对照**：目前英文核对覆盖核心术语和配方，不能证明中译本每一句的语气都与英文完全等强。
3. **官方网页存在版本层差异**：尤其 Prompt 的两套三分类，后续成稿必须标注语境，不能当成单一固定分类。
4. **Shine 的中文尚无完美单词**：“发光感（真实的成功感）”是降低漂移的编辑建议，不是新的官方译名。
5. **因果与普适性主张需另维度审证**：“情绪创造习惯”、神经化学解释、模型适用于所有文化等是作者高确定性主张；本维度只记录表达 DNA，不完成证据质量评估。
