## 0. 执行结论

建议最终主题 Skill 只保留 **4 个核心模型**：

1. **时点汇合诊断模型**：把问题压到一个“某人在某时做/没做的具体行为”，用 M、A、P 做即时诊断，并用最小反事实找缺口。
2. **行为选项—匹配模型**：从愿望/成果降到行为选项群，再按影响、想做、做得到筛出黄金行为。
3. **微习惯配方—学习闭环**：用锚点绑定微行为，以真实、即时、可选的积极反馈结束一次试验，再依据执行结果重配。
4. **逆向解结模型**：把概括型坏习惯拆成具体行为，依次处理提示、可执行性/摩擦、动机，必要时再做替换。

这四个模型能形成完整但不混层的链条：

`确定具体行为 → 选择值得设计的行为 → 设计一次可重复执行 → 根据结果排障或逆向终止`

最主要的否决意见有四项：

- 不接受把 `B=MAP` 写成已被充分验证、可计算、适用于所有行为的科学定律。
- 不接受“情绪创造习惯，而不是重复”作为事实性核心模型；稳定情境中的重复与自动性增长有更直接的习惯科学支持。
- 不接受把 `Tiny Habits`、`ABC`、庆祝或习惯自动化回填成 2009 年 `B=MAT` 的组成部分。
- 不接受“忍者式隐性设计”“女王 B”或“对方已经想做”自动提供伦理授权；短期欲望、知情同意和长期福祉不是一回事。

## 1. 审查标准

依据提炼规范，每个候选框架逐项审查：

- **跨域复现**：是否在至少两个不同领域被反复使用，而非只服务一个案例。
- **生成力**：是否能对新问题产生可检验的诊断、选择或干预建议。
- **排他性**：是否具有 Fogg 体系的可辨识结构，而不是所有行为科学、设计思维或习惯书都会说的常识。

标签含义：

- **PASS**：证据和结构足以承担该维度。
- **WEAK**：存在可用结构，但证据、边界或独特性不足。
- **FAIL**：不满足该维度，或强版本不可接受。

重要说明：这里的“排他性 PASS”只表示**能辨认为 Fogg 的框架组合**，不表示其组件均由 Fogg 首创，更不表示框架已获独立因果验证。

## 2. 七个候选框架逐项裁决

### 候选 1：时点汇合诊断模型

**最小运行形式**

1. 把输入改写成一个特定时刻、可观察的具体行为 B。
2. 确认当时是否有足够的 Motivation、Ability 和 Prompt。
3. 用最小反事实一次拿掉一个因素：若 P 不到、A 下降或 M 下降，预测是否改变。
4. 实务排障优先试 `Prompt → Ability → Motivation`，但把这个顺序标成设计启发式，不冒充理论重要性排序。
5. 每次只修改一个主要变量并观察。

**跨域复现：PASS**

- 正向习惯：牙线、运动、备餐、工作启动。
- 负向习惯：刷手机、甜食、社交媒体。
- 群体与组织：会议迟到、家庭家务、护士项目。
- 产品与公共行为：短信捐款、移动提示、数字产品。

**生成力：PASS**

面对“员工不按时填报”“患者忘记服药”“用户没完成注册”“孩子没收拾滤网”等新问题，它会生成同一组可测试问题：提示是否被注意、行为是否当时可做、行为是否真有足够动机。它还能生成最小干预：改时点、降摩擦、换行为，而不是先加压。

**排他性：PASS**

动机、能力、提示本身并不独特；可辨识之处在于“同一时点汇合 + M/A 补偿行动线 + 先把行为压到具体节点 + P/A/M 排障”。这足以与 TPB、SDT、COM-B 或一般“提高动机”建议区分。

**科学地位**

- 适合作为**概念性诊断图和设计启发式**。
- 不应称为数学方程：M、A、P 没有通用量纲，行动线没有参数，B 也没有统一定义为概率、频率或二元结果。
- 现有独立证据主要支持构件方向相容；未充分验证三要素的必要充分性、同一时点汇合、行动线曲率或跨文化普适性。
- 若把任何内在状态、时间流逝或念头都事后叫 Prompt，“没有 Prompt 就没有行为”会接近不可证伪。

**裁决：推荐保留为核心模型，但必须降低科学断言强度。**

---

### 候选 2：行为选项—匹配模型

**最小运行形式**

1. 区分 aspiration、outcome、behavior：方向性愿望、可衡量结果、可在明确时刻执行的动作。
2. 围绕愿望发散一组具体行为选项，发散阶段不提前评判。
3. 第一轮只判断对愿望的影响，第二轮只判断现实可行性。
4. 对候选行为再拆问：“本人想做吗？”“当下做得到吗？”
5. 选择同时满足“有效、想做、做得到”的黄金行为；没有则继续发散，不硬挑。

**跨域复现：PASS**

- 健康：睡眠、运动、饮食。
- 工作与财务：减压、最重要任务、储蓄。
- 家庭与教育：家务、作业、亲子协作。
- 群体设计：团队共同生成和排序行为。

**生成力：PASS**

它不只评价一个给定方案，还能生成替代方案。面对“我应该冥想但坚持不了”，该模型不会立即把冥想做小，而会先问这个行为是否真有高影响、本人是否想做、是否有更匹配的行为。这种“先选对 B，再设计 B”的顺序能改变新问题的解法。

**排他性：PASS**

“把目标具体化”和“选可行方案”是通用常识；但 aspiration/outcome/behavior 三分、行为选项群、影响/可行性两轮焦点映射、黄金行为三标准组成了可辨识的 Fogg 工作流。应把独特性归给**程序组合**，不能声称各组件由 Fogg 独创或已分别验证。

**科学地位**

- 自主匹配与 SDT 相容，if-then 具体化与成熟行为研究相容。
- 焦点地图和黄金行为筛选算法本身缺少组件级比较试验。
- “本人想做”不能覆盖安全、医疗、法律、照护等不可自由放弃的责任；这些场景应在必要目标内最大化自主选择，而不是把责任取消。

**裁决：推荐保留为核心模型。**

---

### 候选 3：能力链—最小基线模型

**最小运行形式**

1. 问“是什么让这个行为难做？”
2. 扫描时间、资金、体力、脑力、与既有日程/惯例的适配。
3. 找当前最弱环。
4. 从技能、工具/资源、缩小行为三路提出方案。
5. 缩小时区分 Starter Step 与 Scaling Back；额外完成不抬高下次基线。

**跨域复现：PASS**

在牙线、备餐、运动、工作任务、数字产品步骤、群体流程和坏习惯反向增摩擦中均可运行。

**生成力：PASS**

它能对新问题生成明确问题和方案：障碍究竟是时间、工具、体力还是决策复杂度；应培训、换工具、预处理环境，还是缩成一个入口动作。

**排他性：WEAK**

降低摩擦、找瓶颈、拆小任务和保留最低标准都广泛存在于行为科学、精益设计、工程与习惯方法。Fogg 的辨识度主要来自 Ability Chain、Starter Step/Scaling Back 的命名及与行动线的连接，而非底层思想独有。

**科学地位**

- “降低摩擦提高启动概率”有较强相邻证据。
- “最弱环决定全部能力”是诊断启发式，不是经测量证实的普遍定律；障碍可能交互。
- “30 秒”“一个动作”“越小越好”没有通用最优阈值。
- 小行为提高启动机会，不等于自然提供最终效果所需的剂量、质量或持续时间。

**裁决：降级为候选 1 和候选 4 中的关键启发式模块，不单列为最高层核心模型。**

---

### 候选 4：微习惯配方—学习闭环

**最小运行形式**

1. 选择已通过匹配的行为，并缩成安全的 Tiny Behavior。
2. 找一个可靠既有日程，匹配地点、频率、主题，并精确到锚点最后动作。
3. 写成：`在我【锚点最后动作】之后，我会【微行为】；然后我会【即时、真实、可选的庆祝】。`
4. 观察是否想起、是否执行、是否感觉自然。
5. 失败时修改锚点、规模、工具或行为；不把一次配方失败解释成人格失败。

**跨域复现：PASS**

书中在身体活动、牙线、做饭、工作启动、感恩、清洁、亲子任务和群体习惯上重复使用。

**生成力：PASS**

它能为一个新行为生成完整配方，也能预测失败点：锚点不稳定、地点不匹配、行为太大、庆祝延迟或不真实。它还生成下一轮修订，而不是只给一句“坚持”。

**排他性：PASS**

Anchor 与 implementation intentions 高度相似，Celebration 与强化/积极反馈同源，微小步骤也不独有。但“行动锚点 + 极小行为 + 即时 Shine + 配方可重设计”的组合是 Tiny Habits 最有辨识度、最可运行的结构。排他性属于组合，不属于各组件的科学原创性。

**科学地位**

- 锚点/线索计划拥有最强的邻近证据，但行动锚点未证明普遍优于钟点提示。
- 稳定情境中的重复是自动性形成的重要机制；ABC 设计的价值之一正是创造重复机会。
- 积极体验、信息性反馈与坚持相容；“即时自我庆祝独立加速自动性”尚缺组件隔离试验。
- 不得声称庆祝必然释放特定剂量多巴胺并把行为立即“接线”成习惯。

**裁决：推荐保留为核心模型，但名称必须表明它是 Tiny Habits 方法，而不是 B=MAP 本体。**

### 候选 5：逆向解结模型

**最小运行形式**

1. 先筛查临床、安全和零容忍风险。
2. 把“少拖延、戒糖、少刷手机”等概括标签拆成多个具体行为。
3. 先选最容易、风险最低的一个“结”。
4. 依次尝试：移除/规避 Prompt → 增加旧行为摩擦、降低 Ability → 最后处理 Motivation。
5. 完全停止过难且不存在零容忍风险时，可缩短周期、时长、频次或强度。
6. 仍无效再选择一个更想做、更容易做的新行为，重映射旧提示。

**跨域复现：PASS**

可用于数字使用、饮食、睡眠、消费、工作回避和关系中的即时反应；其机制也能从个人扩到家庭/组织环境。

**生成力：PASS**

面对新坏习惯，它会先生成具体行为清单和风险分级，再给出有顺序的干预树，而不是泛泛要求“打破习惯”。它还能识别“遗漏型问题”应转为创建所需行为，而非停止“不作为”。

**排他性：PASS**

行为分解、刺激控制、增加反应成本与替代行为均不是 Fogg 首创；可辨识结构是“同一 MAP 反向运行 + 解结隐喻 + P/A/M 顺序 + 替换置后 + 先练改变技能”。作为组合，它足以保留。

**科学地位**

- 这是可执行的设计流程，不是成瘾治疗协议。
- “资金摩擦”“公开承诺”“去激励因素”可能成为惩罚、经济歧视或羞辱，应严格限制。
- 严重成瘾、强迫、自伤、进食障碍、药物戒断和精神健康危机不得进入普通自助流程。

**裁决：推荐保留为核心模型，并把临床分流放在第一步。**

---

### 候选 6：无责备的单变量实验循环

**最小运行形式**

`具体描述失败 → 去掉人格判断 → 选一个可改变量 → 短期试验 → 观察 → 保留、回退或重配`

**跨域复现：PASS**

个人习惯、家庭反馈、产品设计、组织流程和坏习惯案例均采用“设计问题而非人格问题”的复盘方式。

**生成力：PASS**

能稳定生成低威胁的复盘问题、单变量试验和撤销条件；对避免羞耻型干预尤其有价值。

**排他性：FAIL**

无责备、把失败当数据、原型迭代和一次改一个变量是设计思维、实验方法、行为治疗与教练实践的共有原则。它体现 Fogg 的教学人格，却不足以作为独特心智模型。

**裁决：降级为贯穿整个 Skill 的操作姿态，不单列核心模型。**

---

### 候选 7：自主性—成功感双原则

**最小运行形式**

1. 帮助人做他们已经想做的事。
2. 帮助人感受具体、真实的成功。
3. 在他人或群体场景补充知情、可拒绝、可撤回、受益/风险归属和长期福祉审查。

**跨域复现：PASS**

个人教练、家庭、团队、产品设计和公共健康中均出现。

**生成力：PASS**

它能否决羞辱、强迫庆祝和只看转化率的干预，也会要求先问行为主体真正想要什么。

**排他性：WEAK**

两条 Fogg Maxims 的措辞有辨识度，但自主支持和积极反馈是广泛伦理/行为科学原则。更重要的是，原始两条原则无法独立解决短期欲望与长期利益、儿童与患者同意、雇佣权力、暗黑模式等问题。

**裁决：降级为伦理启发式，并由更强的知情同意与反操纵护栏补足；不作为解释性核心模型。**

## 4. 看似独特、实为通用行为科学常识的观点

以下内容可以使用，但不应包装成 Fogg 独有发现：

1. **让行为更容易、减少摩擦。**  
   这是行为设计、人因工程、默认选项、COM-B/机会设计和产品 UX 的普遍原则。Fogg 的特殊贡献在操作化组合，而非“简单更容易发生”本身。

2. **把抽象目标改成具体动作。**  
   目标设定、行动计划、认知行为技术和 implementation intentions 都强调具体化。

3. **把线索与反应绑定。**  
   `After I…, I will…` 与 if-then implementation intentions 高度相似；外部元分析证据不能全部记到 Tiny Habits 名下。

4. **稳定情境和提示有助于行为发生。**  
   这是主流习惯和线索反应研究的核心，不是 Anchor 命名后才出现。

5. **即时正反馈可能提高未来行为概率。**  
   与操作性强化和 SDT 的信息性反馈传统相容。Fogg 的 Shine 强调主观成功感，但不能据此宣称发现了“积极后果影响行为”。

6. **动机会波动。**  
   情绪、目标强度和情境动机并不稳定是常识及成熟研究主题。“动机猴子/波浪”是有效传播隐喻，不是独有科学发现。

7. **把复杂坏习惯拆成具体行为。**  
   功能分析、刺激控制、替代反应和逐步塑造均早已存在。Fogg 的价值在于把这些步骤接入 MAP 流程。

8. **失败是反馈，不应人格化。**  
   这是设计思维、实验方法、自我同情与多类治疗/教练方法的共同立场。

9. **优先支持自主选择。**  
   “做本人想做的事”与 SDT 的自主支持相容，不应写成由 Fogg 独自发现。

10. **瓶颈决定当前可执行性。**  
    最弱环是常见工程隐喻；真实行为障碍可能是多个因素交互，不能把隐喻升级为定律。

## 5. 作者主张被误写成科学事实的高风险清单

### 5.1 必须使用归因或证据限定的主张

- “Fogg 主张 B=MAP 可解释所有年龄、文化和行为。”  
  不可写：“科学证明 B=MAP 适用于所有人类行为。”

- “在该模型中，三要素被视为行为发生条件。”  
  不可写：“M、A、P 已被证明是所有行为的必要充分条件。”

- “Fogg 用行动线表达 M/A 补偿。”  
  不可写：“行动线是已估计、可计算的行为概率曲线。”

- “Fogg 认为 Prompt 是‘现在做’的必要信号。”  
  不可写：“任何行为都必定存在一个可识别提示。”内部 Prompt 的无限扩张会削弱可证伪性。

- “Fogg 把积极情绪视为习惯形成的关键加速器。”  
  不可写：“情绪而非重复创造习惯。”

- “庆祝旨在产生即时成功感。”  
  不可写：“庆祝一定触发多巴胺并立刻把习惯写入大脑。”

- “小行为可能生长或繁殖。”  
  不可写：“微小行动必然滚成巨大改变或身份转变。”

- “五日项目有初步短期正向信号。”  
  不可写：“五天足以形成持久习惯。”

- “作者案例说明如何运行流程。”  
  不可写：“这些成功案例证明方法造成了体重、婚姻、学业或职业结果。”

- “P→A→M 是 Fogg 的实务排障顺序。”  
  不可写：“科学证明所有行为问题都必须按这个唯一顺序解决。”

### 5.2 外部证据不能被挪用

- implementation intentions 的元分析支持 if-then 计划，不等于验证 Tiny Habits 全部组件。
- 稳定情境重复研究支持线索—反应自动性，不等于验证 Celebration。
- SDT 支持自主性动机，不等于验证黄金行为焦点地图。
- 一般强化与积极反馈证据不等于验证 Shine 的专有多巴胺机制。
- 以 FBM 为标签的捆绑式公共健康干预，不等于拆分验证 M、A、P 或行动线。
- 作者官网、官方课程、认证学员数量和引用数量只能核对作者体系与传播，不能作为独立有效性证据。

## 6. 层级审计：B=MAP、Behavior Design 与 Tiny Habits 不可混写

建议固定以下层级：

### 层级 1：Fogg Behavior Model

- 对象：某个具体行为在某个时刻为何发生/未发生。
- 构件：Motivation、Ability、Prompt；旧版第三项为 Trigger。
- 产物：行动线、M/A 补偿关系、即时诊断。
- 不是：愿望选择流程、完整习惯形成理论、庆祝方法或坏习惯治疗协议。

### 层级 2：Fogg Behavior Design

- 对象：选择、设计、测试和修正行为。
- 包含：愿望/成果/行为区分、行为选项群、焦点映射、黄金行为、能力诊断、提示设计、排障。
- B=MAP 是其底层诊断模型之一，不等于整套 Behavior Design。

### 层级 3：Tiny Habits 方法

- 对象：把一个被匹配的行为做成容易重复并逐渐自动化的日常实践。
- 典型配方：Anchor → Tiny Behavior → Celebration。
- Anchor 向 B=MAP 提供 Prompt；Tiny Behavior 主要提高 Ability；前置行为匹配保证最低限度的 Motivation。
- Celebration 发生在 B 之后，是学习反馈；它不是 B=MAP 三个即时发生条件之一。

### 层级 4：Behavior Change System

- 对象：终止或替换不想要的习惯。
- 做法：把旧习惯具体化，反向处理 P/A/M，再在需要时选择替代行为。
- 它是扩展流程，不是 B=MAP 公式本身。

### 必须再分开的四种结果

1. **一次行为发生**；
2. **行为被重复**；
3. **行为形成自动性/习惯**；
4. **行为产生足量、长期、功能性成果**。

B=MAP 主要处理第 1 层；ABC 试图帮助第 2–3 层；是否达到第 4 层还取决于剂量、质量、资源、反馈和环境。不得从“一次做到了”跳到“健康/技能/组织结果已实现”。

## 7. 版本矛盾与并存分类审计

1. **诞生年份：2007 vs 2009**  
   2007 是作者回溯认定的发现年；2009 是可核实的正式论文。不得把两者写成同一种证据。

2. **公式：B=MAT → B=MAP**  
   2009 使用 Trigger；2017 年末后改为 Prompt。机制被作者描述为不变，历史材料仍应保留原词。

3. **Tiny Habits 成熟时间**  
   2011 年项目形成“小行为 + 锚点 + 反馈”的早期方法；2020 书整合成熟 ABC。不得把 2020 的完整术语回填到 2009。

4. **Ability：六因素 → 五因素**  
   2009 有 time、money、physical effort、brain cycles、social deviance、non-routine；2020 能力链为时间、资金、体力、脑力、日程适配，social deviance 不再单列。

5. **Prompt 两套三分类并存**  
   - 按功能：Spark / Facilitator / Signal。
   - 按来源：Person / Context / Action（Anchor）。
   二者正交，不可混成一个互斥六分类，也不可声称后一套废止前一套。

6. **Motivation 两套切分并存**  
   - 内容/心理维度：Sensation、Anticipation、Belonging（对应早期三对正负动机）。
   - 来源：Person、Action、Context。
   没有正式映射，不应编成九宫格。

7. **Behavior Grid：35 → 15**  
   35 类是被后续 15 类取代的早期版本，不宜进入核心 Skill 主流程。

8. **出版年份：2019 年末 vs 2020**  
   可写“2019 年末首发，2020 年全面发行/版权年”。简中 2021 年标题《福格行为模型》改变了英文 *Tiny Habits* 的重心。

9. **确定性公式 vs 概率性叙述**  
   “条件齐备行为就发生”与书中“更可能、提高概率”并存。Skill 应采用概率性、可测试的表述，不替作者制造未给出的数学调和。

10. **“强动机无需提示” vs “没有提示就没有行为”**  
    两种文本字面冲突。除非明确标成解释假设，不得擅自补成“强烈情绪本身就是内部提示”来消除矛盾。

## 8. 不可抹平的核心张力

### 张力一：确定性、普适性 vs 可证伪性

Fogg 用“所有行为”“三要素同时出现就会发生”获得传播力；但构件过宽、Prompt 可事后扩张、行动线未参数化，使模型很难承担同等强度的科学预测。不能用“这是启发式”抹掉作者的强普适主张，也不能因缺乏定量验证就否认其设计生成力。最终 Skill 应同时保留：**强而简洁的诊断图，与弱得多的科学验证状态。**

### 张力二：情绪编码 vs 稳定情境中的重复

Fogg 反对固定 21/66 天神话，并强调即时成功感；主流习惯研究则支持在稳定情境中重复后自动性渐进增长。不能把二者伪调和为“大家其实说的是一回事”：Fogg 的公开强句确实赋予情绪更高、甚至排他的因果地位，而现有组件试验不足。可操作综合是“积极体验可能促进重复和联结”，但必须注明这是收缩后的综合，不是作者原强命题。

### 张力三：做对方想做的事 vs 隐性说服和必要行为

两条 Maxims 强调自主和成功感；“忍者”隐性嵌入、“女王 B”重包装、产品促发和儿童/员工场景却可能绕过知情同意。短期“想点开、想吃、想逃避”也可能与长期福祉冲突。有效促发不自动等于正当促发，这一冲突需要外加伦理门槛，不能靠 Maxim 1 自动解决。

### 张力四：极小基线 vs 有效剂量

把行为缩小能提高启动和重复机会；健康改善、技能增长、康复和组织结果却常需要足够剂量与质量。“一颗牙”可训练启动，但不等于完整口腔护理；“打开文档”不等于完成报告。Skill 必须同时保护微小基线与成果所需剂量，不能把“做到了最小动作”误写成“目标已经实现”。

### 张力五：去人格化设计 vs 结构性机会与权力

把失败从品格转到设计通常有益；但把贫困、照护负担、无障碍缺失、歧视和排班压进宽泛 Ability，也可能把制度责任重新交还个人。对复杂问题，MAP 可处理一个动作节点，却不能替代 Opportunity、资源、政策和权力分析。

### 张力六：庆祝成功 vs 真实负面情绪

真实成功感可能帮助行动；强迫庆祝、控制性表扬或用积极情绪覆盖哀伤、羞耻、创伤和身体疼痛，会变成情绪否认。Celebration 必须可选、自然且允许“不庆祝/换形式”，不能成为新的服从测试。

## 9. 临床、安全与伦理边界

### 9.1 必须转介或暂停自助流程

- 严重成瘾、药物依赖或戒断风险；
- 自伤、自杀风险；
- 强迫行为、进食障碍；
- 躁郁、重度抑郁、创伤反应或其他精神健康危机；
- 异常疼痛、眩晕或需要医疗评估的身体症状；
- 家暴、骚扰、歧视和危险环境。

这些问题不能被改写成普通“自由落体习惯”，更不能用庆祝、珍珠习惯、增加摩擦或身份叙事替代专业评估和安全计划。

### 9.2 安全设计限制

- Starter Step 也必须安全；“打开燃气灶”之类动作若可能被中断，不应作为通用示例。
- 零容忍风险（酒后驾驶、自伤等）不能用“只减少一点”处理。
- 疼痛不是需要更强庆祝的信号。
- Prompt 不应在驾驶、过马路、操作机器时制造注意分散。
- 增加摩擦不能妨碍紧急联系、无障碍需求或工作职责。

### 9.3 对他人应用的伦理门槛

在家庭、学校、医疗、组织和产品场景，至少检查：

1. 行为主体是否知情同意；
2. 是否能轻易拒绝、退出、关闭提示和撤回数据；
3. 目标由谁选择，收益归谁，风险由谁承担；
4. 是否存在儿童、患者、员工、伴侣等权力不对等；
5. 是否用强力区、个性化提示、羞耻或经济成本利用脆弱点；
6. 是否把短期点击、服从或留存冒充长期福祉；
7. 行为数据是否最小收集、限定用途和保留期限；
8. 问题是否源于排班、资源、制度或歧视，而非个人习惯。

### 9.4 庆祝的伦理边界

- 必须真实、自主、文化上自然；
- 不强迫外显表演；
- 不用虚假夸奖替代具体反馈；
- 不把延迟奖品、金钱控制或排名竞赛偷换成 Celebration；
- 不用“帮助你感受成功”掩盖操纵目标。

## 10. 最终三类清单

### A. 推荐保留为核心模型

1. **时点汇合诊断模型**  
   保留 B=MAP、具体时点、M/A 补偿、最小反事实和 P→A→M 排障；明确它是概念启发式，不是数学定律。

2. **行为选项—匹配模型**  
   保留愿望/成果/行为三分、行为选项群、焦点映射和黄金行为；强调“先选对行为，再设计行为”。

3. **微习惯配方—学习闭环**  
   保留 Anchor–Tiny Behavior–Celebration 和配方修订；把稳定情境重复纳入习惯形成说明，把庆祝机制降到有边界的假说/实践组件。

4. **逆向解结模型**  
   保留具体化、先易后难、反向 P/A/M、替换置后；第一步固定为临床与安全分流。

### B. 降级为启发式、模块或护栏

- `Prompt → Ability → Motivation`：实务排障顺序，不是普适科学定律。
- 能力链五项与“最弱环”：快速扫描表，不是完整因果模型。
- 技能/工具/缩小三路简化：方案生成器，不是唯一干预全集。
- Starter Step / Scaling Back：重要操作区分，不单列核心模型。
- Motivation Wave：借高动机做一次性难事的实务启发式。
- 行动锚点的地点/频率/主题/最后动作：锚点质量检查表。
- 即时庆祝、Shine：可选的积极反馈组件；不得独占习惯因果解释。
- 生长/繁殖：观察习惯变化的描述性语言，不是必然结果。
- 无责备、单变量试验、失败即数据：全局操作姿态。
- 两条 Fogg Maxims：最低伦理启发式，必须外加知情同意、可退出、反操纵和长期福祉审查。
- 珍珠习惯、顺便习惯：低风险情境的配方变体，不是普遍策略。
- 7–10 次演练、3 个起步、每月加 3 个、五日项目：实践建议，不是普适阈值。

### C. 推荐删除或禁止进入核心叙述

- “B=MAP 已被科学证明是所有行为的必要充分定律。”
- 把 `=` 或 MAP 解释成可计算乘法公式。
- “没有可识别 Prompt 就绝不可能有行为”的不可证伪版本。
- “情绪创造习惯，而不是重复”的排他性事实表述。
- “庆祝必然释放多巴胺并立即固化习惯”的神经科学叙事。
- “微行为必然自然长大、繁殖并改变身份/人生”的保证。
- “五天、7–10 次、21/60/66 天或 30 秒是普适习惯阈值。”
- 把作者案例、课程规模、官网引用数或认证学员数写成独立效果验证。
- 把外部 implementation intentions、SDT、强化或习惯自动性证据全部归功于 Fogg。
- 把 ABC/Celebration/Anchor 回填成 2009 FBM 原始构件。
- 把 Prompt 两套分类、Motivation 两套分类强行合并。
- 当前核心中继续使用已被替代的 35 类 Behavior Grid。
- “所有改变只有顿悟、环境、微小习惯三条路径”的排他性断言。
- “忍者式隐性设计无需告知”或以“对方想做”为暗黑模式授权。
- 对严重成瘾、精神疾病、家暴、创伤或医疗风险提供微习惯替代治疗。

## 11. 推荐给最终 Skill 作者的模型命名

为避免中文书名把 Tiny Habits 与 B=MAP 混成一层，推荐使用以下固定名称：

1. **时点汇合诊断模型（Fogg Behavior Model / B=MAP）**
2. **行为选项—匹配模型（Behavior Swarm → Focus Mapping → Golden Behavior）**
3. **微习惯配方—学习闭环（Tiny Habits ABC）**
4. **逆向解结模型（Reverse MAP for Unwanted Behaviors）**

不推荐用“福格行为模型”统称上述四者。可用“Fogg Behavior Design 工具箱”作为总称，并在开头画清层级。

## 12. 最终审稿意见

候选材料最有价值之处，不是提出了一个足以解释全部人类行为的公式，而是把行为改变压缩成一组能被普通人运行、观察和重设计的工程动作。最终 Skill 的质量取决于能否同时做到两件事：

1. 保留 Fogg 体系真正有辨识度的程序组合和教练式生成力；
2. 拒绝把传播口号、商业案例、相邻理论证据和通俗神经科学升级为已证实事实。

若只能保留一个总原则，应是：**先确定一个具体行为，再设计一次可测试的改变；成功与失败都只更新配方，不更新对人格的判决。**  
但这句话本身属于操作姿态，而不是 Fogg 独有、已验证的科学定律。
