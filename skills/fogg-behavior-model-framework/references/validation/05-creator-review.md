# Phase 5 Agent B｜Skill Creator 评审

- 评审对象：`fogg-behavior-model-framework/SKILL.md`
- 评审日期：2026-09-07
- 约束：未修改 `SKILL.md`
- 总判定：**可用，但建议做 3 处高价值收紧**

## 触发判定

**基本通过。** Frontmatter 已覆盖显式术语、行为未发生、降摩擦和稳定重复，且用“一般生产力闲聊不自动触发”抑制误触发。主要漏项是两个真实入口：用户未说 Fogg 术语但明确想“终止/替换一个普通坏习惯”，以及在知情、可拒绝前提下为他人或团队设计具体行为。反面边界虽覆盖临床、成瘾和危机，但“仅需医学诊断时不触发”不足以说明：若用户明确要求用 Fogg 分析高风险问题，Skill 只能启用安全分流，不能继续做普通习惯处方。

## 最关键缺口

1. **处方药硬门仍可能让 Agent 过早进入提醒设计。** 现文禁止补服、加倍、停药和调剂量是正确的，但没有明确要求：只要存在“当前漏服、疑似重复服用或剂量不确定”，就先暂停 MAP/Tiny Habits；只有当前处理方式和既定方案已由可靠来源确认后，才能设计未来提醒。疑似过量也应直接升级，而不是只写“联系医生或药师”。
2. **默认模板会把非重复任务也拖入 Tiny Habits。** 虽然 Step 3 已写“需要重复时才写配方”，模板却固定显示“微习惯配方”，容易让 Agent 对一次性任务、坏习惯终止和高风险问题机械填满。Step 2 的“至少核对五项”也可能被误读成五连问。
3. **`Behavior Change Masterplan` 名称基本正确，归属句不够精确。** Fogg 官方 2020 `Tiny Habits Toolkit` 明确出现 “Behavior Change Masterplan Phase 1 - Create a New Habit”；中文原书正文使用“行为改变系统方案”。但现文称其为“英文原书对终止、减少或替换不想要行为流程的名称”，当前可核证材料更直接支持“官方英文配套工具包用名”，且 Masterplan 的第一阶段是创建新习惯，不宜概括成只处理终止、减少或替换。

## 建议的具体文本改动

### 1. 替换 frontmatter 的 `description`

```yaml
description: |
  福格行为设计的中性、证据分级工具箱，严格区分 B=MAP、Behavior Design、Tiny Habits 与 Behavior Change Masterplan，提供 6 个模型、9 条 if-then 启发式及安全路由。用户明确提到「福格行为模型」「B=MAP」「Tiny Habits/微习惯」「黄金行为」「锚点/庆祝」「设计习惯」，或要把愿望改写为具体行为、排查某行为为何在特定时点没发生、降低摩擦并形成稳定重复、终止或替换普通非临床坏习惯时使用；也可用于为知情且可拒绝的他人或团队设计具体行为。一般生产力闲聊、仅需医学诊断/治疗、成瘾或精神健康危机不自动触发；若用户明确要求用本框架分析高风险问题，只启用安全分流，不替代专业服务。
```

价值：补齐真实入口，同时用“明确”“具体行为”“普通非临床”和“只启用安全分流”限制泛化触发。

### 2. 替换 Step 1 的“处方药硬门”

```markdown
**处方药硬门**：只要涉及当前漏服、疑似重复服用、停药打算或剂量不确定，立即暂停 MAP/Tiny Habits 设计；不得推断或建议补服、加倍、停药、改剂量或用微行为替代既定方案。先查药品说明与既有医嘱，并联系开药医生或药师确认当前处理方式；疑似过量、严重不良反应、意识异常或即时危险时，直接联系当地急救或毒物咨询服务。只有当前事件与既定用药方案已经澄清后，才可在不改变方案的前提下，一次只测试一个未来提醒或环境变量。
```

价值：把“当前剂量事件”与“未来执行支持”切开，并保留一次一变量约束；这是本 Skill 最重要的失败预防。

### 3. 收紧默认输出，并修正 Masterplan 归属

将“先分层”中的 Masterplan 说明替换为：

```markdown
- **Behavior Change Masterplan**：Fogg 官方 2020 英文配套工具包使用的总名，第一阶段是创建新习惯；中文原书把用于解结不想要行为的三阶段方案译为“行为改变系统方案”。本 Skill 在逆向 MAP 与替代行为流程外加入风险分级和升级处理；这些安全扩展不归因于 Fogg。
```

同时将“默认输出模板”整体替换为：

```markdown
## 默认输出模板

信息不足时，仅当缺口会改变安全判断或首个试验才提问；每轮最多问一个阻断性问题，其余写成“待核假设”。只输出当前主路由需要的字段：

> **目标行为**：在【主体/情境/时点】做【可观察动作】。  
> **判断**：【已知】；【合理推断】；【唯一待核项，如有】。  
> **首个最小改动**：只改【Prompt / Ability / 匹配 / 环境中的一个变量】，具体为【动作】。  
> **观察**：在【与目标行为频率匹配的短周期】记录【一个主要行为指标】；本轮不同时改其他变量。  
> **下一步**：若【成功/连续失败/负担或风险信号】出现，则【保留、回退、重选、停止或升级】。

仅当目标是安全的重复行为时，追加：

> **微习惯配方**：在我【锚点最后动作】之后，我会【安全的微行为】；可选【真实、即时、非控制性的积极反馈】。

坏习惯终止、高风险、为他人设计和纯框架问题改用对应主路由，不补齐无关字段。
```

价值：删除固定全量问诊与模板漂移，显式保护用户选择、频率匹配、一次一变量和退出条件；六模型仍可按需调用，而不是强迫用户走完整漏斗。

## 六模型可操作性结论

六模型的分工总体清楚：模型 2 保留行为候选与主体选择，模型 3–5 处理摩擦、时序和重复，模型 1/6 负责诊断与失败迭代。用户选择主要由“本人想做”、自主门槛、可拒绝/退出和返回模型 2 保护，未被单一路径取代。真正的运行风险不是模型不够，而是 Agent 同时调用太多模型；上述默认输出收紧后，主路由、单变量试验和停止条件会更稳定。

## 改动摘要

1. Frontmatter 补“终止/替换坏习惯”和合伦理的他人/团队设计入口，并收紧高风险触发。
2. 处方药硬门先暂停行为设计，澄清当前剂量事件后才允许优化未来提醒。
3. 将 Masterplan 精确归因于官方英文 Toolkit，并把默认输出改成按路由、单问题、单变量、频率匹配的最小模板。
