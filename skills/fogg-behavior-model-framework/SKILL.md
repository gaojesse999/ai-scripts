# 福格行为设计框架

## 先分层：四者不相等

**B=MAP ≠ Behavior Design ≠ Tiny Habits ≠ Behavior Change Masterplan。**

- **B=MAP（Fogg Behavior Model）**：诊断某个具体行为为何在某一时刻发生或未发生；它是概念性设计启发式，不是数学乘法公式或科学定律。
- **Behavior Design**：从愿望/成果澄清、行为发散与匹配，到摩擦、提示、试验和重设计的工具链；B=MAP 只是其中一个底层诊断模型。
- **Tiny Habits**：把已匹配的微行为接到锚点，并可选地加入即时积极反馈，以创造稳定重复和学习机会的应用方法。
- **Behavior Change Masterplan**：Fogg 官方 2020 英文配套工具包使用的总名，第一阶段是创建新习惯；中文原书把用于解结不想要行为的三阶段方案译为“行为改变系统方案”。本 Skill 在逆向 MAP 与替代行为流程外加入风险分级和升级处理；这些安全扩展不归因于 Fogg。

同样要分开四类结果：**一次行为发生 → 重复执行 → 自动性/习惯 → 足量、长期、功能性成果**。前一层成功不自动证明后一层成立。

## 激活后的工作原则

1. 一次只锁定一个主体、一个可观察行为和一个目标时点。
2. 先去掉“懒、没毅力、不自律”等人格归因，再检查可修改变量。
3. 先保证安全、合法、自主和基本权利，再追求行为发生率。
4. 先给首个可逆的小改动，再给扩展方案；不一次堆满所有技巧。
5. 对框架定义说清楚；对个体处方使用“测试—观察—调整”。
6. 案例只展示运行方式，不当作因果证明。

## Agentic Protocol

### Step 1｜问题分类

先判断用户的问题属于哪类；可并列，但必须指定主路由：

1. **纯框架问题**：概念、术语、模型关系、版本或证据。可直接回答，不必强行收集个人资料。
2. **想建立一个行为**：路由到模型 2 → 3 → 4 → 5，模型 1 用于诊断失败。
3. **行为没有发生**：先用模型 1，再按缺口转到模型 2/3/4。
4. **想终止或替换不想要行为**：先做风险分级，再进入模型 6 的坏习惯逆向解结。
5. **为他人、团队、组织或产品设计**：先过知情、可拒绝、可撤回和反暗黑模式门槛，再运行相关模型。
6. **临床、结构、安全、法律或高风险问题**：模型只做局部行为分析，不替代专业、组织、政策或法定流程。

**模型交接规则**：模型 1 是“目标行为在某时点未发生”的主诊断入口；模型 6 是失败迭代、风险升级和不想要行为解结的治理层。普通新行为失败时只在模型 1 做 P→A→M 诊断，模型 6 负责观察期、单变量重试、回退与升级。终止不想要行为时以模型 6 为主；只有需要生成或筛选替代行为，才调用模型 2。

**处方药硬门**：只要涉及当前漏服、疑似重复服用、停药打算或剂量不确定，立即暂停 MAP/Tiny Habits 设计；不得推断或建议补服、加倍、停药、改剂量或用微行为替代既定方案。先查药品说明与既有医嘱，并联系开药医生或药师确认当前处理方式；疑似过量、严重不良反应、意识异常或即时危险时，直接联系当地急救或毒物咨询服务。只有当前事件与既定用药方案已经澄清后，才可在不改变方案的前提下，一次只测试一个未来提醒或环境变量。

### Step 2｜按六模型反推五个诊断/研究维度

信息够用就开始，不为完整而盘问。只核对会改变安全判断、主路由或首个试验的项目：

1. **目标行为与时点**：它是 aspiration、outcome 还是 behavior？谁在何处、何时、做什么？评价一次发生、重复、自动性，还是功能成果？
2. **主体与自主性**：目标由谁提出？主体是否知情、愿意、可拒绝、可退出、可撤回数据？谁获益、谁承担风险？
3. **摩擦/资源**：时间、资金、体力、脑力、日程中哪一环最弱？是否缺技能、工具、协助、无障碍或结构性机会？
4. **提示/环境**：目标时点前有什么可核验 Prompt？是否被注意且当时可执行？环境里有哪些竞争行为、默认项和提示疲劳？
5. **证据/风险**：主张来自作者体系、独立研究还是推断？是否涉及临床症状、成瘾、药物、疼痛、危机、安全、权力或法律边界？

**外部核实规则**：若回答需要具体公司/产品现状、医学结论、安全规范、法律要求或最新研究，必须先用 WebSearch 等可用工具核实，并标明信息日期与来源层级。纯框架解释可依据本 Skill 和 `references/research/` 直接回答。

### Step 3｜输出设计

1. 先复述一个可观察的目标行为和时点。
2. 给 MAP 诊断，并区分“已知、合理推断、仍需观察”。
3. 只选一个首要杠杆，优先测试 Prompt 或 Ability；若行为选错，返回匹配。
4. 需要重复时才写 Tiny Habits 配方；Celebration 可省略。
5. 给短观察期、客观指标和一次只改一个变量的重设计规则。
6. 明确升级、停止、转介和撤回条件。

## 默认输出模板

信息不足时，仅当缺口会改变安全判断或首个试验才提问；每轮最多问一个阻断性问题，其余写成“待核假设”。只输出当前主路由需要的字段：

> **目标行为**：在【主体/情境/时点】做【可观察动作】。  
> **判断**：【已知】；【合理推断】；【唯一待核项，如有】。  
> **首个最小改动**：只改【Prompt / Ability / 匹配 / 环境中的一个变量】，具体为【动作】。  
> **观察**：在【与目标行为频率匹配的短周期】记录【一个主要行为指标】；本轮不同时改其他变量。  
> **下一步**：若【成功/连续失败/负担或风险信号】出现，则【保留、回退、重选、停止或升级】。

仅当目标是安全的重复行为时，追加：

> **微习惯配方**：在我【锚点最后动作】之后，我会【安全的微行为】；可选【真实、即时、非控制性的积极反馈】。

坏习惯终止、高风险、为他人设计和纯框架问题改用对应主路由，不补齐无关字段。

## 证据纪律

### 证据等级

- **A｜较强独立证据**：独立系统综述、元分析、直接 RCT，或多项方向一致的同行评审研究。
- **B｜中等独立证据**：独立纵向/观察研究、邻近理论直接检验，或多项捆绑干预结果；支持方向，但未隔离 Fogg 专有机制。
- **C｜模型与实践证据**：原始模型论文、作者著作/官网、系统案例；能说明如何运行，不足以证明独特因果效力。
- **D｜薄弱或推断性证据**：个案、自我实验、回顾叙事、未隔离机制或未经检验的外推。

作者资料可以高可信地证明“Fogg 主张了什么”，不自动证明“该主张成立”。外部 implementation intentions、SDT、强化和自动性研究不能全部记作 Tiny Habits 的验证。

### 强制表述

- 写“与独立研究相容”，不把邻近证据写成“验证了 Fogg 专有机制”。
- 写“设计启发式/概念阈值”，不把 B=MAP 写成数学公式、可计算概率或科学定律。
- 写“稳定情境中的重复与自动性增长有较强证据”；不得把“情绪而非重复创造习惯”写成已证实事实。
- 把 Celebration 定位为**可选的积极反馈**；其对自动性的独立增益证据弱，不声称必然释放特定多巴胺或立即固化习惯。
- 微行为可以降低启动门槛，但不保证自然增长到有效剂量、质量或长期成果。

## 六个核心模型

### 模型 1｜时点汇合诊断：B=MAP

**一句话**：先锁定“谁在什么时刻做哪个具体动作”，再检查当时的 Motivation、Ability 与 Prompt 是否共同达到行为发生条件。

**运行步骤**

1. 把输入改写为一个具体、可观察的 Behavior。
2. 固定目标时点，记录行为前而非事后反推的 M/A/P 线索。
3. 先查 Prompt 是否出现、被察觉且指向“现在做”。
4. 再查 Ability：此刻做起来是否足够容易，具体卡点是什么。
5. 最后查 Motivation：主体此刻是否真想做这个具体动作。
6. 一次只改一个变量，观察是否改变行为；模型不自动给出处方。

**案例**：员工没有按时提交日报。若他愿意且表单只需一分钟，但下班时没有可见提示，首个试验应是把提示放到关机前，而不是开展“责任心培训”。

**证据等级**：完整 MAP 结构 **C**；M/A 与执行相关的方向 **B**；行动线的统一函数、精确形状与普适性 **D**。

**局限/失效条件**

- “更健康、专注、改善关系”不是可直接套 MAP 的 Behavior。
- M/A/P 没有通用单位，不能用等号做数值乘法或计算行为概率。
- 事后把任何念头都叫 Prompt、把一切约束都塞进 Ability，会形成循环解释。
- 适合局部时点诊断，不替代长期自动性、剂量、质量、结构或成果分析。

### 模型 2｜行为清晰化与匹配

**一句话**：愿望指方向，成果定义结果，只有具体行为能被设计；先发散，再选择“有影响、本人想做、现实做得到”的黄金行为。

**运行步骤**

1. 区分 Aspiration、Outcome、Behavior。
2. 围绕愿望生成行为集群：一次性行为、新习惯、停止/替换行为。
3. 第一轮只判断各行为对成果的潜在影响。
4. 第二轮判断主体是否想做、现实是否做得到。
5. 选择三项同时较高的 Golden Behavior；没有合适候选就继续发散，不强挑“应该做”的方案。

**案例**：“建立应急金”是愿望，“存到 5000 元”是成果；“每次工资到账后自动转 200 元到独立账户”才是可设计行为。若现金流不允许，就应重选行为而非责怪自控力。

**证据等级**：三层分法与专有筛选流程 **C**；自主性匹配方向 **A/B**；Focus Mapping 是否优于其他筛选方式 **C/D**。

**局限/失效条件**

- “想做”可能受短期冲动、胁迫、信息不足或成瘾性设计影响。
- 医疗、安全、照护、合规等必要目标不能仅因“不想做”而取消；应在实现路径上最大化自主。
- 自报可行性不能替代对资源、残障、季节、照护和制度条件的检查。

### 模型 3｜摩擦优先

**一句话**：不要先要求更努力；扫描当前行为的能力链，找到主要摩擦，再用技能、工具/资源或更小动作降低门槛。

**运行步骤**

1. 扫描时间、资金、体力、脑力、日程/惯例适配五环。
2. 选当前最主要的摩擦；“最弱环”是诊断启发式，不是定律。
3. 生成三路方案：提升技能、提供工具/资源/协助、缩小行为。
4. 缩小时区分 `Starter Step`（动作链的安全入口）与 `Scaling Back`（同一行为的极小剂量）。
5. 保留最小基线；偶尔多做不自动抬高下次最低标准。
6. 三路都不可行时，返回模型 2 重选行为或升级结构层。

**案例**：每周备餐五小时总失败。扫描后发现时间与体力是主要摩擦，可测试预切食材、简化菜单和家庭分工，而不是反复观看健康教育视频。

**证据等级**：降摩擦与启动 **B**；稳定情境中的易重复 **A/B**；五环链、单一最弱环和特定秒数阈值 **C/D**。

**局限/失效条件**

- 微行为不能违反安全步骤，也不能把必要治疗或训练剂量无限缩小。
- 疼痛、药物副作用、执行功能障碍和临床症状不能只当一般摩擦。
- 缺钱、排班、歧视、无障碍缺失等应显式进入资源/Opportunity/政策层，而不是个人归责。
- 购买工具可能只是拖延，资源成本也不能暗中转嫁给他人。

### 模型 4｜时序架构

**一句话**：让 Prompt 在真实可执行且能被察觉的时刻出现；重复习惯可优先测试稳定锚点，并精确到前序事件的最后动作。

**运行步骤**

1. 明确 Prompt 是“现在做”的信号，不是一般知识或动机演讲。
2. 同时用两条轴检查提示：来源为 Person/Context/Action；功能为 Spark/Facilitator/Signal，二者不能混成一套分类。
3. 一次性或低频任务可用适时日历/情境提示；重复行为可测试稳定 Action Prompt。
4. 选择 Anchor 时检查同地点、同频率、同主题。
5. 把“早餐后”收紧为可感知的 `Trailing Edge`，如“关掉水龙头后”。
6. 监测注意率、忽略率、负担和撤除提示后的表现；若当时不可执行，先修 Ability。

**案例**：“早餐后擦台面”总被忘记，可改为“关掉厨房水龙头后擦一下台面”，使时点边界更明确；若早晨经常赶时间，则锚点本身不匹配。

**证据等级**：明确线索—反应计划 **A**；稳定情境与自动性 **A/B**；行动锚点普遍优于钟点线索的主张 **C/D**。

**局限/失效条件**

- 提示过多会产生疲劳、习惯化或反感。
- 锚点不稳定、频率不匹配、地点相隔太远时会失效。
- 不得在驾驶、过马路、操作机器等时刻制造分心。
- 提示促成一次行动不等于形成长期习惯。

### 模型 5｜Tiny Habits 学习环

**一句话**：把一个匹配且足够小的行为接到明确锚点，在稳定情境中重复，并可选地加入真实、即时、非控制性的积极反馈，再用结果重配。

**运行步骤**

1. 确认行为已通过匹配并缩成安全的 Tiny Behavior。
2. 写配方：`在我【Anchor 最后动作】之后，我会【Tiny Behavior】；然后可选【Celebration】。`
3. Celebration 可以是微笑、点头、心中确认或具体记录；尴尬、虚假、控制性时就删除或更换。
4. 观察是否想起、是否执行、情境是否稳定、实际剂量与自动性是否变化。
5. 失败时只改锚点、行为大小、环境、匹配或反馈中的一个主要变量。
6. 自然想加量且功能指标改善时可小幅扩展；低状态日仍允许回到安全基线。

**案例**：“刷完牙并把牙刷放回杯中后，我清洁一颗牙；然后点头确认完成。”一颗牙训练启动，不代表完整口腔护理已经达标；实际护理剂量仍需单独评估。

**证据等级**：明确线索与稳定重复 **A**；组合 Tiny Habits 项目 **B/C**；即时自我庆祝对自动性的独立效应 **D**。

**局限/失效条件**

- ABC 不是 B=MAP 的替代公式：Anchor 提供 Prompt，Tiny Behavior 提高 Ability，Celebration 发生在行为之后。
- Shine 是真实成功感，不等于 Celebration 这个反馈动作；也不保证每个人都会产生。
- 不存在人人适用的 5/21/60/66 天固定阈值。
- 不宣称积极情绪取代重复，也不宣称微行为必然长成足量行为。
- 不用积极表达压制哀伤、抑郁、创伤或身体疼痛。

### 模型 6｜无责迭代与分级升级

**一句话**：把未执行视为设计信息，每轮只修改一个关键变量；对不想要行为逆向解结，对临床、安全、权力和结构问题及时停止个人习惯化解释并升级。

**运行步骤**

1. 记录“什么提示后，本想做什么，实际发生什么”，去掉人格判决。
2. 先筛查临床、安全、零容忍风险、权力不对等和结构约束。
3. 普通新行为失败时，按 P→A→M 排障；若行为本身不匹配，回到模型 2。
4. 一轮只改一个主要变量，预先设观察期、指标、回退和停止条件。
5. **坏习惯逆向解结**：把“少刷手机/少吃糖”等概括标签拆成具体行为结；先移除或规避 Prompt，再增加旧行为摩擦、降低其 Ability，最后才处理 Motivation 或设计更想做、更易做的替代行为。
6. 对“没有做该做的事”这类遗漏型问题，设计要发生的新行为，不把“不作为”当作可终止动作。
7. 风险超出自助范围时，转向合格专业支持、组织流程、无障碍/资源配置、政策或法定安全措施。

**案例**：睡前刷短视频不是一个单一“手机瘾”。可先拆为“上床后点开通知”“视频结束后继续上滑”等行为结；关闭通知、移出卧室、退出自动登录分别作用于 Prompt 与 Ability。若伴随严重失眠、躁狂、戒断或功能损害，应升级评估。

**证据等级**：迭代流程与逆向 MAP **C**；刺激控制/增摩擦等邻近方向 **B**；自主支持 **A/B**；临床、结构和伦理升级是规范性安全边界。

**局限/失效条件**

- 严重成瘾、自伤、进食障碍、强迫、精神健康危机或药物戒断不能按普通习惯自助处理。
- 酒后驾驶、自伤等零容忍风险不存在可接受的“先减少一点”剂量。
- 不能用罚款、羞辱、公开排名或过度追踪把“增摩擦”变成伤害。
- 对他人应用必须知情、可拒绝、可撤回；禁止隐秘操控、dark patterns、hypernudging 和利用脆弱点。

## 九条 if-then 启发式

### H1｜如果输入仍是抽象目标，就先清晰化

**IF** 用户说“更健康、更专注、别拖延”，**THEN** 区分愿望、成果、行为，并把行为写成“主体 + 时点 + 可观察动作”。

### H2｜如果具体行为没发生，就按 P→A→M 排障

**IF** 某动作在目标时点未发生，**THEN** 先查提示，再查当时可执行性，最后查动机；这是实务顺序，不是唯一因果定律。

### H3｜如果动机正高，就用浪峰安装系统

**IF** 主体此刻高度有动力，**THEN** 用窗口学习技能、取得工具、预约支持或重设环境，不把浪峰当作未来每天完成高难行为的保证。

### H4｜如果行为太难，就扫描能力链并生成三路方案

**IF** 行为反复卡住，**THEN** 扫描时间、资金、体力、脑力、日程，分别考虑技能、工具/资源、Starter Step 或 Scaling Back。

### H5｜如果需要重复，就设计精确而不过量的提示

**IF** 要建立重复行为，**THEN** 优先测试稳定且适时的线索，把锚点写到最后动作，并监测忽略率与提示疲劳。

### H6｜如果配方不稳定，就一轮只改一个变量

**IF** 配方连续未执行，**THEN** 只改匹配、锚点、行为大小、环境或反馈中的一个主要变量，短期重试并保留回退条件。

### H7｜如果想加量，就保留基线并看功能证据

**IF** 行为已轻松稳定且本人自然想多做，**THEN** 小幅扩展，同时检查实际剂量、质量和成果；疲劳、疼痛或生活中断时退回安全基线。

### H8｜如果想终止坏习惯，就先分级再逆向解结

**IF** 是普通、非临床的不想要行为，**THEN** 拆成具体行为结，依次处理 P、旧行为的 A、M/替代；若有成瘾、危机或零容忍风险，先转专业或安全流程。

### H9｜如果为他人设计，就先审查自主与受益分配

**IF** 行为主体不是设计者本人，**THEN** 先确认目标、知情同意、拒绝权、退出方式、数据撤回、谁受益谁担责；任何暗黑模式请求都应拒绝优化。

## 术语纪律

- **Aspiration（愿望）**：持久、抽象的方向，如“更健康”。
- **Outcome（成果）**：可衡量的预期结果，如“本月平均睡眠达到 7 小时”。
- **Behavior（行为）**：在明确时点可观察的动作，如“22:30 把手机放到客厅充电”。三者不可互换。
- **Motivation**：当时对该具体行为的想做程度，不等于品格、意志力或长期价值。
- **Ability**：此刻做该动作的容易程度/可执行性，不等于人的稳定能力素质，也不应吞并结构性 Opportunity。
- **Prompt**：指向“现在做”的行动信号；2009 年原始文献称 `Trigger`。
- **Anchor**：Tiny Habits 中作为 Action Prompt 的稳定既有动作或事件；不是所有 Prompt 都是 Anchor。
- **Celebration**：行为中或刚结束后的可选积极反馈动作；不是延迟奖品、金钱激励或强迫表演。
- **Shine**：真实的成功感，是可能的主观体验；不是 Celebration 的同义词，也不是必然结果。
- **Action Line**：M/A 达到行为发生阈值的概念曲线，不是步骤清单，没有通用参数。

引用强主张时分开写：

> **作者主张**：Fogg 强调积极情绪可帮助习惯编码。  
> **独立证据**：稳定情境重复与自动性渐进增长证据较强；即时自我庆祝的独立增益仍缺组件试验。

## 核心张力与流派/证据分歧

### 张力 1｜简洁可用 vs 解释分辨率

B=MAP 的三个桶适合快速排障，却可能让 Ability 吸收资源、机会和权力，让 Prompt 事后无限扩张。单个动作可先用 MAP；复杂健康、组织和公共问题应补 COM-B 的 Opportunity、政策、权力和临床分析。

### 张力 2｜即时发生 vs 长期习惯与成果

B=MAP 主要解释某时点的一次行为；自动性研究关注稳定情境中的长期重复。一次完成、重复、习惯和足量成果必须分别测量。

### 张力 3｜积极情绪 vs 稳定重复

Fogg 把 Celebration/Shine 放在习惯方法核心；主流 habit automaticity 研究更强调线索—反应在稳定情境中的渐进学习。可操作综合是把积极反馈视为可选放大器，不能写成重复的替代物。

### 张力 4｜有效促发 vs 伦理正当

精准提示和降摩擦既能支持健康行动，也能服务无限滚动、冲动消费和员工服从。模型回答“怎样更可能发生”，不回答“是否应该发生”；后者必须额外审查知情、退出、长期福祉和受益分配。

## 伦理与临床/结构/安全边界

### 对他人应用

- 必须让行为主体知情，并提供真实、易用的拒绝、退出和撤回机制。
- 儿童、患者、员工、伴侣和平台用户存在权力差时，提高保护标准。
- 数据最小收集、限定用途与期限；不得用羞耻、经济压力、隐秘个性化或脆弱点优化服从。
- **禁止暗黑模式**：不帮助设计不可退出、误导、强迫、诱导成瘾或短期转化损害长期福祉的机制。

### 必须暂停或升级

- 严重成瘾、药物依赖/戒断、自伤/自杀风险、进食障碍、强迫、躁郁、重度抑郁、创伤反应或其他危机；
- 异常疼痛、眩晕、药物副作用或需医学评估的身体症状；
- 家暴、骚扰、歧视、危险环境、违法要求或零容忍安全风险；
- 贫困、排班、照护负担、无障碍缺失、组织权力和政策约束主导的问题。

此时可用 MAP 描述一个局部节点，但不得用微习惯替代专业治疗、安全计划、组织责任、资源支持或法律流程。
