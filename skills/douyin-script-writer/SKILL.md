# 抖音知识口播脚本生成器

## 定位与目标

为**知识类真人口播**短视频生成高留存率、高认同度与强吸粉转化的标准化脚本。核心把控指标：
- **降低 2 秒跳出率**（目标 < 40%）：开头 15 字黄金痛点反问 + 前 3 秒头顶固定大标题卡（抓牢静音刷屏人群）；
- **提升完播率**（目标 > 0.8%）：严格控制口播时长在 60-90 秒，四段式紧凑推进，无废话拖沓；
- **激发自发点赞**：战友视角共情 + “高反差生活化神比喻”（制造认知顿悟，打通点赞动机）；
- **稳定公域吸粉**：结尾利他型关注价值钩子（给完播铁粉一个明确的明天继续看你的理由，已实战验证转粉）。

---

## 输入要求

用户需提供：
1. **主题**：一句话概括视频要讲什么（例：如何解决读完书转头就忘的问题）
2. **主要内容**：核心知识点、方法论、案例素材（可以是口语化的草稿、笔记、读书摘录等）

可选输入：
- 目标受众描述
- 是否为系列视频（如果是，说明是第几集）
- 希望的视频风格偏好

## 执行流程

### Step 1：内容评估 — 判断是否需要拆分

**规则：口播脚本最终字数必须控制在 250-450 字之间（对应约 60-120 秒口播时长，按中文口播语速 ~4 字/秒计算）。**

评估用户提供的内容量：
- 如果核心知识点 ≤ 2 个 → 做成 **单条视频**，进入 Step 2
- 如果核心知识点 ≥ 3 个 → 必须 **拆分为系列**，为每条视频分别执行 Step 2-5

拆分时向用户输出**系列规划表**：

```markdown
## 系列规划：[系列名称]

| 集数 | 子主题 | 核心知识点 | 预计时长 |
|------|--------|----------|---------|
| 第1集 | ... | ... | ~80秒 |
| 第2集 | ... | ... | ~80秒 |
| ... | ... | ... | ... |

建议发布节奏：严格遵守一日一更，连续 N 天发布
每集结尾预告下一集内容，引导关注
```

询问用户确认系列规划，以及先生成哪一集的脚本。

---

### Step 2：生成开头钩子候选（至少 3 个）

开头钩子是决定 2 秒跳出率的听觉核心。必须为用户生成**至少 3 个候选钩子**，每个使用不同的钩子类型。

#### 钩子类型库

从以下类型中选取，**优先选前 3 种**（数据验证效果最好）：

| 类型 | 公式 | 示例 | 适用场景 |
|------|------|------|---------|
| **痛点反问** | "你有没有[具体场景]？" | "你有没有这种情况？花几天看完一本书，画满荧光笔，过两天脑子还是一片空白" | 通用，效果最稳定 |
| **反常识** | "[违反直觉的结论]" | "读书读完就忘，先别自责，这真不是你记性差，而是大脑的节能机制" | 适合有认知颠覆的内容 |
| **结果前置** | "我用[方法]，[具体结果]" | "我用一个技巧，把整本书的收获浓缩成两行字，比硬啃十本书都有用" | 适合有个人案例的内容 |
| **数字钩子** | "[数字] + [利益点]" | "两步，帮你彻底戒掉坏习惯" | 适合方法论、步骤类 |
| **场景代入** | "每天下班回家，你是不是[场景]" | "每天下班回家，你是不是往沙发上一躺就啥也不想干了" | 适合日常生活类痛点 |
| **对比钩子** | "[普通人做法] vs [正确做法]" | "普通人读书把整本书往脑子里搬，聪明人只盯着一句话死磕" | 适合方法对比类 |

#### 钩子生成规则

1. **必须在 15 字以内切入痛点**（前 2 秒对应约 8-15 字）
2. **禁止使用**以下无效开头：
   - ❌ "这条视频我会分享..."（"这条视频"是废话）
   - ❌ "今天我来给大家讲一下..."（教师腔，无钩子）
   - ❌ "大家好，我是xxx..."（新号无人设，必被划走）
   - ❌ "如果你有xxx问题，这个视频可以帮你解决"（太平淡，缺少场景感）
3. **必须包含**以下至少一项：具体场景、具体数字、反问句式、反常识判断
4. 每个钩子候选附带**为什么有效**的一句话解释

---

### Step 3：构建脚本结构

使用以下**四段式黄金结构**（历经多轮数据验证的最优结构）：

```
[0-5秒]   钩子段：痛点场景 + 情绪共鸣（Step 2 选定的钩子）
[5-15秒]  问题放大段：战友视角肯定付出 + 客观归因（大脑机制/客观规律）
[15-55秒] 核心方法段：1 个核心概念 + 1 个生活化神级比喻（情绪顿悟）+ 1 个极小可落地指令（给糖吃）
[55-75秒] 收尾段：认知金句 + 利他型关注价值钩子（战友身份 + 持续交付利益）
```

#### 各段详细要求与数据铁律

**1. 钩子段（0-5秒，约20-35字）：**
- 使用 Step 2 中选定的钩子；
- 第一句话必须在 2 秒内说完（8-12 字为佳）；
- 紧跟场景细节补充，让观众下意识产生“说的就是我”的代入感。

**2. 问题放大段（5-15秒，约40-60字）：**
- **视角铁律（战友视角，严禁居高临下）**：
  - 严禁站在上帝视角否定、嘲讽或批评观众（严禁出现“演给别人看”、“像小学生交差”、“没过脑子”等攻击性词汇）；
  - 必须**首先肯定观众的付出与痛点**，将问题根源归因于客观的大脑生物学规律或方法机制（“先别自责，这真不是你记性差，而是大脑天生是个节能专家”）；
  - 作用：给观众台阶下，消除心理防御，形成“我和你站在同一战壕”的深度共情。

**3. 核心方法段（15-55秒，约150-200字）：**
- **只讲 1 个核心方法**（严禁罗列 3 个以上复杂要点）；
- **配 1 个高反差的生活化神比喻（顿悟爆点，激发自发点赞）**：
  - *数据实证*：10/07 视频 A 斩获 28 个陌生人自发点赞，核心在于用“买错烂片电影票，非要硬看完两个小时”生动具象化了沉没成本，观众会心一笑瞬间顿悟；而平铺直叙的说明文即便再有道理，点赞往往只有个位数；
  - *要求*：必须把抽象概念映射为具有反差感的生活细节（例如：把知识缝接比作“烂片电影票”、把大脑清理记忆比作“手机后台杀进程”、把贪多求全比作“去超市采购塞满冰箱发霉”等）；
- **落地动作交付（给糖吃，极其重要）**：
  - 必须包含一个**明天起床就能立刻照着做、毫不费力的极小动作指令**（例如：“今晚翻开书，不用记页数，只要看到一句触动你的话，立马停下拿出笔写两行字：第一行写那句话，第二行写一个明天就能做的微小改变”）。

**4. 收尾段（55-75秒，约40-60字）：**
- 一句话认知金句（有力、通透、可被截图传播）；
- **利他型关注价值钩子（已实操验证带来公域精准转粉）**：
  - *数学漏斗定论*：全天能听完整条视频的公域观众仅 2~4 人。在末尾设计无人回答的选择题是徒劳的；但他们是信任度拉满的超级精准铁粉，必须交付**“明天继续看你的理由”**；
  - ❌ **严禁官方自嗨**：“我是专注个人成长的博主，致力于帮助大家认知跃迁，欢迎关注我”（官腔浓厚，直接划走）；
  - ✅ **固化统一收尾话术（全库铁律）**：
    **所有口播脚本收尾必须强制统一使用以下标准句：**
    > **“我是钩玄纪，持续分享可实操的干货，关注我，每天进步一点点。”**
- **禁止**使用“好了今天就分享到这里”这类无效泄气废话。

### Step 4：生成完整脚本

基于 Step 3 的结构，输出**逐字口播稿**，并严格遵循字数硬限制与口语化要求。

#### 脚本撰写规则
1. **口语化**：读出来要自然流畅，像跟对桌朋友聊天，不用书面语；
2. **短句为主**：每句话 10-20 字，避免长难句；
3. **停顿标注**：关键转折处留 0.5 秒停顿标记（用 `[停顿]` 标注）；
4. **字数硬限制**：250-450 字（严格对应 60-100 秒时长）。

### Step 5：输出拍摄机位与画面包装规范（立竿见影根治硬伤）

每次生成脚本后，**必须强制输出以下三套视觉执行标准**，指导播主剪辑与拍摄：

```markdown
## 三、📌 拍摄机位、出镜神态与画面包装指南

### 1. 拍摄机位与黄金三分法留白（根治“大头怼脸”与“文字贴脸”）
- **拉开机位距离**：手机后移 20~30 厘米（或人后退半步），拍摄中景（露出胸部至头顶）；
- **头顶留白铁律**：**博主头顶距离画面顶部必须预留 15%~20% 的纯净空白空间**（这是放置大标题卡的专属安全区，严禁大头顶满屏幕）；
- **视线锁定镜头孔**：将提词器悬浮窗紧贴手机摄像头小圆孔正下方，**录制时眼神直视摄像头孔**，面带诚恳与从容微笑，杜绝眼神向下游离。

### 2. 00:00 - 00:03 秒【顶部固定花字大标题卡】（降低2秒跳出率的头条武器）
- **所在物理位置**：**博主头顶上方的空白留白区**（严禁压在额头、头发或眉毛上！）；
- **呈现形式**：黄底黑字或红底白字高对比粗体大字，宽度占画面 70%~80%；
- **展示时间**：**从 00:00:00 秒开始常驻至 00:03:00 秒整**；
- **核心作用**：在视频刚滑出的第 0 秒，让静音刷屏的公域用户一眼看清核心痛点与价值，杜绝秒划走。
- **推荐标题文案**：
  - 主标题卡（6-8字以内）：「......」

### 3. 正片动态强调花字规范（辅助听觉理解）
- **入场时机与视觉排他原则**：**00:00 - 00:03 前3秒全屏仅允许展示【顶部固定大标题卡】与口播字幕，绝对禁止弹出任何侧边动态花字！** 所有动态强调花字必须在大标题卡淡出后（00:03 之后，建议约 00:08 开始）才按需出现，避免画面杂乱争夺注意力；
- **绝对禁区**：**严禁将花字贴在博主的额头、眼睛、嘴唇、下巴或任何五官上**（杜绝“创可贴打码感”，保护真人口播亲和力）；
- **规范摆放位置**：只能放在**身体两侧空白处**（肩膀斜上方或侧方空隙）或大标题卡淡出后的**头顶安全区**；
- **词组精炼完整**：每次出现 4~6 字完整有力的关键词（杜绝断句半截词），停留 1.5~2 秒后利落消失。
- **关键花字时刻推荐**：
  - `[00:08]` 「......」（位置：右肩上方 / 痛点场景定格或客观归因）
  - `[00:18]` 「......」（位置：头顶留白区 / 设问转折）
  - `[00:35]` 「......」（位置：左肩上方 / 核心方法或神比喻关键词）
  - `[00:50]` 「......」（位置：画面底部卡片 / 核心认知金句）
  - `[01:05]` 「......」（位置：右肩上方 / 极小微动作指令）
```

## 质量自检清单

生成脚本后，必须逐项自检，不通过者必须修正后再输出：

- [ ] **开头钩子**：第一句 ≤ 15 字，在 2 秒内切入痛点，无“这条视频”“今天给大家分享”“大家好”等废话
- [ ] **总字数与时长**：总字数在 250-450 字区间内（60-100 秒）
- [ ] **核心知识点**：只聚焦 1 个核心方法（非多点罗列）
- [ ] **生活化神比喻**：核心方法段是否配有 1 个**高反差的生活化神比喻**（像“烂片电影票”一样具象，能让人顿悟/会心一笑）
- [ ] **微动作交付**：是否包含 1 个明天即可无痛执行的极小微动作指令（给糖吃、易落地）
- [ ] **战友视角审查**：全篇绝无居高临下的否定、批评或说教词汇（严禁“演给别人看”“交差”），将问题归因于客观规律
- [ ] **利他关注钩子**：结尾必须统一使用固化标准话术：「我是钩玄纪，持续分享可实操的干货，关注我，每天进步一点点。」
- [ ] **头顶留白提示**：是否明确提示拍摄机位头顶留白 15%~20%，严禁大头怼脸
- [ ] **第0秒大标题卡**：是否在 00:00-00:03 标配头顶固定花字大标题卡（用于静音滑屏留存）
- [ ] **花字不贴脸铁律**：是否明确标明正片花字置于身体两侧或头顶，严禁覆盖面部五官和额头
- [ ] **自动落盘**：已自动将完整内容保存至「口播脚本/YYYYMMDD-HHMMSS-标题.md」并给出链接
