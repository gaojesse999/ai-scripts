针对你**自评的三个短板**，先给一张对应表，后面的训练都围绕它展开：

| 你的短板 | 具体表现（你的原话例子） | 主要用哪些能力对治 |
|---|---|---|
| **思考浅** | 测试用例失败，第一反应是"和以前某问题像"，而非列可能性再缩小 | 假设-验证式思考、议题树/MECE、第一性原理、二阶思维、抽象↔具象切换 |

|---|---|---|---|

### 主线一：认知 / 思维能力

> 学习顺序已排好：**先学能立刻改善"想清楚+说清楚"的（1、2、3），再学拓展深度的（4、5、6、7），心智模型库（8）作为全程长期积累。** 新增的 **元认知（9）与抽象↔具象（10）贯穿全程**，以每日/每周微练习形式嵌入，不额外占大块时间。

| # | 框架 / 方法 | 它治你哪个短板/盲区 | 学会的标志（可自测勾选） |
|---|---|---|---|
| 1 | **结论先行 + 金字塔结构** | 表达乱 | 任何观点都能"先给一句话结论，再给 3 个支撑点，每个支撑点有事实/例子"；别人问你任何事，30 秒内先给结论再展开 |
| 2 | **事实–推断–判断三分** | 思考浅、表达乱 | 拿到一段话，能标出哪句是事实、哪句是你的推断、哪句是价值判断；自己表达时不把三者混成一锅 |
| 3 | **假设-验证式思考（Hypothesis-driven）** | 思考浅 | 面对陌生问题，能先**穷举可能假设**、排序、设计"最小验证"，而不是"这像以前那个问题"。（用你自己的测试用例例子能重做一遍） |
| 4 | **结构化拆解 / 议题树 / MECE** | 思考浅 | 能把一个大问题拆成"不重不漏"的子问题树，深度 ≥ 3 层，且能说清每层的拆分依据 |
| 5 | **第一性原理** | 思考浅 | 对一个"大家都这么做"的常识，能拆到不可再拆的基本事实，再自己重新推导一遍结论 |
| 6 | **概率与决策 + 决策复盘** | 判断力弱 | 做决策前能写下"我赌的是什么 / 赢面多大 / 错了代价多大"；事后能把"决策质量"和"结果好坏"分开评价（用你买股票的例子能复盘） |
| 7 | **二阶思维 + 逆向思考（Inversion）** | 思考浅、判断力弱 | 对任何方案能追问"然后呢？（二阶后果）"和"要让它彻底失败该怎么做？"并各给出 ≥ 2 条 |
| 8 | **心智模型库（复利、机会成本、幸存者偏差、沉没成本…）** | 全面 | 能随口调用 ≥ 20 个心智模型，各配一个自己生活/工作里的真实例子 |
| 9 | **元认知 / 自我诊断**（盲区②） | 不知道"问题在哪" | 一条内容/一段分析不行时，能定位到是**钩子 / 结构 / 例子 / 受众**哪一环出了问题，而非笼统"感觉不好"；能每周对自己产出做一次结构化复盘 |
| 10 | **抽象 ↔ 具象双向切换**（盲区③） | 思考浅 | 能从一件具体小事**提炼出一条普遍原则**（归纳），再为该原则**配一个跨领域的新例子**（举例）——两个方向都过关 |

**主线一 · 26 周可检验目标：**
- [ ] 给你一个**陌生、非通信领域**的问题，你能在**不靠 AI 代写**的情况下，自己搭出"议题树 + 假设清单 + 最小验证"，并产出 **≥ 800 字结构化分析**，其中事实/推断/判断分离清晰；
- [ ] 能对第 6 项做到：任取一个你过去的决策，写出一份"决策质量 vs 结果"分离的复盘；
- [ ] 心智模型库累计 ≥ 20 个，每个都有你自己的例子；
- [ ] **（元认知）** 能对自己任一条内容做结构化诊断，指出具体薄弱环节并给出改法；
- [ ] **（抽象↔具象）** 能当场从一件小事提炼一条原则，并为它配一个跨领域的新例子。

### 主线二：表达 / 内容能力（能力阶梯 L0 → L5）

> 从"把想法讲清楚"到"做出一条能发布的短视频"，逐级爬，不跳级。前 2 个月按你的要求：文字线（L0–L2）与镜头线（L4）**交错**推进。

**(a) 能力阶梯 L0 → L5（决定"做不做得出来"）**

| 阶 | 能力 | 学会的标志（可自测勾选） |
|---|---|---|
| **L0** | 一句话结论 | 任何话题，30 秒内给出一句"结论先行"的话（配合主线一第 1 项） |
| **L1** | 结构化短文 300–800 字 | 能**自己搭骨架**（结论+分点+例子），AI 只做润色和逻辑校验，而不是替你想 |
| **L2** | 通勤口述成稿 | 地铁上语音口述 → 转文字 → 晚上整理成一篇可读短文，流程顺畅 |
| **L3** | 口播脚本（60–90 秒） | 能写出"钩子—正文—收尾/金句"结构的脚本，开头 3 秒有钩子 |
| **L4** | 对镜头念稿录制（可不发布） | 能对着手机念稿录一条，语速、停顿、眼神基本自然（前期只求"敢录、能录完"） |
| **L5** | 完整短视频 | 独立完成"选题 → 脚本 → 录制 → 剪辑 → 发布"整条链路 |

**(b) 内核能力（贯穿 L0–L5，决定"有没有人看"）** —— 即隐藏盲区 ① 与 ④：

| 内核能力 | 学会的标志（可自测勾选） |
|---|---|
| **受众思维 / 共情**（盲区①） | 每条内容能明确回答**"受众三问"**：写给谁？他第一句为什么不划走？他看完得到什么？能用 AI 扮演目标观众挑刺，并据此改稿 |
| **叙事 / 故事化**（盲区④） | 能用**"我以前这样 → 遇到这件事 → 我发现 → 现在这样"**的模板，把一个道理讲成一个让人想听完的个人故事 |

**主线二 · 26 周可检验目标：**
- [ ] 能在**不看稿**的情况下，用 60–90 秒把一个认知框架讲清（结论先行 + 1 个例子 + 1 句金句）；
- [ ] 完成"通勤口述 → 成稿"这条工作流的稳定运转（成为你日常产出的主引擎）；
- [ ] **（受众思维）** 每条内容都能通过"受众三问"，不再自说自话；
- [ ] **（叙事）** 能脱稿用个人故事模板，讲清一次自己的真实转变经历；
- [ ] 累计独立完成并发布短视频（**具体条数目标放到第 2 部分按阶段设定**，此处不写死，避免早期为凑数牺牲质量）。

### 主线三：平台 / 事业能力

> 早期只求"看懂规律 + 跑通闭环"，不追粉丝数。变现作为后期附产品。

| 能力 | 学会的标志（可自测勾选） |
|---|---|
| **账号定位** | 能用一句话说清"我为谁、解决什么问题、我是谁"（例：为想提升认知但没时间的普通人，一个工程师用 AI 重塑思维的真实过程） |
| **选题系统** | 有一个持续增长的选题库 + 至少 1 个可复用的"选题公式"，随时能取题不发愁 |
| **冷启动认知** | 能看懂完播率/互动/发布节奏这些指标**说明了什么**（而不是盲目追爆款），能据此改下一条 |
| **变现雏形** | 能设计出"付费咨询"或"最小产品"的草案（对应你 7 号答案里的"可持续盈利方式"） |

**主线三 · 26 周可检验目标：**
- [ ] 有一句清晰、稳定的账号定位；
- [ ] 选题库 ≥ 50 条；
- [ ] 完整跑通"选题 → 脚本 → 发布 → 看数据 → 迭代"闭环 ≥ 若干轮（第 2 部分定量）；
- [ ] 产出 1 份可落地的"付费咨询 / 小产品"草案（对应你的"值得继续"信号之一）。

---

> **说明 1：为什么三条主线要并行、但配比随阶段变。**
> 你的核心风险是"只输入不输出"。所以即便主线一（思维）是根基，我也不会让你花几个月只练思维再开始表达——**从第 1 周起，思维训练的产物就直接喂给表达线**（想清楚的东西立刻写出来/讲出来）。三条线的**时间配比**会在第 2 部分按阶段调整（离职前偏思维+文字，离职后加重镜头+平台）。
>
> **说明 2：新增的 4 项盲区如何塞进离职前的 90 分钟而不超支。**
> 它们都不作为"独立大任务"，而是**寄生在你每天本来就要做的产出里**：
> - **受众思维①**：不额外花时间——每天产出前后各花 1–2 分钟回答"受众三问"即可；
> - **抽象↔具象③**：并进"每日一条产出"里（把当天的具体事提炼成一条原则再配例子），本身就是产出素材；
> - **叙事④**：融入你的个人故事类内容，用固定模板降低成本；
> - **元认知②**：离职前只做**轻量版**（每周 1 次结构化自检，放周末 30 分钟）；**深度复盘与品味训练⑤留到离职后**再加重。
> 结论：离职前不因这 4 项而增加每日时长；**真正吃时间的深度部分（元认知深度复盘 + 品味/拆解优秀内容）明确挪到离职后**。具体排期见第 2、3 部分。

## 补充确认：每日知识卡片 = 全程核心引擎（完整工作流与提示词见第 4 部分）

> 你每日硬交付的**具体形态**，就是"**一张知识卡片**"。它不是"第二大脑"式的知识仓库（你有 AI，检索从不是瓶颈），而是**逼你练最缺能力 + 持续产出内容素材**的日更引擎。

**它的真正价值（对你而言）：**
- 一张合格的卡 = 用自己的话说清一个观点 + 配一个例子 → 天然在练 **抽象↔具象（盲区③）**；
- 把"被动刷公众号"改造成"刷完必须交一张卡" → 消费变产出；
- **卡片 = 内容素材库 / 选题库的源头**：一张卡 → 一条短文 → 一条脚本 → 一条视频，直接喂养主线二、主线三。

**两条铁规矩（对你尤其致命，先立规矩）：**
1. **不折腾系统、只看产出**：前 4 周禁止折腾 Obsidian 插件/结构；卡片"能拿给别人看 / 能当选题"才算完成；成功指标是**卡片 → 已发布内容的转化率**，不是卡片数量。
2. **AI 不许代笔**：卡里的"我的话复述"和"我的例子"**必须自己写**；AI 只当**苏格拉底式提问者 / 例子生成器 / 逻辑校验员**。否则卡是 AI 的认知，不是你的，认知没提升。

**知识卡片模板（每一项都在练一个能力）：**

```
标题：一句话结论（用我自己的话，不抄原文）      ← 结论先行（主线一 #1）
触发来源：我读到 / 听到 / 想到的什么             ← 主动输入
我的话复述（≤5 句，把结论"讲透"：是什么/为什么/边界，费曼式大白话，不抄原文）  ← 抽象↔具象（盲区③）
我的一个例子（最好来自工程师 / 生活经历）        ← 抽象↔具象 + 叙事（盲区④）
这能做成给谁看的什么内容？                      ← 受众思维（盲区①）+ 选题库种子
我还没想清的一个问题 / 一个反例                  ← 元认知（盲区②）+ 二阶思维
```

**嵌进通勤工作流（不额外占时间）：**

| 时段 | 动作 | 落到哪 |
|---|---|---|
| 8:30–9:30 地铁 | 读/听一个素材，语音口述初卡（结论+复述+例子） | `00_每日产出` |
| 19:30–20:00 地铁 | 修当天/昨天的卡，补"例子 / 反例" | `00_每日产出` |
| 晚上疲惫 20 分钟 | 低耗：把卡整理进 Obsidian，成熟的打标"可做内容" | `10_观点卡片` / `20_选题库` |
| 每周 | 从卡库挑 1–2 张扩写成短文 / 脚本（主线二产出源） | 内容草稿 |

**Obsidian 极简三件套（起步阶段，禁止复杂化）：**
`00_每日产出`（语音初稿落这）→ `10_观点卡片`（成型的卡）→ `20_选题库`（可做成内容的卡）。

## 第 2 部分：阶段划分（Phase）

把 26 周切成 **4 个阶段**，逻辑是一条"**能力递进 + 逐步公开**"的路：**建引擎 → 跑闭环 → 上镜迭代 → 放大变现**。

> **一个关键设计：阶段按"能力里程碑"划分，而不是死绑日期。** 因为你离职时间在 W5–W12 之间浮动，所以**每个跨越离职点的阶段都同时给了"离职前碎片版"和"离职后整块版"两套时间预算**，离职当周直接切换即可，无需重排计划。

### 阶段总览

| 阶段 | 周数 | 主题 | 时间背景 | 一句话核心目标 | 进入下一阶段的准入检验点 |
|---|---|---|---|---|---|
| **P1 建引擎** | W1–W4 | 输入重构 + 每日卡片习惯 | 离职前（碎片 90min） | 让"每日一张知识卡片"跑起来，敢对着镜头开口 | 连续 ≥21 天每天交卡；能用"结论先行"讲清一件事；已录 ≥4 条不发布的对镜头练习 |

### 为什么现阶段不该模仿 Dan Koe / Justin Welsh

你向往他们，但**他们的打法是"终点的打法"，不是"起点的打法"**，现在照搬会害了你：

1. **他们的模式建立在你还不具备的前提上**：成熟人设 + 已有受众 + 长期高密度输出能力 + 稳定分发渠道。Dan Koe 的"哲学长文/一人公司体系"之所以成立，是因为他背后有几年积累的思考密度和作品验证——**你现在连"每天产出、发布第一条"都还没跨过**，直接模仿只会产出空洞的大道理。
2. **平台错配**：他们主战场是英文 Twitter / Newsletter 长文；**你的主战场是中文短视频**，内容形态、冷启动逻辑完全不同。
3. **反馈周期错配**：他们的长内容反馈慢，而你最怕"坚持了没人看却不知问题在哪"——你现在需要的是**短平快、能快速拿到反馈并诊断**的模式，而不是憋大招。

**正确顺序（也正是本规划的阶段逻辑）**：先用**最低门槛模式**（私密卡片 → 不出镜图文/口播 → 出镜短视频 → 内容公式化+变现）建立"产出-发布-反馈-迭代"闭环，每阶段只升级一步。等你到 P3–P4、手里有了真实作品和一点受众，**再去拆解 Dan Koe 们的方法论骨架为你所用**——那时模仿才有地基。这也正是你自己定的原则："他们是最终目标，但每个阶段选最适合我当前水平的模式。"

## 第 4 部分：贯穿全程的机制与资源

### 4.1 把 AI 变成你的"教练团"——7 个可复用提示词模板

> **总原则（贴在你 Obsidian 首页）：AI 负责"问我、查我、给我选项、帮我润色"；AI 不负责"替我思考、替我下结论、替我写复述和例子"。** 一旦让 AI 代笔核心思考，卡片就成了 AI 的认知，你的认知不会提升——这直接违背你的首要目标。

复制下面模板，把 `【】` 换成你的内容即可。

**① 框架拆解教练（用于每周学新框架）**
```
你是我的认知框架教练。请教我"【框架名，如：第一性原理】"，按以下结构：
1) 用一句大白话讲它是什么；2) 它解决什么问题、什么时候不该用；
3) "学会的标志"是什么（给我一个可自测的检验动作）；
4) 先别给我答案——出一道让我用它拆解的练习题，题目要贴近【软件工程师/日常生活】。
5) 最后告诉我：这个框架的经典出处/原作者是谁？有没有常见的误解或滥用？（防偏差·溯源）
我做完后你再点评。全程用中文，不要长篇大论。
```
> 配合"修正 A"：重要框架建议再用**另一个 AI**问一遍做交叉验证；说法冲突处正是你要深挖的地方。

**② 苏格拉底提问器（治"思考浅"，每日可用）**
```
接下来就一个话题，你只许向我提问、不许给结论。每次只问一个问题，
层层追问，逼我把"【我的初步想法】"想深、想全（尤其追问：还有别的可能吗？
证据是什么？反例是什么？）。直到我自己得出更深的结论为止。用中文。
```

**③ 表达教练 / 逻辑校验（治"表达乱"，每次写完必用）**
```
下面是我写的一段话：【粘贴】。请做三件事：
1) 指出哪里逻辑混乱、哪里"结论没先行"、哪里事实与观点混在一起；
2) 用"结论先行+金字塔结构"帮我重排骨架（只给骨架，别替我重写内容）；
3) 告诉我一个读者最可能在哪句话划走。用中文，直接、别客气。
```

**④ 知识卡片副驾（每日做卡时用，严禁代笔）**
```
我在做一张知识卡片，主题是【】。规则：你不许替我写"我的话复述"和"我的例子"。
你只能：a) 就我的复述向我提问，指出我没讲透/讲错的地方；
b) 若我卡在例子，给我 3 个"例子方向"让我自己选和展开，而不是直接给成品；
c) 最后帮我检查这张卡能不能变成一条内容（受众是谁）。用中文。
```

**⑤ 受众模拟器（治"没人看"，每条内容发布前用）**
```
你现在扮演我的目标观众：【一个想提升认知、但没耐心、时间碎片化的普通上班族】。
这是我的内容：【粘贴脚本/文案】。以他的口吻告诉我：
1) 开头 3 秒你会不会划走、为什么；2) 哪句让你觉得"这跟我有关"；
3) 看完你记住了什么、会不会转发。别夸我，越挑剔越好。用中文。
```

**⑥ 决策复盘器（治"判断力弱"，每次重要决策后用）**
```
帮我复盘一个决策：【描述决策，如去年买某只股票】。请引导我分开评估：
1) 决策质量：当时我掌握了什么信息、赢面判断是否合理、有没有忽略的风险；
2) 结果好坏：结果差是"决策差"还是"运气差"；
3) 可迁移的教训（不要安慰我，也不要只怪运气）。用提问方式引导，用中文。
```

**⑦ 优秀内容拆解器（治"品味"，P3 起每周用）**
```
这是一条我觉得做得好的内容：【粘贴文案/转述结构】。请帮我拆解它的"可复用骨架"：
钩子怎么写的、结构怎么排的、用了什么情绪/例子、结尾怎么收。
最后给我一个"套用这个骨架、换成我的选题【】"的空白模板。用中文。
```

- **每阶段**：过了准入检验点 = 一个里程碑，给自己一个非物质奖励（睡个懒觉/一顿好的）。

**B. "卡住时怎么办"——先分清卡在哪一类，再对症（贴在 Obsidian）**：

|---|---|---|
